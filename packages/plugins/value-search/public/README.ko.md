# 값 검색

값 검색은 컬렉션의 모든 필드에서 값을 한 번에 찾습니다. 이름, 이메일 주소, 주문 번호, ObjectId, 날짜 등을 찾을 수 있습니다. 값은 알지만 어느 필드에 있는지 모를 때 사용하세요. 찾은 도큐먼트마다 일치한 필드가 표시되며 앱에서 열 수 있습니다.

이 플러그인은 읽기만 합니다. 데이터베이스는 전혀 변경하지 않습니다.

## 표시되는 위치

- **컬렉션 탭:** 모든 컬렉션과 뷰에서 도큐먼트, 집계 및 다른 탭 옆에 **검색** 탭이 표시됩니다.

## 사용 방법

1. 컬렉션을 연 다음 **검색** 탭을 엽니다. 먼저 컬렉션의 샘플을 읽어 필드를 파악하며, 빈 페이지에는 검색할 필드 수가 표시됩니다.
2. **검색어**에 찾을 내용을 입력합니다. 텍스트, 숫자, `2026-01-05` 같은 날짜 또는 ObjectId를 입력할 수 있습니다.
3. **일치 방식**을 선택합니다. **포함**, **전체 값**, **정규식** 중에서 고릅니다.
4. 필요하면 **대소문자 구분 안 함**을 켜거나, **필드 이름도 일치 대상에 포함**을 켜서 해당 텍스트가 들어 있는 필드 이름도 나열합니다.
5. **검색 위치**를 선택합니다. **컬렉션 전체**(기본값) 또는 **도큐먼트 필터**(도큐먼트 탭의 쿼리) 중에서 고릅니다. **열기**가 남기는, `_id`로 도큐먼트 하나를 지정하는 필터는 선택지로 제공되지 않습니다.
6. **검색**을 누르거나 Enter 키를 누릅니다.

결과에는 찾은 도큐먼트가 나열되며, 각 도큐먼트마다 일치한 필드와 그 값이 표시되고 일치한 부분은 강조됩니다. **모든 필드**를 사용하면 목록이 한 필드에서 일치하는 도큐먼트로 좁혀집니다. **열기**는 도큐먼트를 앱에서 보여 주며, 탭으로 돌아오면 검색과 결과가 그대로 남아 있습니다. **도큐먼트에서 보기**는 검색을 필터로 도큐먼트 쿼리에 넣으므로, 일치하는 모든 도큐먼트를 그곳에서 페이지별로 볼 수 있습니다.

## 검색어 종류별로 찾는 것

- **텍스트:** 그 텍스트를 포함하거나(포함), 같거나(전체 값), 일치하는(정규식) 문자열 필드.
- **숫자**(`1042`, `19.90` 등): 텍스트 일치 외에도, 저장된 유형(int, long, double, decimal)과 관계없이 그 숫자를 가진 필드. `1042`는 `1042`, `NumberLong(1042)`, `1042.0`을 모두 찾고, `524.66`은 decimal `524.66`을 찾습니다. **포함**에서는 자릿수에 검색어가 들어 있는 숫자도 찾습니다. `524`는 `524.66`과 `1524`를 찾습니다.
- **ObjectId**(16진수 24자리): 텍스트 일치 외에도, 도큐먼트를 가리키는 참조처럼 그 ObjectId를 가진 필드.
- **날짜**(`2026-01-05`, `2026-01-05 14:30` 또는 `2026-01-05T14:30:15`): 텍스트 일치 외에도, UTC 기준으로 그 날, 분 또는 초에 속하는 날짜 필드.

**정규식**에서는 검색어가 입력한 그대로 서버가 실행하는 정규 표현식이며, 숫자, ObjectId, 날짜는 추가되지 않습니다.

## 예시

`customers` 컬렉션에서 `ada@example.com`을 **포함**, **대소문자 구분 안 함**으로 검색합니다. 결과는 다음과 같을 수 있습니다.

```
도큐먼트 2개 · 필드 38개 · 컬렉션 전체
Ada Lovelace     email: Ada@Example.com
Charles Babbage  contacts.1.email: ada@example.com
```

그런 다음 **도큐먼트에서 보기**를 누르면 도큐먼트에 다음과 같은 필터가 들어갑니다(검색한 필드마다 조건 하나).

```json
{ "$or": [ { "email": { "$regularExpression": { "pattern": "ada@example\\.com", "options": "i" } } }, … ] }
```

## 권한

- **도큐먼트 읽기**(`documents:read`): 필드를 파악하기 위해 컬렉션의 샘플을 읽고 검색을 실행합니다.

읽기는 앱을 통해 로그인한 사용자의 권한과 필드 마스킹에 따라 이루어집니다. 이 플러그인은 다른 컬렉션을 읽을 수 없습니다.

## 설정

없음.

## 제한

- 검색하는 필드는 무작위로 뽑은 200개 도큐먼트의 샘플에서 가져오며, 필드 경로는 최대 100개, 깊이는 여섯 단계까지입니다. 샘플링된 도큐먼트에 하나도 없는 필드는 검색되지 않습니다. 다른 샘플로 나중에 다시 검색하거나, 도큐먼트에서 필터를 직접 지정하세요. 도큐먼트가 크면 샘플이 줄어들어, 페이지로 가는 한 번의 응답(1MB)에 담길 만큼만 가져옵니다.
- 도큐먼트는 최대 100개까지 나열됩니다. 더 많이 일치하면 개수가 “100+”로 표시되며, 도큐먼트에서 보기로 모두 볼 수 있습니다.
- 도큐먼트마다 일치한 필드는 최대 20개까지 표시됩니다.
- 정규식은 최대 200자입니다. 서버가 실행하며 실행 시간도 서버가 제한합니다. 페이지는 일치한 필드를 직접 표시하지만, 끝없이 되돌아갈 수 있는 패턴(`(a+)+` 등)이나 값의 처음 1,000자를 넘는 부분에는 표시하지 않습니다. 이 경우에도 도큐먼트는 목록에 나옵니다.
- 검색은 필드마다 조건 하나를 둔 쿼리 하나입니다. 적합한 인덱스가 없는 큰 컬렉션에서는 모든 도큐먼트를 읽습니다. 디스크를 사용하지 않고 최대 10초 동안 실행되며, 시간이 초과되면 도큐먼트 필터로 범위를 좁히세요.
- 포함과 정규식은 문자열 안에서만 텍스트를 찾습니다. 숫자, 날짜, ObjectId는 전체 값으로만 찾습니다.
