# 值搜索

值搜索一次性在集合的所有字段中查找某个值：姓名、电子邮件地址、订单号、ObjectId、日期。当你知道某个值，却不知道它存放在哪个字段时，就可以使用它。找到的每个文档都会显示匹配的字段，并可在应用中打开。

该插件只读取数据，不会更改数据库中的任何内容。

## 出现的位置

- **集合标签页：** 在每个集合和视图中，位于“文档”、“聚合”及其他标签页旁边的**搜索**标签页。

## 使用方法

1. 打开一个集合，然后切换到**搜索**标签页。它会先读取集合的一个样本以了解其字段；空白页面会说明将搜索多少个字段。
2. 在**搜索内容**中输入要查找的内容：文本、数字、`2026-01-05` 这样的日期，或 ObjectId。
3. 选择**匹配方式**：**包含**、**完整值**或**正则**。
4. 也可以开启**忽略大小写**，或开启**同时匹配字段名**，一并列出包含该文本的字段名。
5. 选择**搜索范围**：**整个集合**（默认）或**文档筛选**（“文档”标签页的查询）。**打开**操作留在那里的、按 `_id` 指定单个文档的筛选不会提供。
6. 点击**搜索**（或按 Enter）。

结果会列出找到的文档，每个文档都带有匹配的字段及其值，并标出匹配部分。**所有字段**可将列表缩小到在某一个字段中匹配的文档。**打开**会在应用中显示文档；你回到该标签页时，搜索及其结果仍在原处。**在文档中显示**会把搜索作为筛选放入“文档”查询，这样所有匹配的文档都可以在那里分页浏览。

## 各类搜索词能找到什么

- **文本：** 包含它（包含）、等于它（完整值）或匹配它（正则）的字符串字段。
- **数字**（如 `1042` 或 `19.90`）：除文本匹配外，还有持有该数字的字段，无论其存储类型是 int、long、double 还是 decimal。`1042` 能同时找到 `1042`、`NumberLong(1042)` 和 `1042.0`，`524.66` 能找到 decimal `524.66`。使用**包含**时，数位中含有该搜索词的数字也会被找到：`524` 能找到 `524.66` 和 `1524`。
- **ObjectId**（24 位十六进制数字）：除文本匹配外，还有持有该 ObjectId 的字段，例如对该文档的引用。
- **日期**（`2026-01-05`、`2026-01-05 14:30` 或 `2026-01-05T14:30:15`）：除文本匹配外，还有落在该日、该分钟或该秒内的日期字段，按 UTC 计算。

使用**正则**时，搜索词是由服务器按原样运行的正则表达式；不会再加入数字、ObjectId 和日期的匹配。

## 示例

在 `customers` 集合中搜索 `ada@example.com`，选择**包含**和**忽略大小写**。结果可能如下：

```
2 个文档 · 38 个字段 · 整个集合
Ada Lovelace     email: Ada@Example.com
Charles Babbage  contacts.1.email: ada@example.com
```

随后，**在文档中显示**会在“文档”中放入类似下面的筛选（每个被搜索的字段对应一个条件）：

```json
{ "$or": [ { "email": { "$regularExpression": { "pattern": "ada@example\\.com", "options": "i" } } }, … ] }
```

## 权限

- **读取文档**（`documents:read`）：用于读取集合样本以获得其字段，并运行搜索。

读取通过应用进行，使用已登录用户的权限和字段掩码。该插件无法读取其他集合。

## 设置

无。

## 限制

- 被搜索的字段来自 200 个文档的随机样本，最多 100 个字段路径，深度最多六层。样本文档中没有任何一个包含的字段不会被搜索；可稍后再次搜索以获取另一个样本，或在“文档”中使用明确的筛选。大文档的样本会更少：只取页面一次应答（1 MB）能容纳的数量。
- 最多列出 100 个文档。匹配更多时，数量显示为“100+”；“在文档中显示”会显示全部。
- 每个文档最多显示 20 个匹配字段。
- 正则表达式最多 200 个字符。它由服务器运行，并由服务器限制自身的运行。页面会自行标出匹配的字段，但对于可能无限回溯的模式（如 `(a+)+`），或超出值的前 1,000 个字符的部分，不会标记；文档仍会列出。
- 搜索是一次查询，每个字段一个条件；在没有合适索引的大型集合上，它会读取每个文档。它最多运行 10 秒，且不使用磁盘；如果超时，请用“文档”筛选缩小范围。
- “包含”和“正则”只在字符串内部查找文本；数字、日期或 ObjectId 按其完整值查找。
