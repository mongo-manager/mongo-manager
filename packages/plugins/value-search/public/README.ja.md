# 値の検索

値の検索は、コレクションのすべてのフィールドから値を一度に探します。名前、メールアドレス、注文番号、ObjectId、日付などが対象です。値はわかっていても、どのフィールドに入っているかわからないときに使います。見つかった各ドキュメントには一致したフィールドが表示され、アプリで開けます。

このプラグインは読み取りのみを行います。データベースの内容は何も変更しません。

## 表示される場所

- **コレクションのタブ:** すべてのコレクションとビューで、ドキュメントや集計などのタブの横に表示される**検索**タブ。

## 使い方

1. コレクションを開き、**検索**タブに切り替えます。最初にコレクションのサンプルを読み取ってフィールドを把握します。空のページには、検索されるフィールドの数が表示されます。
2. **検索する内容**に探したいものを入力します。テキスト、数値、`2026-01-05` のような日付、または ObjectId です。
3. **一致の方法**を選びます。**含む**、**完全一致**、**正規表現**のいずれかです。
4. 必要に応じて、**大文字と小文字を区別しない**をオンにします。**フィールド名も対象にする**をオンにすると、そのテキストを含むフィールド名も一覧に表示されます。
5. **検索範囲**を選びます。**コレクション全体**（既定）か、**ドキュメントのフィルター**（ドキュメントタブのクエリ）です。**開く**がドキュメントに残す、`_id` で 1 件のドキュメントを指定するフィルターは選択肢に出ません。
6. **検索**を押します（または Enter キー）。

結果には、見つかったドキュメントが、一致したフィールドとその値とともに、一致部分を強調して一覧表示されます。**すべてのフィールド**を使うと、1 つのフィールドで一致したドキュメントだけに絞り込めます。**開く**はドキュメントをアプリで表示します。タブに戻っても、検索とその結果はそのまま残っています。**ドキュメントで表示**は、検索をフィルターとしてドキュメントのクエリに設定するので、一致したすべてのドキュメントをそちらでページ送りして見られます。

## 検索語の種類ごとに見つかるもの

- **テキスト:** それを含む（含む）、それと等しい（完全一致）、またはそれに一致する（正規表現）文字列フィールド。
- **数値**（`1042` や `19.90` など）: テキストの一致に加えて、保存された型（int、long、double、decimal）にかかわらず、その数値を持つフィールド。`1042` は `1042`、`NumberLong(1042)`、`1042.0` のすべてを見つけ、`524.66` は decimal の `524.66` を見つけます。**含む**では、桁に検索語を含む数値も見つかります。`524` は `524.66` と `1524` を見つけます。
- **ObjectId**（24 桁の 16 進数）: テキストの一致に加えて、その ObjectId を持つフィールド（ドキュメントへの参照など）。
- **日付**（`2026-01-05`、`2026-01-05 14:30`、`2026-01-05T14:30:15`）: テキストの一致に加えて、その日、分、または秒の範囲内にある日付フィールド（UTC）。

**正規表現**では、検索語はサーバーがそのまま実行する正規表現です。数値、ObjectId、日付の一致は追加されません。

## 例

`customers` コレクションで、`ada@example.com` を**含む**、**大文字と小文字を区別しない**で検索します。結果は次のようになります。

```
2 件のドキュメント · 38 フィールド · コレクション全体
Ada Lovelace     email: Ada@Example.com
Charles Babbage  contacts.1.email: ada@example.com
```

続けて**ドキュメントで表示**を押すと、次のようなフィルターがドキュメントに設定されます（検索したフィールドごとに 1 つの条件）。

```json
{ "$or": [ { "email": { "$regularExpression": { "pattern": "ada@example\\.com", "options": "i" } } }, … ] }
```

## 権限

- **ドキュメントの読み取り**（`documents:read`）: フィールドを把握するためにコレクションのサンプルを読み取り、検索を実行するために使います。

読み取りはアプリを通じて、サインインしているユーザーの権限とフィールドのマスクに従って行われます。このプラグインは他のコレクションを読み取れません。

## 設定

なし。

## 制限

- 検索されるフィールドは、200 件のドキュメントのランダムなサンプルから取得され、最大 100 個のフィールドパス、深さは 6 階層までです。サンプルのどのドキュメントにもないフィールドは検索されません。別のサンプルを使うには後でもう一度検索するか、ドキュメントで明示的なフィルターを使ってください。大きなドキュメントはサンプル数が少なくなり、ページへの 1 回の応答（1 MB）に収まる数だけになります。
- 一覧表示されるのは最大 100 件のドキュメントです。それより多く一致した場合、件数は「100+」と表示されます。ドキュメントで表示するとすべてを確認できます。
- 1 つのドキュメントにつき、一致したフィールドは最大 20 個まで表示されます。
- 正規表現は 200 文字以内です。サーバーが実行し、実行自体もサーバーが制限します。一致したフィールドの強調表示はページ自身が行いますが、際限なくバックトラックする可能性のあるパターン（`(a+)+` など）や、値の最初の 1,000 文字を超える部分では行いません。その場合でもドキュメントは一覧に表示されます。
- 検索はフィールドごとに 1 つの条件を持つ 1 回のクエリです。適切なインデックスのない大きなコレクションでは、すべてのドキュメントを読み取ります。最大 10 秒、ディスクを使わずに実行されます。タイムアウトする場合は、ドキュメントのフィルターで絞り込んでください。
- 「含む」と「正規表現」は文字列の内部のテキストだけを探します。数値、日付、ObjectId は値全体で見つかります。
