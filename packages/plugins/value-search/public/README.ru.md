# Поиск значений

Поиск значений ищет значение сразу во всех полях коллекции: имя, адрес электронной почты, номер заказа, ObjectId, дату. Используйте его, когда знаете значение, но не знаете, в каком поле оно находится. Каждый найденный документ показывает совпавшие поля и открывается в приложении.

Плагин только читает. Он ничего не меняет в базе данных.

## Где он появляется

- **Вкладка коллекции:** вкладка **Поиск** рядом с «Документами», «Агрегациями» и другими вкладками каждой коллекции и представления.

## Как пользоваться

1. Откройте коллекцию, затем вкладку **Поиск**. Сначала плагин читает выборку из коллекции, чтобы узнать ее поля; на пустой странице указано, сколько полей будет просмотрено.
2. В поле **Что искать** введите то, что нужно найти: текст, число, дату вроде `2026-01-05` или ObjectId.
3. Выберите **Способ сопоставления**: **Содержит**, **Значение целиком** или **Regex**.
4. При необходимости включите **Без учета регистра** или **Искать и в названиях полей**, чтобы дополнительно перечислить названия полей, содержащие этот текст.
5. Выберите **Где искать**: **Вся коллекция** (по умолчанию) или **Фильтр документов** (запрос вкладки «Документы»). Фильтр, который задает один документ по его `_id` и который оставляет действие **Открыть**, не предлагается.
6. Нажмите **Найти** (или клавишу Enter).

В результате перечислены найденные документы, у каждого — совпавшие поля и их значения, совпадение выделено. **Все поля** сужают список до документов, совпавших в одном поле. **Открыть** показывает документ в приложении; когда вы возвращаетесь на вкладку, поиск и его результаты на месте. **Показать в «Документах»** переносит поиск в виде фильтра в запрос «Документов», чтобы там можно было листать все подходящие документы по страницам.

## Что находит каждый вид запроса

- **Текст:** строковые поля, которые его содержат («Содержит»), равны ему («Значение целиком») или соответствуют ему (Regex).
- **Число** (например, `1042` или `19.90`): помимо текстового совпадения, поля с этим числом независимо от сохраненного типа: int, long, double или decimal. `1042` находит и `1042`, и `NumberLong(1042)`, и `1042.0`, а `524.66` находит decimal `524.66`. При **Содержит** находятся и числа, в цифрах которых есть запрос: `524` находит `524.66` и `1524`.
- **ObjectId** (24 шестнадцатеричные цифры): помимо текстового совпадения, поля с этим ObjectId, например ссылки на документ.
- **Дата** (`2026-01-05`, `2026-01-05 14:30` или `2026-01-05T14:30:15`): помимо текстового совпадения, поля с датой в пределах этого дня, минуты или секунды по UTC.

При **Regex** запрос — это регулярное выражение, которое сервер выполняет как написано; числа, ObjectId и даты не добавляются.

## Пример

В коллекции `customers` найдите `ada@example.com` с режимом **Содержит** и включенным **Без учета регистра**. Результат может выглядеть так:

```
2 документа · 38 полей · вся коллекция
Ada Lovelace     email: Ada@Example.com
Charles Babbage  contacts.1.email: ada@example.com
```

Затем **Показать в «Документах»** помещает в «Документы» фильтр такого вида (по одному условию на каждое просмотренное поле):

```json
{ "$or": [ { "email": { "$regularExpression": { "pattern": "ada@example\\.com", "options": "i" } } }, … ] }
```

## Разрешения

- **Чтение документов** (`documents:read`): чтобы прочитать выборку из коллекции и узнать ее поля, а также чтобы выполнить поиск.

Чтение идет через приложение с правами вошедшего пользователя и с маскированием полей. Плагин не может читать другие коллекции.

## Настройки

Нет.

## Ограничения

- Просматриваемые поля берутся из случайной выборки в 200 документов: не более 100 путей полей, глубина до шести уровней. Поле, которого нет ни в одном документе выборки, не просматривается; повторите поиск позже, чтобы получить другую выборку, или используйте «Документы» с явным фильтром. Из больших документов берется меньше: столько, сколько помещается в один ответ странице (1 МБ).
- Выводится не более 100 документов. Если совпало больше, счетчик показывает «100+»; «Показать в „Документах“» показывает все.
- Для каждого документа показывается не более 20 совпавших полей.
- Регулярное выражение содержит не более 200 символов. Его выполняет сервер, он же ограничивает время выполнения. Страница сама выделяет совпавшие поля, но не делает этого для шаблона, который мог бы бесконечно откатываться (например, `(a+)+`), и за пределами первых 1000 символов значения; документ в списке все равно остается.
- Поиск — это один запрос с условием на каждое поле; в большой коллекции без подходящих индексов он читает каждый документ. Он выполняется не дольше 10 секунд и без использования диска; если время истекло, сузьте поиск фильтром документов.
- «Содержит» и Regex находят текст только внутри строк; число, дата или ObjectId находятся только по значению целиком.
