# Анонимизатор

Разработчику нужны данные, похожие на рабочие, чтобы воспроизвести ошибку; команда хочет передать подрядчику образец; тестовая среда должна выглядеть как настоящая, не содержа ничьих персональных данных. Собственная анонимная копия приложения записывает `***` вместо скрытых значений. Анонимизатор создает данные, которые по-прежнему выглядят и ведут себя как исходные, — по подходу, как инструменты вроде маскирования данных в Studio 3T, Hackolade и функции маскирования в платформах баз данных: вымышленные значения того же вида, хеши, при которых соединения продолжают работать, значения, перемешанные между документами, слегка сдвинутые даты, числа с шумом.

## Как пользоваться

Откройте коллекцию и ее вкладку **Анонимизировать**.

1. Плагин случайно выбирает 100 документов и перечисляет их поля (поле внутри объекта или массива объектов перечисляется отдельно; объект, который его содержит, — нет, если только в некоторых документах на его месте нет значения вместо объекта: тогда он тоже перечисляется, с пометкой *если не объект*, для этих значений). Каждому полю назначается метод:
   - **Оставить** — значение как есть.
   - **Вымышленное значение** — правдоподобное значение того же вида, по имени и типу поля или по выбранному вами виду (полное имя, эл. почта, телефон, адрес, город, почтовый индекс, компания, предложение, UUID, дата…): адрес эл. почты остается адресом эл. почты, на примерном домене; номер телефона — в диапазоне, где нет настоящих линий.
   - **Согласованный хеш** — один и тот же вход дает один и тот же результат во всей копии (адрес эл. почты остается одним и тем же хешем в каждом документе, где он есть, так что по нему по-прежнему можно группировать и соединять), тип сохраняется (ObjectId остается ObjectId, целое число — целым числом). Его ключ создается при открытии вкладки и никогда не сохраняется: две сессии дают разные хеши.
   - **Перемешать** — значения поля перемещаются между документами: каждое значение по-прежнему на месте, но ни одно не в своем документе.
   - **Сдвинуть даты** — даты сдвигаются не более чем на ± указанное вами число дней, одинаково для всех дат одного документа (порядок событий одного человека сохраняется). Даты, записанные текстом, сохраняют свой формат.
   - **Шум для чисел** — числа меняются не более чем на ± указанную вами долю; целое число остается целым.
   - **Null**, **Удалить**, **Скрыть** (`***`).
   Для `_id` допустимо только оставить, хешировать, заменить вымышленным значением (как ObjectId или UUID), перемешать или удалить (тогда при импорте будут созданы новые): ничего, из-за чего два документа получили бы одинаковый `_id`.
   Поля, которые указывают на человека, адрес или учетную запись (имена, адреса эл. почты, телефоны, улицы, почтовые индексы, даты рождения, пароли, IBAN…), начинают с метода **Вымышленное значение**; остальные — с **Оставить**.
2. **Поля, которых нет в выборке**: те, что есть в более позднем документе, но отсутствовали в выборке, по умолчанию исключаются, так же как и значение, найденное там, где в выборке были только объекты; вы можете их оставить.
3. Предпросмотр показывает пять документов до и после и отслеживает каждое изменение. **Новые значения** создают новые вымышленные значения, новое перемешивание и новый ключ хеша.
4. **Создать копию** читает до 1 000 документов (количество выбираете вы) страницами в порядке `_id` (все виды `_id`, числа раньше ObjectId, как сортирует MongoDB) и анонимизирует их на странице. Копия не больше того, что приложение принимает в одном сообщении (около 1 МБ): если больше не поместилось бы, она обрезается по целому документу, и страница сообщает об этом.
5. Затем:
   - **Сохранить NDJSON** или **Сохранить JSON** сохраняет копию в файл;
   - **Импорт…** открывает мастер импорта приложения для новой коллекции той же базы данных (по умолчанию `<collection>_anonymised`) с копией в качестве файла: там вы проверяете, сопоставляете и запускаете импорт.

**Сохранить настройки** сохраняет метод каждого поля в файл JSON (никогда не ключ хеша и никогда не значение); **Загрузить настройки** применяет их снова — поле, которое названо в файле, но отсутствует в этой коллекции, подсчитывается и пропускается.

## Персональные данные

Поле, скрытое от вас правилами персональных данных, никогда не сохраняется: у плагина для него всегда было только `***`. Его можно скрыть, заменить вымышленным значением, сделать null или удалить, а скрытое поле, которого не было в выборке, скрывается везде, где встречается. Сама коллекция никогда не меняется: копия попадает только туда, куда вы ее сохраните или импортируете.

## Разрешения

- **Чтение документов:** документы, из которых делается копия.
- **Чтение базы данных:** передача копии мастеру импорта для другой коллекции базы данных.
