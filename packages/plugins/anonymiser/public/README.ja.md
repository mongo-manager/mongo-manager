# 匿名化

開発者はバグを再現するために本番に近いデータを必要とします。チームはベンダーにサンプルを共有したいことがあります。テスト環境は、誰の個人データも持たずに本物らしく見える必要があります。アプリ自身の匿名コピーは、非表示の値の代わりに `***` を書き込みます。一方、匿名化は元のデータと同じように見え、同じように振る舞うデータを作ります。Studio 3T のデータマスキング、Hackolade、各データベースプラットフォームのマスキング機能と同じ考え方で、同じ種類のダミー値、結合が引き続き機能するハッシュ、ドキュメント間でシャッフルした値、少しずらした日付、ノイズを加えた数値を使います。

## 使い方

コレクションを開き、その**匿名化**タブを開きます。

1. プラグインは 100 件のドキュメントをランダムにサンプリングし、そのフィールドを一覧表示します（オブジェクトやオブジェクトの配列の中のフィールドは個別に表示され、それを含むオブジェクト自体は表示されません。ただし、一部のドキュメントでそこにオブジェクトではなく値が入っている場合は、その値用に _オブジェクト以外の場合_ と表示されて一覧に加わります）。各フィールドには方法が割り当てられます。
   - **保持** — 値をそのまま残します。
   - **ダミー値** — フィールド名と型から、または選んだ種類（氏名、メールアドレス、電話番号、番地、市区町村、郵便番号、会社、文、UUID、日付…）に応じた、本物らしい値にします。メールアドレスはメールアドレスのまま（例示用ドメイン）、電話番号は実在しない番号帯になります。
   - **一貫したハッシュ** — コピー全体で同じ入力は同じ出力になります（メールアドレスは、それを持つすべてのドキュメントで同じハッシュになるため、それでグループ化や結合ができます）。型は保たれます（ObjectId は ObjectId のまま、整数は整数のまま）。キーはタブを開いたときに生成され、保存されません。セッションが違えばハッシュも変わります。
   - **シャッフル** — フィールドの値をドキュメント間で入れ替えます。すべての値は残りますが、元のドキュメントに残るものはありません。
   - **日付をシフト** — 指定した日数の ± の範囲で日付をずらします。1 つのドキュメントのすべての日付は同じ日数だけずれるため、1 人の出来事の順序は保たれます。テキストで書かれた日付は形式が保たれます。
   - **数値にノイズ** — 指定した割合の ± の範囲で数値を変化させます。整数は整数のままです。
   - **Null**、**削除**、**マスク**（`***`）。
     `_id` に選べるのは、保持、ハッシュ、ダミー値（ObjectId または UUID）、シャッフル、削除（その場合、インポート時に新しい `_id` が付きます）だけです。2 つのドキュメントが同じ `_id` を共有することになる方法は選べません。
     人物、住所、アカウントを表すフィールド（氏名、メールアドレス、電話番号、番地、郵便番号、生年月日、パスワード、IBAN…）は最初から**ダミー値**、それ以外は**保持**になります。
2. **サンプルにないフィールド**：後のドキュメントにあってサンプルになかったフィールドや、サンプルではオブジェクトだけだった場所にある値は、既定では除外されます。保持を選ぶこともできます。
3. プレビューには 5 件のドキュメントの変換前後が表示され、変更のたびに更新されます。**値を再生成**すると、新しいダミー値、シャッフル、新しいハッシュキーになります。
4. **コピーを作成**は、最大 1,000 件のドキュメント（件数は選べます）を `_id` 順にページ単位で読み込み（あらゆる型の `_id` が対象で、MongoDB の並び順どおり数値が ObjectId より先になります）、ページ内で匿名化します。コピーの大きさは、アプリが 1 回のメッセージで受け取れる上限（約 1 MB）までです。収まらない場合はドキュメントの区切りで切り捨てられ、ページに表示されます。
5. その後：
   - **NDJSON を保存**または **JSON を保存**で、コピーをファイルとして保存します。
   - **インポート…**は、同じデータベースの新しいコレクション（既定は `<コレクション>_anonymised`）に対して、コピーをファイルとしてアプリのインポートウィザードを開きます。確認、マッピング、開始はウィザードで行います。

**設定を保存**は、各フィールドの方法を JSON ファイルとして保存します（ハッシュキーや値は保存されません）。**設定を読み込む**は、保存した設定を再び適用します。ファイルにあってもこのコレクションにないフィールドは、数えられてスキップされます。

## 個人データ

個人データのルールで非表示になっているフィールドは、保持されることはありません。プラグインはそれについて `***` しか受け取っていません。マスク、ダミー値、null、削除のいずれかにでき、サンプルに現れなかった非表示のフィールドも、現れた場所ではすべてマスクされます。コレクション自体は変更されません。コピーは、保存またはインポートした先にだけ渡されます。

## 権限

- **ドキュメントの読み取り：** コピーの元になるドキュメント。
- **データベースの読み取り：** コピーを、データベース内の別のコレクションのインポートウィザードに渡すため。
