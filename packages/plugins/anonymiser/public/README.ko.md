# 익명화

개발자는 버그를 재현하려고 운영 환경과 비슷한 데이터가 필요하고, 팀은 협력사와 샘플을 공유하고 싶어 하며, 테스트 환경은 누구의 개인 데이터도 담지 않으면서 실제처럼 보여야 합니다. 앱 자체의 익명 복사는 숨겨진 값을 `***`로 바꿉니다. 익명화 플러그인은 원본처럼 보이고 동작하는 데이터를 만듭니다. Studio 3T의 데이터 마스킹, Hackolade, 데이터베이스 플랫폼의 마스킹 기능과 같은 접근 방식입니다. 같은 종류의 가짜 값, 조인이 계속 동작하게 하는 해시, 도큐먼트 간에 섞은 값, 조금 이동한 날짜, 노이즈를 더한 숫자를 사용합니다.

## 사용 방법

컬렉션을 열고 **익명화** 탭을 엽니다.

1. 플러그인이 도큐먼트 100개를 무작위로 샘플링하여 필드를 나열합니다(객체나 객체 배열 안의 필드는 각각 따로 나열되고, 그것을 담은 객체는 나열되지 않습니다. 다만 일부 도큐먼트에 객체 대신 값이 들어 있으면 그 객체도 해당 값을 위해 *객체가 아닌 경우*로 표시되어 나열됩니다). 각 필드에는 방식이 하나씩 지정됩니다.
   - **유지** — 값을 그대로 둡니다.
   - **가짜 값** — 필드 이름과 유형에 따라, 또는 직접 고른 종류(전체 이름, 이메일, 전화번호, 도로명 주소, 도시, 우편번호, 회사, 문장, UUID, 날짜 등)에 맞는 실제 같은 값입니다. 이메일은 예시 도메인의 이메일로 유지되고, 전화번호는 실제 회선이 없는 범위에서 만들어집니다.
   - **일관된 해시** — 복사본 전체에서 같은 입력은 같은 출력을 냅니다(이메일은 그것을 가진 모든 도큐먼트에서 같은 해시가 되므로 계속 그룹화하거나 조인할 수 있습니다). 유형은 유지됩니다(ObjectId는 ObjectId, 정수는 정수). 키는 탭을 열 때 생성되며 저장되지 않으므로 세션이 다르면 해시도 다릅니다.
   - **셔플** — 필드의 값을 도큐먼트 사이에서 옮깁니다. 모든 값이 그대로 남아 있지만 어느 값도 원래 도큐먼트에는 없습니다.
   - **날짜 이동** — 지정한 일수 ± 범위 안에서 날짜를 이동하며, 한 도큐먼트의 모든 날짜에는 같은 일수가 적용됩니다(한 사람의 이벤트 순서가 유지됩니다). 텍스트로 쓰인 날짜는 형식이 유지됩니다.
   - **숫자 노이즈** — 지정한 비율 ± 범위 안에서 숫자를 바꿉니다. 정수는 정수로 유지됩니다.
   - **Null**, **제거**, **마스킹**(`***`).
   `_id`는 유지, 해시, 가짜 값(ObjectId 또는 UUID), 셔플, 제거(그러면 가져오기에서 새 값이 부여됨)만 가능합니다. 두 도큐먼트가 같은 `_id`를 갖게 되는 방식은 허용되지 않습니다.
   사람, 주소, 계정을 나타내는 필드(이름, 이메일, 전화번호, 거리, 우편번호, 생년월일, 비밀번호, IBAN 등)는 **가짜 값**으로 시작하고 나머지는 **유지**로 시작합니다.
2. **샘플에 없는 필드**: 이후 도큐먼트에는 있지만 샘플에는 없던 필드와 샘플에서 객체만 있던 곳에서 발견된 값은 기본적으로 제외됩니다. 원하면 유지할 수 있습니다.
3. 미리보기는 이전과 이후의 도큐먼트 5개를 보여 주며 변경할 때마다 갱신됩니다. **새 값**은 새로운 가짜 값, 셔플, 새 해시 키를 생성합니다.
4. **복사본 만들기**는 `_id` 순서로(MongoDB 정렬 순서대로 숫자가 ObjectId보다 앞서는 모든 종류의 `_id`) 페이지 단위로 최대 1,000개(개수는 직접 선택)의 도큐먼트를 읽고 페이지 안에서 익명화합니다. 복사본은 앱이 한 번에 받는 크기(약 1 MB)까지이며, 더 많으면 도큐먼트 단위로 잘리고 페이지에 그 사실이 표시됩니다.
5. 그다음에는 다음을 할 수 있습니다.
   - **NDJSON 저장** 또는 **JSON 저장**은 복사본을 파일로 저장합니다.
   - **가져오기…**는 같은 데이터베이스의 새 컬렉션(기본값 `<collection>_anonymised`)에 대해, 복사본을 파일로 하여 앱의 가져오기 마법사를 엽니다. 확인, 매핑, 시작은 그곳에서 합니다.

**설정 저장**은 각 필드의 방식을 JSON 파일로 저장합니다(해시 키나 값은 절대 저장하지 않습니다). **설정 불러오기**는 저장한 설정을 다시 적용합니다. 파일에 있지만 이 컬렉션에 없는 필드는 개수만 세고 건너뜁니다.

## 개인 데이터

개인 데이터 규칙에 의해 숨겨진 필드는 절대 유지되지 않습니다. 플러그인은 그 필드에 대해 `***`만 받았기 때문입니다. 마스킹, 가짜 값, null, 제거를 선택할 수 있으며, 샘플에 나타나지 않은 숨겨진 필드는 어디에 있든 마스킹됩니다. 컬렉션 자체는 절대 변경되지 않습니다. 복사본은 저장하거나 가져오기를 선택한 곳으로만 전달됩니다.

## 권한

- **도큐먼트 읽기:** 복사본을 만드는 데 쓰이는 도큐먼트입니다.
- **데이터베이스 읽기:** 데이터베이스의 다른 컬렉션을 위해 복사본을 가져오기 마법사에 전달합니다.
