# 지도

지도는 컬렉션의 도큐먼트가 어디에 있는지 자체 지도 위에 그려 줍니다. GeoJSON 도형(포인트, 선, 폴리곤과 이들의 컬렉션)과 예전 방식의 `[lng, lat]` 좌표 쌍을 지원합니다. 서로 가까운 포인트는 개수와 함께 하나로 묶이고, 도형을 클릭하면 해당 도큐먼트에 대한 카드가 열립니다.

이 플러그인은 읽기만 합니다. 데이터베이스에서는 아무것도 변경하지 않습니다.

## 표시되는 위치

- **컬렉션 탭:** 모든 컬렉션과 뷰에서 도큐먼트, 집계 등 다른 탭 옆에 **지도** 탭이 나타납니다.
- **도큐먼트 동작:** 도큐먼트 탭에서 도큐먼트 행의 동작 메뉴에 있는 **지도에 표시**는 그 도큐먼트 하나만 그립니다.
- **셀 값:** 도큐먼트 탭에서 GeoJSON 포인트 옆에 위치가 `lat, lng`(소수점 다섯 자리) 형식으로 표시됩니다. 예: `41.00820, 28.97840`.

## 사용 방법

컬렉션을 연 다음 **지도** 탭으로 이동합니다. 현재 도큐먼트 쿼리의 도큐먼트를 읽어 도형을 그리고, 지도는 그 도형에 맞게 자동으로 조정됩니다.

- 드래그하여 이동하고, 스크롤하거나 **확대**와 **축소**를 사용해 확대/축소하며, **도형에 맞추기**로 전체를 다시 볼 수 있습니다.
- 숫자가 있는 원은 서로 가까운 여러 장소를 묶은 것입니다. 클릭하면 확대합니다.
- 포인트나 도형을 클릭하면 카드가 열립니다. 도큐먼트의 이름, 몇 가지 필드, 그리고 앱에서 도큐먼트를 보여 주는 **열기**가 있습니다.
- 도큐먼트에 여러 필드(예: `pickup`과 `dropoff`)에 도형이 있을 때 **GeoJSON 필드**로 지도를 한 필드로 제한할 수 있습니다. **모든 필드**는 전부 보여 줍니다.
- **도형** 목록에는 그려진 항목(도큐먼트, 필드, 유형)이 나열됩니다. 키보드로 지도를 탐색하는 방법이기도 합니다. **지도에 표시**는 도형을 중앙에 놓고, **열기**는 해당 도큐먼트를 엽니다.

## 영역으로 필터링

필드 선택기 옆의 버튼 세 개로 영역을 기준으로 도큐먼트를 필터링합니다.

- **영역 그리기:** 지도를 클릭하여 꼭짓점을 추가합니다. 첫 번째 꼭짓점을 클릭하거나 더블 클릭 또는 Enter를 눌러 완료합니다. Backspace는 마지막 꼭짓점을 되돌리고, Esc는 포커스 위치와 관계없이 취소합니다.
- **원 그리기:** 중심을 클릭한 다음 가장자리를 클릭합니다. 움직이는 동안 반지름이 표시되며, 윤곽선은 지구 위에서의 원입니다(지도에서는 극 쪽으로 갈수록 넓어집니다).
- **보이는 영역으로 필터링:** 지도에 표시되는 세계의 부분입니다.

키보드로는 지도에 포커스가 있을 때 화살표 키로 이동하고, Space로 꼭짓점(또는 원의 중심, 그다음 가장자리)을 십자 표시가 있는 지도 중앙에 놓습니다. 사용 중인 도구를 다시 클릭하면 내려놓습니다. 다른 필드를 선택하면 그리던 작업이 중단됩니다.

영역 안에 도형이 있는 도큐먼트는 MongoDB의 `$geoWithin`으로 도큐먼트 쿼리에 들어갑니다. 각 변은 지도에 그린 선을 따릅니다. MongoDB는 두 꼭짓점을 지구상의 최단 경로로 잇는데, 이 경로는 극 쪽으로 휘어 있으므로 선을 따라 꼭짓점이 추가됩니다. 영역은 날짜 변경선을 넘을 수도 있습니다. GeoJSON 도형과 `[lng, lat]` 쌍 모두에 작동하며 인덱스가 필요 없습니다. Feature 안의 도형은 그 지오메트리로, FeatureCollection 안의 도형은 컬렉션의 feature로(도큐먼트의 도형 중 하나라도 들어 있으면 포함), 배열 안의 도형은 배열의 요소로 필터링됩니다. 한 필드가 도형을 이 방식 중 둘 이상으로 담고 있으면 필터는 각각을 모두 적용합니다. 어떤 필터로도 지정할 수 없는 키(점이나 `$`가 들어 있거나 비어 있는 키) 아래의 도형은 제외되며, 필터링하기 전에 도구 옆에 페이지가 이를 알려 줍니다.

영역은 사용 중인 도큐먼트 필터 옆에 추가됩니다. 다른 조건은 유지되고, 같은 필드에 이미 있던 영역(이전에 그린 것이나 직접 작성한 것)은 교체됩니다. 플러그인이 쿼리를 넣을 때와 마찬가지로 도큐먼트의 정렬과 프로젝션은 없음으로 되돌아갑니다. 변이 교차하거나, 맞닿거나, 되돌아가는 폴리곤, 또는 꼭짓점이 한 직선 위에 있는 폴리곤은 영역이 되지 않으며, 그 이유를 페이지가 알려 줍니다. 도큐먼트에 여러 필드의 도형이 있으면 먼저 필터링할 필드를 선택하세요. 페이지가 버튼 옆에서 이를 안내합니다. **지도에 표시**(도큐먼트 하나)에는 그리기 도구가 없습니다.

## 위치로 읽는 것

- 모든 필드의 GeoJSON 지오메트리: `Point`, `MultiPoint`, `LineString`, `MultiLineString`, `Polygon`, `MultiPolygon`, `GeometryCollection`.
- GeoJSON `Feature` 또는 `FeatureCollection`.
- 예전 방식의 `[lng, lat]` 쌍. MongoDB가 저장하는 대로 경도가 먼저입니다. 단, 장소를 뜻하는 이름의 필드에서만 읽습니다: `loc`, `location`, `coordinates`, `coords`, `position`, `pos`, `point`, `geo`, `lnglat`, `lonlat`, `center` 및 이들의 복수형이나 유사한 변형. 다른 곳의 숫자 두 개(버전, 크기 등)는 장소로 취급하지 않습니다. `latlng`라는 이름의 필드는 보통 위도가 먼저이므로 읽지 않습니다.

필드는 최대 여섯 단계 깊이까지, 배열 안에서도 찾습니다. 유효한 GeoJSON이 아닌 도형은 통째로 제외됩니다.

## 예시

`stores` 컬렉션:

```json
{ "_id": 1, "name": "Kadıköy", "location": { "type": "Point", "coordinates": [29.0275, 40.9903] } }
{ "_id": 2, "name": "Beşiktaş", "loc": [29.0094, 41.0422] }
```

둘 다 지도 탭에 나타납니다. 도큐먼트 탭에서는 첫 번째 도큐먼트의 `location` 셀에 값 옆으로 `40.99030, 29.02750`이 표시됩니다.

## 지도 타일

기본 상태에서는 지도 타일을 불러오지 않고 타일 서버에도 연결하지 않습니다. 지도는 경선과 위선 격자를 그리고, 관리자가 타일 서버를 설정할 수 있다는 안내가 표시됩니다. 타일 서버를 설정하면 도형이 실제 지도 타일 위에 그려집니다.

## 권한

- **도큐먼트 읽기**(`documents:read`): 현재 쿼리의 도큐먼트와 지도에 표시의 도큐먼트 하나를 읽기 위해 필요합니다.

읽기는 로그인한 사용자의 권한과 필드 마스킹을 적용하여 앱을 통해 이루어집니다. 플러그인은 다른 컬렉션을 읽을 수 없습니다.

## 설정

관리자가 플러그인 페이지에서 설정합니다. 플러그인을 사용하는 모든 사람이 볼 수 있으므로 비공개 API 키 같은 비밀은 절대 넣지 마세요.

- **타일 서버**(`tileUrl`): 래스터 타일용 http 또는 https 주소 템플릿입니다. `{z}`, `{x}`, `{y}`는 타일마다 채워지고, `{-y}`는 남쪽부터 행을 세며(TMS), `{s}`는 서브도메인(`a`, `b`, `c`)을 고르고, `{r}`은 비워 둡니다. 예: `https://tile.openstreetmap.org/{z}/{x}/{y}.png`(먼저 타일 제공자의 사용 정책을 확인하세요).
- **타일 크레딧**(`tileAttribution`): 지도에 표시되는 크레딧 문구로, 일반 텍스트입니다. 예: `© OpenStreetMap contributors`. 비어 있으면 타일 서버의 호스트 이름이 표시됩니다.

타일 서버의 호스트, 그리고 그 호스트만 플러그인 프레임이 불러올 수 있는 이미지에 추가됩니다. 자격 증명이 포함된 주소나 특이한 호스트는 거부됩니다.

## 한도

- 현재 쿼리의 처음 1,000개 도큐먼트까지만 `_id` 순서로, 앱의 1 MB 메시지 한도에 맞는 페이지 단위로 읽습니다. 더 있으면 요약에 “처음 1,000개 도큐먼트 기준”이라고 표시됩니다. 다른 도큐먼트를 보려면 도큐먼트 필터를 좁히세요.
- 도큐먼트 하나에서 최대 50개의 도형을 가져옵니다.
- 꼭짓점이 10,000개를 넘는 도형은 솎아 내어 그리고(n번째 점마다 유지, 양 끝은 유지), 멀티 도형은 최대 1,000개 부분까지 그립니다.
- 도형 목록에는 처음 200개 행이 표시됩니다.
- 확대는 19단계까지 가능하며, 맞추기는 15단계에서 멈춰 포인트 하나가 거리 수준으로 그려지지 않게 합니다.
- 지도는 웹 메르카토르 투영을 사용합니다. 북위 또는 남위 약 85도를 넘는 위도는 가장자리에 그려집니다.
