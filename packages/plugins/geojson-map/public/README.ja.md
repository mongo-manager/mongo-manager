# マップ

マップは、コレクションのドキュメントがどこにあるかを、専用のマップ上に描画します。対象は GeoJSON シェイプ（ポイント、ライン、ポリゴンとそれらのコレクション）と、従来の `[lng, lat]` 座標のペアです。近接するポイントは件数付きでクラスター表示され、シェイプをクリックするとそのドキュメントのカードが開きます。

このプラグインは読み取りのみを行います。データベースは一切変更しません。

## 表示される場所

- **コレクションタブ：** すべてのコレクションとビューで、ドキュメントや集計などのタブの隣に**マップ**タブが表示されます。
- **ドキュメントアクション：** ドキュメント画面で、ドキュメント行のアクションメニューにある**マップに表示**は、そのドキュメントだけを描画します。
- **セルの値：** ドキュメント画面で GeoJSON ポイントの隣に、位置が `lat, lng`（小数点以下 5 桁）で表示されます。例：`41.00820, 28.97840`

## 使い方

コレクションを開き、**マップ**タブに切り替えます。現在のドキュメントのクエリに該当するドキュメントが読み込まれ、シェイプが描画されます。マップは自動でそれらに合わせて表示されます。

- ドラッグで移動、スクロールまたは**ズームイン**と**ズームアウト**でズーム、**シェイプに合わせる**ですべてを表示し直します。
- 数字の入った円は、近接する複数の場所をまとめたものです。クリックするとズームインします。
- ポイントまたはシェイプをクリックするとカードが開きます。ドキュメント名、いくつかのフィールド、アプリでそのドキュメントを表示する**開く**が含まれます。
- ドキュメントが複数のフィールドにシェイプを持つ場合（例：`pickup` と `dropoff`）、**GeoJSON フィールド**でマップを 1 つのフィールドに絞り込めます。**すべてのフィールド**ではすべて表示します。
- **シェイプ**には描画されたもの（ドキュメント、フィールド、型）が一覧表示されます。キーボードでマップを操作する手段でもあり、**マップに表示**はシェイプを中央に表示し、**開く**はそのドキュメントを開きます。

## 領域でフィルターする

フィールド選択の隣にある 3 つのボタンで、ドキュメントを領域でフィルターできます。

- **フィルター用の領域を描く：** マップをクリックして頂点を追加します。最初の頂点をクリックするか、ダブルクリックまたは Enter で完了します。Backspace で直前の頂点を取り消し、Esc はフォーカスがどこにあっても中止します。
- **フィルター用の円を描く：** 中心をクリックし、次に端をクリックします。動かすと半径が表示され、輪郭は地球上での実際の輪郭です（マップ上では極に近いほど広くなります）。
- **表示中の領域でフィルター：** マップに表示されている範囲です。

キーボードの場合：マップにフォーカスがあるとき、矢印キーで移動し、Space で頂点（または円の中心、次に端）を、十字が表示されているマップの中央に置きます。使用中のツールをもう一度クリックすると解除され、別のフィールドを選ぶと描画が止まります。

領域内にシェイプがあるドキュメントは、MongoDB の `$geoWithin` でドキュメントのクエリに入ります。各辺はマップ上に描いた線に従います。MongoDB は 2 つの頂点を地球上の最短経路で結び、それは極の方へ膨らむため、辺に沿って頂点が追加されます。また、領域は 180 度経線をまたぐこともできます。GeoJSON シェイプにも `[lng, lat]` のペアにも使え、インデックスは不要です。Feature 内のシェイプはその geometry で、FeatureCollection 内のシェイプはコレクションの features で（いずれかのシェイプが領域内にあればそのドキュメントは対象）、配列内のシェイプは配列の要素でフィルターされます。1 つのフィールドがこれらの複数の形でシェイプを持つ場合、フィルターはそれぞれを対象にします。どのフィルターでも指定できないキー（ドットや `$` を含む、または空のキー）の下にあるシェイプは除外され、ページはフィルターする前にツールの隣でそのことを知らせます。

領域は、使用中のドキュメントのフィルターの隣に入ります。他の条件は保持され、同じフィールドにすでにある領域（以前の描画によるもの、または自分で書いたもの）は置き換えられます。プラグインがクエリを入れる場合と同様に、ドキュメントのソートとプロジェクションはなしに戻ります。辺が交差・接触・折り返すポリゴンや、頂点が一直線上にあるポリゴンは領域になりません。ページが理由を表示します。ドキュメントが複数のフィールドにシェイプを持つ場合は、先にフィルターするフィールドを選んでください。ページがボタンの隣で知らせます。**マップに表示**（1 件のドキュメント）には描画ツールはありません。

## 場所として読み取られるもの

- 任意のフィールドの GeoJSON ジオメトリ：`Point`、`MultiPoint`、`LineString`、`MultiLineString`、`Polygon`、`MultiPolygon`、`GeometryCollection`
- GeoJSON の `Feature` または `FeatureCollection`
- 従来の `[lng, lat]` ペア。MongoDB の保存形式どおり経度が先ですが、場所を表す名前のフィールドのみが対象です：`loc`、`location`、`coordinates`、`coords`、`position`、`pos`、`point`、`geo`、`lnglat`、`lonlat`、`center` と、その複数形や近い形。ほかの場所にある 2 つの数値（バージョンやサイズなど）は場所とは見なされません。`latlng` という名前のフィールドは、通常は緯度が先になるため読み取られません。

フィールドは 6 階層の深さまで、配列の中も含めて探索されます。有効な GeoJSON ではないシェイプは、まるごと除外されます。

## 例

`stores` コレクション：

```json
{ "_id": 1, "name": "Kadıköy", "location": { "type": "Point", "coordinates": [29.0275, 40.9903] } }
{ "_id": 2, "name": "Beşiktaş", "loc": [29.0094, 41.0422] }
```

どちらも「マップ」タブに表示されます。ドキュメント画面では、1 件目の `location` セルの値の隣に `40.99030, 29.02750` が表示されます。

## マップタイル

初期状態では、マップタイルは読み込まれず、タイルサーバーにも接続しません。マップは経線と緯線のグリッドを描画し、管理者がタイルサーバーを設定できることを示すメモが表示されます。タイルサーバーを設定すると、シェイプは実際のマップタイルの上に描画されます。

## 権限

- **ドキュメントの読み取り**（`documents:read`）：現在のクエリのドキュメントと、マップに表示する 1 件のドキュメントを読み取るために使います。

読み取りはアプリを介し、サインインしているユーザーの権限とフィールドのマスキングに従って行われます。このプラグインはほかのコレクションを読み取れません。

## 設定

管理者がプラグインのページで設定します。プラグインを使うすべての人が見られるため、ここに秘密情報（非公開の API キーなど）を入れないでください。

- **タイルサーバー**（`tileUrl`）：ラスタータイル用の http または https のアドレステンプレート。`{z}`、`{x}`、`{y}` はタイルごとに埋められ、`{-y}` は行を南から数え（TMS）、`{s}` はサブドメイン（`a`、`b`、`c`）を選び、`{r}` は空になります。例：`https://tile.openstreetmap.org/{z}/{x}/{y}.png`（先にタイル提供元の利用規約を確認してください）。
- **タイルのクレジット**（`tileAttribution`）：マップに表示されるクレジット行で、プレーンテキストです。例：`© OpenStreetMap contributors`。空の場合は、タイルサーバーのホスト名が表示されます。

タイルサーバーのホスト（そのホストのみ）が、プラグインのフレームが読み込める画像の許可先に追加されます。認証情報を含むアドレスや、通常とは異なるホストは拒否されます。

## 制限

- 現在のクエリの最初の 1,000 件までのドキュメントが、`_id` 順に、アプリの 1 MB のメッセージ上限に収まるページ単位で読み取られます。それより多い場合、概要に「最初の 1,000 件のドキュメントから」と表示されます。ほかのドキュメントを見るには、ドキュメントのフィルターを絞り込んでください。
- 1 件のドキュメントから取り込まれるシェイプは最大 50 個です。
- 頂点が 10,000 を超えるシェイプは間引いて描画され（n 個ごとに 1 点を残し、両端は保持）、複数パーツのシェイプは最大 1,000 パーツまで描画されます。
- シェイプ一覧には最初の 200 行が表示されます。
- ズームはレベル 19 まで可能です。1 つのポイントが街路レベルで描画されないよう、フィットはレベル 15 で止まります。
- マップは Web メルカトル図法を使います。北緯・南緯約 85 度を超える緯度は端に描画されます。
