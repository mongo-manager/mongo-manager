# 搜索实验台

Atlas Search 和 Vector Search 能回答普通索引无法回答的查询：带拼写错误的词、相关度得分、高亮的匹配结果，以及嵌入向量与查询向量相近的文档。要查看某个索引的效果，手写 `$search` 或 `$vectorSearch` 阶段相当耗时；Atlas 的 Search Tester 和 Compass 的搜索索引视图只需几次点击即可试用。搜索实验台为集合的搜索索引提供同样的功能。

## 使用方法

打开一个集合及其 **搜索** 标签页。它会列出集合的搜索索引，每个索引都标明类型（全文或向量）和状态；尚不可查询的索引（正在构建、已失败）会被标记，且无法运行。

### 全文

- **搜索内容**：要搜索的词。
- **范围**：索引映射的某个文本字段，或 **所有字段**（动态索引的所有字段，否则为其映射的所有文本字段）。
- **允许的拼写错误**：无、一个字符或两个字符（`fuzzy`）。
- **高亮**：匹配的段落，并标出匹配的词。
- **结果数**：1 到 100。

### 向量

- **向量字段**：索引的某个向量字段，并显示其维度。
- **向量**：粘贴的查询向量（`[0.1, 0.2, …]`，或以逗号或空格分隔的数字），或 **类似某个文档**：集合前 20 个文档之一，用其自身的向量查找与之相似的文档——可以是数字列表，也可以是 float32 或 int8 值的 BSON 向量（二进制子类型 9）。向量必须具有索引所要求的维度。
- **候选数**：MongoDB 考虑的最近邻数量（不少于结果数，最多 10,000）。
- **筛选**：作用于索引筛选字段的 JSON 对象，例如 `{ "year": { "$gte": 2000 } }`。

**搜索** 会运行管道；每条结果显示其得分、高亮和字段。**在聚合中使用** 会把管道交给聚合编辑器，您可以在其中添加阶段并保存。

## 所需条件

搜索索引存在于 Atlas，以及配置了 MongoDB Search（`mongot`）、且版本在 MongoDB 文档所列范围内的自行管理 MongoDB。未启用搜索或集合没有搜索索引时，标签页会给出提示；请在集合的“索引”页面创建索引。

## 安全

应用以您的身份、只读方式运行管道，搜索阶段在最前，且不包含任何写入、联接其他集合或运行代码的内容。高亮以文本形式显示，绝不作为标记。因个人数据而对您隐藏的字段不会提供；对于被隐藏个人数据的用户，凡规则所及之处都会拒绝搜索（搜索可能通过结果泄露被隐藏的值）：标签页会在搜索前说明这一点。

## 权限

- **读取文档：** 搜索结果，以及用于提取向量的文档。
- **读取集合详情：** 集合的搜索索引——其名称、状态和所映射的字段，绝不包含被隐藏的字段。
