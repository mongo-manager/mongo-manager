# 검색 플레이그라운드

Atlas Search와 Vector Search는 일반 인덱스로는 답할 수 없는 쿼리에 대응합니다. 오타가 있는 단어, 관련도 점수, 강조 표시된 일치 항목, 임베딩이 쿼리와 가까운 도큐먼트 등입니다. 인덱스가 무엇을 반환하는지 확인하려고 `$search` 또는 `$vectorSearch` 스테이지를 직접 작성하는 일은 시간이 많이 듭니다. Atlas의 Search Tester와 Compass의 검색 인덱스 보기를 사용하면 몇 번의 클릭으로 시험해 볼 수 있습니다. 검색 플레이그라운드는 컬렉션의 검색 인덱스에 대해 같은 일을 합니다.

## 사용 방법

컬렉션을 열고 **검색** 탭을 선택합니다. 컬렉션의 검색 인덱스가 종류(전체 텍스트 또는 벡터)와 상태와 함께 나열됩니다. 아직 쿼리할 수 없는 인덱스(구축 중, 실패)에는 표시가 붙으며 실행할 수 없습니다.

### 전체 텍스트

- **검색어**: 찾을 단어.
- **검색 대상**: 인덱스가 매핑한 텍스트 필드 중 하나 또는 **모든 필드**(동적 인덱스는 모든 필드, 그렇지 않으면 매핑된 모든 텍스트 필드).
- **허용할 오타**: 없음, 1글자 또는 2글자(`fuzzy`).
- **강조 표시**: 일치한 구절을 일치한 단어에 표시를 붙여 보여 줍니다.
- **결과 수**: 1에서 100.

### 벡터

- **벡터 필드**: 인덱스의 벡터 필드 중 하나이며, 차원 수가 함께 표시됩니다.
- **벡터**: 붙여넣은 쿼리 벡터(`[0.1, 0.2, …]` 또는 쉼표나 공백으로 구분한 숫자), 또는 **도큐먼트와 유사**: 컬렉션의 처음 20개 도큐먼트 중 하나이며, 그 도큐먼트 자체의 벡터로 유사한 도큐먼트를 찾습니다. 숫자 목록 또는 float32나 int8 값으로 된 BSON 벡터(바이너리 서브타입 9)를 사용할 수 있습니다. 벡터는 인덱스의 차원 수와 일치해야 합니다.
- **후보 수**: MongoDB가 고려하는 최근접 이웃의 수(결과 수 이상, 최대 10,000).
- **필터**: 인덱스의 필터 필드에 대한 JSON 객체. 예: `{ "year": { "$gte": 2000 } }`.

**검색**은 파이프라인을 실행하며, 각 결과에는 점수, 강조 표시, 필드가 표시됩니다. **집계에서 사용**을 누르면 파이프라인이 집계 편집기로 전달되어 스테이지를 추가하고 저장할 수 있습니다.

## 필요한 환경

검색 인덱스는 Atlas와, MongoDB 문서에 나온 지원 버전에서 MongoDB Search(`mongot`)를 설정한 자체 관리 MongoDB에 있습니다. 검색이 활성화되어 있지 않거나 컬렉션에 검색 인덱스가 없으면 탭에 그 사실이 표시됩니다. 컬렉션의 인덱스 페이지에서 만드세요.

## 안전

앱은 사용자 권한으로 읽기 전용으로 검색 스테이지를 맨 앞에 둔 파이프라인을 실행하며, 쓰기, 다른 컬렉션과의 조인, 코드 실행을 하는 것은 포함되지 않습니다. 강조 표시는 텍스트로 표시되며 마크업으로 처리되지 않습니다. 개인 데이터로 숨겨진 필드는 제시되지 않으며, 개인 데이터가 숨겨진 사용자는 규칙이 미치는 범위에서 검색이 거부됩니다(검색 결과로 숨겨진 값을 유추할 수 있기 때문입니다). 탭은 검색하기 전에 이 사실을 알려 줍니다.

## 권한

- **도큐먼트 읽기:** 검색 결과와 벡터를 가져오는 도큐먼트.
- **컬렉션 세부 정보 읽기:** 컬렉션의 검색 인덱스. 이름, 상태, 매핑된 필드이며 숨겨진 필드는 포함되지 않습니다.
