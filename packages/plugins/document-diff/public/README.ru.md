# Сравнение документов

Сравнение документов сопоставляет один документ с другим документом той же коллекции поле за полем и перечисляет, что было добавлено, удалено или изменено. Вложенные объекты сравниваются по полям, а массивы по элементам, поэтому изменение в глубине документа показывается по собственному пути.

Плагин только читает. Он ничего не меняет в базе данных.

## Где он появляется

- **Действие документа:** **Сравнить с…** в меню действий строки документа в разделе «Документы». Открывается в диалоговом окне поверх коллекции.

## Как пользоваться

1. В разделе «Документы» откройте меню документа, который хотите сравнить, и выберите **Сравнить с…**. Этот документ окажется **слева**.
2. Укажите сторону **справа**: введите её `_id` в поле или выберите документ в списке **Или один из этой коллекции**.
3. Нажмите **Сравнить**.

Результат начинается со сводки (сколько полей изменено, только слева, только справа или без изменений) и перечисляет изменённые поля. Переключатель **Какие поля** переключает режимы **Только изменения** и **Все поля**. **Поменять стороны** меняет левую и правую стороны местами. **Копировать изменения как JSON** копирует список изменений в буфер обмена.

## Ввод _id

Поле понимает введённое так, как вы это имеете в виду:

- 24 шестнадцатеричные цифры — это ObjectId: `652f1c0e9b1e8a3d4c5b6a79`
- целое число — это число (int, а если оно больше — long): `1042`
- десятичное число — это double: `3.5`
- текст, начинающийся с `{`, `[` или двойной кавычки, читается как Extended JSON: `{ "$uuid": "…" }` или `"A-100"`
- всё остальное — строка: `A-100`

## Пример

Слева:

```json
{ "_id": 1, "name": "Ada", "tags": ["a", "b"], "address": { "city": "Ankara" } }
```

Справа:

```json
{ "_id": 2, "name": "Ada", "tags": ["a", "c"], "address": { "city": "İzmir", "zip": "35000" } }
```

Сравнение покажет, что `tags.1` изменилось с `"b"` на `"c"`, `address.city` изменилось, а `address.zip` есть только справа; `name` совпадает. Поля `_id` не учитываются: у двух документов они всегда различаются.

## Как сравниваются значения

- Объекты сравниваются по полям, массивы по индексу (позиции 0, 1, 2…).
- Любое другое значение сравнивается целиком, по его Extended JSON. Число, сохранённое как int с одной стороны и как double с другой, считается изменением, как и строка `"5"` в сравнении с числом `5`.
- Каждая строка называет свой тип словами (Изменено, Только слева, Только справа, Совпадает), а не только цветом.

## Разрешения

- **Чтение документов** (`documents:read`): чтобы прочитать два документа и получить список документов коллекции для выбора.

Чтение идёт через приложение с правами вошедшего пользователя и маскированием полей. Плагин не может читать другие коллекции.

## Настройки

Нет.

## Ограничения

- Оба документа должны быть в одной коллекции.
- Список выбора содержит до 50 документов текущего запроса в разделе «Документы» (сам документ исключён); каждый назван по первому из полей `name`, `title`, `label`, `displayName`, `fullName`, `username`, `email`, `code` и `slug`. Любой другой документ можно сравнить, введя его `_id`.
- Вложенность отслеживается на глубину до 100 уровней; глубже значение сравнивается целиком.
- Длинные значения сокращаются в таблице; наведите на значение курсор, чтобы увидеть больше (до 2 000 символов).
- Если левый документ был удалён после открытия меню, диалоговое окно сообщает об этом и ничего не сравнивает.
