# 文档比较

文档比较会把一个文档与同一集合中的另一个文档逐字段比较，并列出新增、删除或更改了什么。嵌套对象按字段比较，数组按元素比较，因此文档深处的更改会显示在它自己的路径上。

该插件只读取，不会更改数据库中的任何内容。

## 出现的位置

- **文档操作：** 在“文档”中，文档行的操作菜单里的 **与…比较**。它会在集合上方的对话框中打开。

## 如何使用

1. 在“文档”中，打开要比较的文档的菜单，选择 **与…比较**。该文档是 **左** 侧。
2. 指定 **右** 侧：在输入框中输入它的 `_id`，或从 **或选择此集合中的一个** 中选取一个。
3. 点击 **比较**。

结果以摘要开头（多少个字段已更改、仅在左侧、仅在右侧或相同），并列出已更改的字段。**显示哪些字段** 可在 **仅差异** 和 **所有字段** 之间切换。**交换两侧** 会对调左右两侧。**将差异复制为 JSON** 会把差异列表复制到剪贴板。

## 输入 _id

输入框会按你的本意来理解所输入的内容：

- 24 位十六进制数字是 ObjectId：`652f1c0e9b1e8a3d4c5b6a79`
- 整数是数字（int；更大时为 long）：`1042`
- 小数是 double：`3.5`
- 以 `{`、`[` 或双引号开头的文本按 Extended JSON 读取：`{ "$uuid": "…" }` 或 `"A-100"`
- 其他任何内容都是字符串：`A-100`

## 示例

左：

```json
{ "_id": 1, "name": "Ada", "tags": ["a", "b"], "address": { "city": "Ankara" } }
```

右：

```json
{ "_id": 2, "name": "Ada", "tags": ["a", "c"], "address": { "city": "İzmir", "zip": "35000" } }
```

比较结果会列出：`tags.1` 从 `"b"` 变为 `"c"`，`address.city` 已更改，`address.zip` 仅在右侧；`name` 相同。`_id` 字段不参与比较：两个文档在这里总是不同的。

## 值如何比较

- 对象按字段比较，数组按索引比较（位置 0、1、2…）。
- 其他任何值都按其 Extended JSON 整体比较。一侧存储为 int、另一侧为 double 的数字算作更改，字符串 `"5"` 与数字 `5` 也一样。
- 每一行都用文字标明其类型（已更改、仅在左侧、仅在右侧、相同），而不仅仅依靠颜色。

## 权限

- **读取文档**（`documents:read`）：用于读取这两个文档，并列出集合中可供选择的文档。

读取通过应用进行，使用已登录用户的权限和字段掩码。该插件无法读取其他集合。

## 设置

无。

## 限制

- 两个文档必须在同一集合中。
- 选择列表最多包含当前“文档”查询中的 50 个文档（不含文档自身），以其在 `name`、`title`、`label`、`displayName`、`fullName`、`username`、`email`、`code` 和 `slug` 中的第一个字段命名。其他任何文档都可以通过输入其 `_id` 来比较。
- 嵌套最多跟踪 100 层；更深的值按整体比较。
- 较长的值在表格中会被截短；将鼠标悬停在上面可看到更多内容（最多 2,000 个字符）。
- 如果菜单打开后左侧文档已被删除，对话框会提示这一点，并且不进行任何比较。
