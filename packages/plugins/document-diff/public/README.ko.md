# 도큐먼트 비교

도큐먼트 비교는 도큐먼트 하나를 같은 컬렉션의 다른 도큐먼트와 필드 단위로 비교하여 추가, 삭제, 변경된 내용을 나열합니다. 중첩 객체는 필드별로, 배열은 요소별로 비교하므로 도큐먼트 깊숙한 곳의 변경도 해당 경로에 표시됩니다.

이 플러그인은 읽기만 합니다. 데이터베이스는 어떤 것도 변경하지 않습니다.

## 표시되는 위치

- **도큐먼트 동작:** 도큐먼트 목록에서 도큐먼트 행의 동작 메뉴에 있는 **다음과 비교…**. 컬렉션 위의 대화 상자로 열립니다.

## 사용 방법

1. 도큐먼트 목록에서 비교할 도큐먼트의 메뉴를 열고 **다음과 비교…**를 선택합니다. 이 도큐먼트가 **왼쪽**이 됩니다.
2. **오른쪽**을 지정합니다. 입력란에 `_id`를 입력하거나 **또는 이 컬렉션의 도큐먼트 중 선택**에서 하나를 고릅니다.
3. **비교**를 누릅니다.

결과는 요약(변경됨, 왼쪽에만 있음, 오른쪽에만 있음, 동일한 필드 수)으로 시작하고 변경된 필드를 나열합니다. **표시할 필드**로 **변경 사항만**과 **모든 필드** 보기를 전환합니다. **좌우 바꾸기**는 왼쪽과 오른쪽을 맞바꿉니다. **변경 사항을 JSON으로 복사**는 변경 목록을 클립보드에 복사합니다.

## _id 입력하기

입력란은 입력한 내용을 의도한 대로 해석합니다.

- 16진수 24자리는 ObjectId입니다: `652f1c0e9b1e8a3d4c5b6a79`
- 정수는 숫자입니다(int, 더 크면 long): `1042`
- 소수는 double입니다: `3.5`
- `{`, `[` 또는 큰따옴표로 시작하는 텍스트는 Extended JSON으로 읽습니다: `{ "$uuid": "…" }` 또는 `"A-100"`
- 그 외는 모두 문자열입니다: `A-100`

## 예시

왼쪽:

```json
{ "_id": 1, "name": "Ada", "tags": ["a", "b"], "address": { "city": "Ankara" } }
```

오른쪽:

```json
{ "_id": 2, "name": "Ada", "tags": ["a", "c"], "address": { "city": "İzmir", "zip": "35000" } }
```

비교 결과에는 `tags.1`이 `"b"`에서 `"c"`로 변경됨, `address.city` 변경됨, `address.zip`은 오른쪽에만 있음이 나열되며 `name`은 동일합니다. `_id` 필드는 제외됩니다. 두 도큐먼트는 이 필드에서 항상 다르기 때문입니다.

## 값을 비교하는 방식

- 객체는 필드별로, 배열은 인덱스별(위치 0, 1, 2…)로 비교합니다.
- 그 밖의 값은 Extended JSON 형태로 통째로 비교합니다. 한쪽에는 int, 다른 쪽에는 double로 저장된 숫자는 변경으로 취급하며, 문자열 `"5"`와 숫자 `5`도 마찬가지입니다.
- 각 행은 색상뿐 아니라 글자로도 종류(변경됨, 왼쪽에만 있음, 오른쪽에만 있음, 동일)를 나타냅니다.

## 권한

- **도큐먼트 읽기** (`documents:read`): 두 도큐먼트를 읽고, 선택할 수 있도록 컬렉션의 도큐먼트를 나열하기 위해 필요합니다.

읽기는 앱을 통해 로그인한 사용자의 권한과 필드 마스킹을 적용하여 이루어집니다. 플러그인은 다른 컬렉션을 읽을 수 없습니다.

## 설정

없음.

## 제한 사항

- 두 도큐먼트는 같은 컬렉션에 있어야 합니다.
- 선택 목록에는 현재 도큐먼트 목록 쿼리의 도큐먼트가 최대 50개까지 표시되며(해당 도큐먼트 자신은 제외), 각 도큐먼트는 `name`, `title`, `label`, `displayName`, `fullName`, `username`, `email`, `code`, `slug` 중 처음 나오는 필드로 이름이 붙습니다. 다른 도큐먼트는 `_id`를 직접 입력하여 비교할 수 있습니다.
- 중첩은 100단계까지 따라갑니다. 그보다 깊은 값은 통째로 비교합니다.
- 긴 값은 표에서 줄여서 표시되며, 마우스를 올리면 더 볼 수 있습니다(최대 2,000자).
- 메뉴를 연 뒤 왼쪽 도큐먼트가 삭제된 경우 대화 상자가 이를 알리고 아무것도 비교하지 않습니다.
