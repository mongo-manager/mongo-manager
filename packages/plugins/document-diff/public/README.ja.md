# ドキュメント比較

ドキュメント比較は、あるドキュメントを同じコレクションの別のドキュメントとフィールドごとに比較し、追加・削除・変更された内容を一覧にします。ネストされたオブジェクトはフィールド単位、配列は要素単位で比較されるため、ドキュメントの深い場所での変更もそのパスに表示されます。

このプラグインは読み取りのみを行います。データベースは一切変更しません。

## 表示される場所

- **ドキュメントアクション:** 「ドキュメント」でドキュメント行のアクションメニューにある **…と比較**。コレクションの上のダイアログで開きます。

## 使い方

1. 「ドキュメント」で、比較したいドキュメントのメニューを開き、**…と比較** を選びます。そのドキュメントが **左** 側になります。
2. **右** 側を指定します。ボックスに `_id` を入力するか、**またはこのコレクションから選択** から選びます。
3. **比較** を押します。

結果は概要（変更されたフィールド、左のみ、右のみ、同一のフィールドの数）から始まり、変更されたフィールドが一覧表示されます。**表示するフィールド** で **差分のみ** と **すべてのフィールド** を切り替えられます。**左右を入れ替え** は左と右を入れ替えます。**差分を JSON としてコピー** は差分の一覧をクリップボードにコピーします。

## _id の入力

ボックスは、入力した内容を意図どおりに解釈します。

- 16 進数 24 桁は ObjectId です: `652f1c0e9b1e8a3d4c5b6a79`
- 整数は数値です（int、より大きい場合は long）: `1042`
- 小数は double です: `3.5`
- `{`、`[`、またはダブルクォートで始まるテキストは Extended JSON として読み取られます: `{ "$uuid": "…" }` や `"A-100"`
- それ以外は文字列です: `A-100`

## 例

左:

```json
{ "_id": 1, "name": "Ada", "tags": ["a", "b"], "address": { "city": "Ankara" } }
```

右:

```json
{ "_id": 2, "name": "Ada", "tags": ["a", "c"], "address": { "city": "İzmir", "zip": "35000" } }
```

比較では、`tags.1` が `"b"` から `"c"` に変更、`address.city` が変更、`address.zip` が右のみ、と一覧表示されます。`name` は同一です。`_id` フィールドは対象外です。2 つのドキュメントでは、ここは常に異なるためです。

## 値の比較方法

- オブジェクトはフィールド単位、配列はインデックス単位（位置 0、1、2…）で比較します。
- その他の値は、Extended JSON としてまるごと比較します。片側が int、もう片側が double として保存された数値は変更として扱われ、文字列 `"5"` と数値 `5` も同様です。
- 各行は、色だけでなく文字でも種類（変更あり、左のみ、右のみ、同一）を示します。

## 権限

- **ドキュメントの読み取り**（`documents:read`）: 2 つのドキュメントを読み取り、選択用にコレクションのドキュメントを一覧表示するために使います。

読み取りはアプリを通じて、サインインしているユーザーの権限とフィールドマスキングに従って行われます。このプラグインは他のコレクションを読み取れません。

## 設定

なし。

## 制限

- 両方のドキュメントが同じコレクションにある必要があります。
- 選択リストには、現在の「ドキュメント」クエリの結果から最大 50 件（そのドキュメント自身を除く）が入り、`name`、`title`、`label`、`displayName`、`fullName`、`username`、`email`、`code`、`slug` のうち最初に見つかったフィールドで表示されます。それ以外のドキュメントは `_id` を入力して比較できます。
- ネストは 100 階層まで追跡します。それより深い値はまるごと比較します。
- 長い値は表内で省略されます。マウスを重ねると、より多く（最大 2,000 文字）表示されます。
- メニューを開いた後で左のドキュメントが削除された場合、ダイアログがその旨を表示し、何も比較しません。
