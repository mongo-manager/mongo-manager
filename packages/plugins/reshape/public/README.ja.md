# リシェイプ

アプリケーションが成長するにつれて、コレクションの形も変わります。`fullName` が `name.full` になったり、`address` オブジェクトがレポート用のフラットな列になったり、テキストで保存された価格を数値にする必要が出たりします。リシェイプはこうした変更をステップとして組み立て、お手元のドキュメントで結果を示し、パイプラインとして集計に渡します。移行スクリプトは不要で、コレクションにも触れません。Studio 3T（「Reschema」）と NoSQLBooster（「Collection re-schema tool」）にも同様の機能があります。

## 使い方

1. コレクションを開き、**リシェイプ**タブを開きます。フィールドを把握するため、50 件のドキュメントをサンプルとして読み込みます。
2. **ステップ**を順番に追加します。
   - **名前変更または移動：** 新しい名前を指定します。`a.b` はフィールドをオブジェクト内へ移動します。
   - **オブジェクトをフラット化：** `address.city` が `address_city` になります（区切り文字は自由に指定できますが、`.` と `$` は使えません）。オブジェクトから出るのは移動したキーだけです。サンプルに現れなかったキーはオブジェクトに残り、オブジェクトでない値はそのまま残り、移動の結果空になったオブジェクトは削除されます（元から空だったものは残ります）。
   - **オブジェクトにネスト：** リストでチェックしたフィールドを新しいフィールドの下にまとめ（`lat`、`lng` → `location`）、既存の内容は置き換えられます。同じ名前で終わる 2 つのフィールドは一方が失われるため拒否され、フィールドとその内側のフィールドの組み合わせも拒否されます。
   - **型を変換：** int、long、double、decimal、string、date、bool、ObjectId に変換します。変換できない値は null になるか、そのまま残ります。欠落しているフィールドは欠落のまま、null は null のままです。
   - **欠落時のデフォルト値**（または**欠落または null 時**）：欠落しているフィールド、または欠落もしくは null のフィールドに値を設定します。どちらにするかはお選びいただけ、ステップの名前もそれに応じて決まります。
   - **削除**、**テキストをリストに分割**、**リストをテキストに結合**（オブジェクトなどテキストにできない要素は、空として結合されます）。
3. **プレビュー**は、編集が止まった後に、同じ 5 件のサンプルドキュメントの変更前と変更後を MongoDB 自身の実行結果で表示します。既存のフィールドを上書きするステップはその旨を表示し、ドキュメントのリストの内側に書き込むステップは、値がそれぞれのドキュメントに設定されることを表示します。問題のあるステップは問題の内容を表示し、ステージからは除外されます。名前がまだ指定されていないステップは未完了として数えられ、完了するまで除外されます。
4. プレビューされ、渡されるステージは最大 48 個です。それを超えると、変更後が表示されない理由がプレビューに表示されます。
5. **集計で使用**はステージを渡します（アプリが先に確認します）。結果を書き込むには、集計で新しいコレクションを指定した `$out` ステージを追加してください。集計が書き込みの内容を表示し、実行前に確認します。**ステージをコピー**はステージをクリップボードに入れます。

## 決して行わないこと

- コレクションを変更しません。読み取り専用の `$set` と `$unset` ステージを組み立てるだけで、自身が `$out` や `$merge` を組み立てることはありません。
- `_id` は名前変更、移動、削除されません。個人データとして非表示になっているフィールドと、それを含むオブジェクトは表示されません。入力した名前によるものも含め、それらを読み取り、移動、書き込み、削除するステップは拒否されます。サンプルで値としてしか現れなかったフィールドは、ルールがその配下のフィールドを名前そのもの（`profile.ssn`）で指定している場合は保留されますが、ルールが `*`（`*.ssn`）経由で到達する場合は保留されません。そうしないと使えるフィールドが残らなくなるためです。非表示のフィールドをアプリが時間内に判定できなかった場合は、**再試行**で判定されるまでフィールドは表示されません。
- フィールドに使えない名前（空、`$` を含む、`a..b`）は拒否され、フィールド自身の中への移動も拒否されます。
- デフォルト値や区切り文字は常に値として扱われ、フィールドや演算子として解釈されることはありません。

## 権限

- **ドキュメントの読み取り：** フィールドを把握するためのサンプルとプレビューのドキュメント。お客様の権限で読み取られ、非表示のフィールドは非表示のままです。
