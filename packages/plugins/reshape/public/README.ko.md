# 재구성

애플리케이션이 성장하면 컬렉션의 구조도 바뀝니다. `fullName`이 `name.full`이 되고, `address` 객체가 보고서용 평면 열이 되고, 텍스트로 저장된 가격이 숫자여야 하게 됩니다. 재구성은 이런 변경을 단계로 구성하고, 사용자의 도큐먼트에서 결과를 보여 주며, 파이프라인으로 집계에 넘깁니다. 마이그레이션 스크립트도 필요 없고 컬렉션을 건드리지도 않습니다. Studio 3T("Reschema")와 NoSQLBooster("Collection re-schema tool")도 같은 기능을 제공합니다.

## 사용 방법

1. 컬렉션을 열고 **재구성** 탭으로 이동합니다. 필드를 파악하기 위해 도큐먼트 50개의 샘플을 읽습니다.
2. **단계**를 순서대로 추가합니다.
   - **이름 변경 또는 이동:** 새 이름을 지정합니다. `a.b`는 필드를 객체 안으로 이동합니다.
   - **객체 평탄화:** `address.city`가 `address_city`가 됩니다(구분자는 직접 정하며 `.`과 `$`는 쓸 수 없습니다). 이동한 키만 객체에서 빠집니다. 샘플에 나타나지 않은 키는 객체에 남고, 객체가 아닌 값은 그대로 남으며, 이동 후 비게 된 객체는 사라집니다(원래부터 비어 있던 객체는 남습니다).
   - **객체로 중첩:** 목록에서 선택한 필드를 새 필드 아래로 모읍니다(`lat`, `lng` → `location`). 이미 있던 내용은 대체됩니다. 같은 이름으로 끝나는 두 필드는 하나가 사라지므로 거부되며, 필드와 그 안의 필드도 거부됩니다.
   - **유형 변환:** int, long, double, decimal, string, date, bool, ObjectId로 변환합니다. 변환할 수 없는 값은 null이 되거나 그대로 유지됩니다. 없는 필드는 없는 채로, null은 null인 채로 남습니다.
   - **없을 때 기본값**(또는 **없거나 null일 때**): 없는 필드, 또는 없거나 null인 필드에 넣을 값입니다. 선택은 사용자가 하며 단계 이름에도 반영됩니다.
   - **삭제**, **텍스트를 목록으로 분할**, **목록을 텍스트로 결합**(객체처럼 텍스트가 될 수 없는 요소는 빈 값으로 결합됩니다).
3. **미리 보기**는 편집을 멈추면 같은 샘플 도큐먼트 다섯 개를 변경 전후로 보여 주며, MongoDB가 직접 실행합니다. 이미 있는 필드를 덮어쓰는 단계는 그렇다고 알려 주고, 도큐먼트 목록 안에 쓰는 단계는 값이 각 도큐먼트에 설정된다고 알려 줍니다. 문제가 있는 단계는 무엇이 문제인지 알려 주고 스테이지에서 제외됩니다. 아직 이름이 지정되지 않은 단계는 완료되지 않은 것으로 집계되며 완료될 때까지 제외됩니다.
4. 미리 보기와 전달은 최대 48개 스테이지까지 가능합니다. 이를 넘으면 미리 보기가 이후 결과를 표시하지 않는 이유를 알려 줍니다.
5. **집계에서 사용**은 스테이지를 집계로 넘깁니다(앱이 먼저 확인합니다). 결과를 쓰려면 집계에서 새 컬렉션 이름을 지정한 `$out` 스테이지를 추가하세요. 집계가 쓰기 동작을 보여 주고 실행 전에 확인합니다. **스테이지 복사**는 스테이지를 클립보드에 복사합니다.

## 하지 않는 일

- 컬렉션을 변경하지 않습니다. 읽기 전용 `$set` 및 `$unset` 스테이지를 만들 뿐이며 `$out`이나 `$merge`는 직접 만들지 않습니다.
- `_id`의 이름 변경, 이동, 삭제는 하지 않습니다. 개인 데이터로 숨겨진 필드와 이를 포함한 객체는 제안되지 않으며, 직접 입력한 이름을 통하더라도 이런 필드를 읽거나 이동하거나 쓰거나 삭제하는 단계는 거부됩니다. 샘플에서 값으로만 확인된 필드는 규칙이 그 아래 필드를 자체 이름으로 지정할 때(`profile.ssn`) 제외되지만, 규칙이 `*`를 통해 도달할 때(`*.ssn`)는 제외되지 않습니다. 그러면 필드가 하나도 남지 않기 때문입니다. 앱이 어떤 필드가 숨겨져 있는지 제때 알 수 없으면 **다시 시도**로 확인될 때까지 필드를 제안하지 않습니다.
- 필드가 가질 수 없는 이름(빈 이름, `$` 포함, `a..b`)은 거부되며, 자기 자신 안으로 이동하는 필드도 거부됩니다.
- 기본값이나 구분자는 항상 값으로만 취급되며 필드나 연산자로 해석되지 않습니다.

## 권한

- **도큐먼트 읽기:** 필드를 파악하기 위한 샘플과 미리 보기의 도큐먼트입니다. 사용자의 권한이 적용되며 숨겨진 필드는 보이지 않습니다.
