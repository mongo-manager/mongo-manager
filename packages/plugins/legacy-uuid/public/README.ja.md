# 旧形式 UUID

MongoDB に標準の UUID 型（バイナリのサブタイプ 4）がなかった頃、ドライバーは UUID をバイナリのサブタイプ 3 として、それぞれ独自のバイト順で保存していました。Java ドライバーはバイト列の前半と後半をそれぞれ反転し、C# ドライバー（.NET の `Guid`）は最初の 3 つのグループを反転し、Python ドライバーは順序をそのまま保ちました。そのため同じ 16 バイトが 3 通りの UUID として読めてしまい、UUID を検索するときは、それを保存したドライバーの順序で書く必要があります。このプラグインは、あらゆる順序でそれらを読み取り、フィールドがどの順序で書き込まれたかを判定し、どの形式で保存された UUID も検索します。

プラグインは読み取りのみを行います。データベースは何も変更しません。

## 表示される場所

- **ドキュメント内:** 旧形式の UUID（サブタイプ 3 の 16 バイトのバイナリ）にポインターを合わせると、Java、C#、Python の順序で読み取った結果が表示されます。
- **コレクションのタブ:** すべてのコレクションとビューで、ドキュメント、集計などのタブの隣に **UUID** タブが表示されます。

## 使い方

コレクションを開き、**UUID** タブを開きます。タブを開くとすぐに 1,000 件のドキュメントのランダムなサンプルを読み取ります。**再スキャン** で別のサンプルを読み取ります。

**UUID フィールド** には、サンプル内で UUID を持つ各フィールド（ネストされたフィールドや配列も含む）が、旧形式と標準の件数とともに一覧表示されます。旧形式の UUID を持つフィールドでは、すべての値を正しい形式の UUID として読み取れるバイト順のドライバー名が表示されます。UUID のバージョン桁とバリアントビットは決まった位置にあり、誤った順序で読むと、ほとんどその位置に収まらないためです。フィールドの最初の値を各順序で読み取った結果も表示されます。**このフィールドで検索** を押すと、そのフィールドとドライバーが検索欄に入力されます。

**UUID を検索** では、一般的な書き方の UUID（ハイフンや波括弧の有無を問わない 16 進数 32 桁、または `UUID("…")`）、検索するフィールド、保存形式（**いずれか**、標準のサブタイプ、または Java、C#、Python の旧形式の順序）を指定します。各ドライバーが保存した形の値を、シェルでの表記（`BinData(3, "…")`、`UUID("…")`）で表示し、それぞれにコピーボタンがあります。**ドキュメントで表示** を押すと、その UUID を持つドキュメントを選ぶフィルターがドキュメントのクエリに設定されます。**いずれか** を選ぶと、どのドライバーの値でも検索できます。

## 例

UUID `00112233-4455-6677-8899-aabbccddeeff` を各ドライバーが保存した形:

```
標準      UUID("00112233-4455-6677-8899-aabbccddeeff")
Java      BinData(3, "d2ZVRDMiEQD/7t3Mu6qZiA==")
C#        BinData(3, "MyIRAFVEd2aImaq7zN3u/w==")
Python    BinData(3, "ABEiM0RVZneImaq7zN3u/w==")
```

## 権限

- **ドキュメントの読み取り**（`documents:read`）: サンプルの読み取りと、ドキュメントのクエリへのフィルターの設定に使います。

読み取りは、サインインしているユーザーの権限とフィールドのマスクを適用したうえで、アプリ経由で行われます。非表示の値は、プラグインが UUID として読み取れる値ではありません。プラグインは他のコレクションを読み取れません。セルレンダラーに送られるのは、バイナリ値の先頭の数バイト、サブタイプ、長さだけです。

## 設定

なし。

## 制限

- フィールドは 1,000 件のランダムなサンプルから検出されるため、まれなフィールドはサンプルに含まれないことがあります。
- ドキュメントが大きい場合（API ログなど）、サンプルはページへの 1 回の応答（1 MB）に収まる数に限られます。
- 複数のドライバー由来の値を持つフィールドは、単一の順序に当てはまりません。その場合はタブに表示されます。値が少ないと、複数の順序に当てはまることがあり、その場合はすべて表示されます。
- UUID として読み取るのは、サブタイプ 3 または 4 の 16 バイトのバイナリのみです。
