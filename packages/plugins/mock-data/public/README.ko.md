# 테스트 데이터

인덱스, 쿼리, 차트, 화면을 시험하려면 직접 입력하기엔 너무 많고 실제 데이터가 아닌 도큐먼트가 필요합니다. 테스트 데이터는 컬렉션과 같은 형태의 현실적인 도큐먼트를 만들어 앱의 가져오기 마법사에 전달하고, 마법사에서 확인한 뒤 가져오기를 시작합니다. NoSQLBooster도 "Test Data Generator"라는 이름으로 같은 기능을 제공합니다.

## 사용 방법

1. 컬렉션을 열고 **테스트 데이터** 탭을 엽니다. 플러그인이 도큐먼트 100개를 샘플로 읽어 필드를 나열합니다(`_id`는 서버에 맡깁니다).
2. 각 필드에는 이름과 유형에 따라 고른 **테스트 값**이 지정됩니다. `email`에는 이메일 주소, `createdAt`에는 지난 1년 내 날짜, `price`에는 가격, `status`에는 컬렉션에 이미 있는 값 중 하나, GeoJSON `location`에는 점이 들어갑니다. 이름이 필드의 유형을 바꾸지는 않습니다. 텍스트로 저장된 날짜에는 텍스트 날짜가, 바이트로 저장된 이미지에는 작은 PNG 이미지가 들어갑니다. 100개 이상의 템플릿 중에서 원하는 것으로 바꿀 수 있으며, 템플릿은 사람, 인터넷, 위치, 회사, 상거래, 금융, 날짜 및 시간, 숫자, 텍스트, 식별자, 참 또는 거짓, 기타("이 텍스트", null, 비어 있음)로 묶여 있습니다.
3. 필드를 제외하려면 체크를 해제하고, 필드를 추가할 수도 있습니다(다른 필드 안에 넣으려면 `profile.phone`처럼 입력하며, `items[].qty`처럼 객체 배열 안의 필드는 요소가 1~3개 생성됩니다).
4. 도큐먼트 수(최대 5,000), 제외할 필드 비율(모든 필드를 갖지는 않는 도큐먼트를 위한 설정), 단어 언어(앱의 10개 언어 중 하나), **시드**를 선택합니다. 탭을 열어 두는 동안은 같은 시드로 같은 도큐먼트가 다시 만들어집니다(날짜는 탭을 연 시각부터 거슬러 계산합니다). 필드가 하나도 없는 도큐먼트는 만들어지지 않습니다.
5. **미리보기**를 확인한 뒤 **가져오기…**를 누릅니다. 가져오기 마법사가 해당 컬렉션에서 열리고, 이 도큐먼트가 파일로 전달됩니다. 마법사에서 사용자 본인의 권한으로 가져오기를 시작하기 전까지는 아무것도 기록되지 않습니다. **JSON 다운로드**는 대신 도큐먼트를 저장합니다.

## 만들지 않는 것

- 이메일과 웹 주소에는 예약된 예시 도메인(`example.com`, `example.org`, `example.net`, `.test`)만, IP 주소에는 문서용 대역만 사용합니다. 전화번호는 허구용으로 비워 둔 대역(`+1 2xx-555-01xx`)이나 회선이 없는 대역(`+90 000 …`)을 사용합니다. 회사 이름은 지어낸 것입니다.
- 사람이나 사물을 구별할 수 있는 값은 컬렉션에서 복사하지 않습니다. "기존 값 중 하나"는 범주를 뜻하는 이름의 필드(상태, 국가)이거나 식별자(ID, 번호, 코드, 여권 등) 또는 사람(소유자, 고객, 작성자, 사용자 등)으로 읽히지 않는 필드에만 제공되며, 짧은 값이 모두 샘플에서 두 번 이상 나타나는 경우에만(값은 직접 볼 수 있습니다) 제공됩니다. 사람의 이름, 이메일, 전화번호, 주소는 `email2`, `phone1`을 포함해 절대 제공되지 않습니다.
- 개인 데이터로 분류되어 사용자에게 숨겨진 필드는 유형을 알 수 없는 숨김 필드로 표시되며, 다른 값을 선택하기 전까지 테스트 값은 텍스트입니다(이유는 해당 컨트롤과 함께 읽을 수 있습니다). 가져오기 마법사는 거기서 포함하지 않으면 이 필드를 제외합니다. 앱이 어떤 필드가 숨겨져 있는지 제때 알 수 없으면 **다시 시도**를 선택하기 전까지 모든 필드를 숨김으로 처리합니다.
- 새 필드는 도큐먼트 목록 안(`items[].qty` 옆의 `items.note`)에 놓이지 않으며, `$`나 대괄호를 포함하지 않습니다.
- 도큐먼트는 앱이 받는 형태로 측정됩니다. 한 번의 전달 또는 다운로드는 전송 기준으로 최대 1,000,000자, 1.04 MB입니다. 앱의 질문에 아니오라고 답하면 오류가 아니라 짧은 안내가 표시됩니다.
- 실제 IBAN, 계좌 번호, 카드 번호는 없습니다. 해당 템플릿은 가짜로 표시됩니다(`XX00 TEST …`).

## 권한

- **도큐먼트 읽기:** 필드를 파악하기 위한 컬렉션 샘플입니다. 가져오기 자체는 마법사를 통해 앱이 수행합니다.
