# テストデータ

インデックス、クエリ、グラフ、画面を試すにはドキュメントが必要です。手で入力できる量より多く、しかも本物ではないものが。テストデータは、コレクションのドキュメントに似せたリアルなドキュメントを作成し、アプリのインポートウィザードに渡します。確認してインポートを開始するのはウィザード側で、あなたが行います。NoSQLBooster にも同じ機能が「Test Data Generator」としてあります。

## 使い方

1. コレクションを開き、その**テストデータ**タブを開きます。プラグインは 100 件のドキュメントをサンプルとして読み取り、そのフィールドを一覧にします（`_id` はサーバーに任せます）。
2. 各フィールドには、名前と型から選ばれた**テスト値**が割り当てられます。`email` にはメールアドレス、`createdAt` には過去 1 年以内の日付、`price` には価格、`status` にはコレクションにすでにある値のいずれか、GeoJSON の `location` には 1 つの点です。名前がフィールドの型を変えることはありません。テキストとして保存された日付にはテキストの日付、バイトとして保存された画像には小さな PNG 画像が入ります。どのフィールドも、グループ分けされた 100 以上のテンプレートから変更できます。人物、インターネット、場所、会社、商取引、金融、日付と時刻、数値、テキスト、識別子、真または偽、その他（「このテキスト」、null、空）です。
3. フィールドのチェックを外すと除外され、新しいフィールドを追加することもできます（別のフィールドの内側なら `profile.phone`。`items[].qty` のようなオブジェクトの配列は 1 〜 3 個の要素になります）。
4. ドキュメント数（最大 5,000）、空にするフィールドの割合（すべてのフィールドを持つとは限らないドキュメント向け）、単語の言語（アプリの 10 言語のいずれか）、**シード**を選びます。タブを開いている間は、同じシードなら同じドキュメントが再び作られます（日付はタブを開いた時刻から遡ります）。フィールドが 1 つもないドキュメントは作られません。
5. **プレビュー**を確認して**インポート…**を押すと、そのコレクションでインポートウィザードが開き、ドキュメントがそのファイルとして渡されます。ウィザードであなた自身の権限でインポートを開始するまで、何も書き込まれません。代わりに **JSON をダウンロード**で保存することもできます。

## 作られないもの

- メールアドレスと Web アドレスには予約済みの例示用ドメイン（`example.com`、`example.org`、`example.net`、`.test`）だけを使います。IP アドレスにはドキュメント用の範囲、電話番号にはフィクション用に確保された範囲（`+1 2xx-555-01xx`）またはどの回線にもない範囲（`+90 000 …`）を使います。会社名は架空です。
- 人や物を見分けられる値は、コレクションからコピーされません。「既存の値のいずれか」が提示されるのは、カテゴリ（ステータス、国）を表す名前のフィールド、または識別子（id、番号、コード、パスポート…）や人（所有者、顧客、作成者、ユーザー…）と読めない名前のフィールドで、しかも（あなたにも見える）数少ない短い値のすべてが、サンプル内で 2 回以上出てくる場合に限られます。人の氏名、メールアドレス、電話番号、住所は決して対象になりません。`email2` や `phone1` も同様です。
- 個人データとして非表示になっているフィールドは、型が不明な「非表示」として一覧に載ります。別のテンプレートを選ぶまでテスト値はテキストです（理由はコントロールと一緒に読み上げられます）。インポートウィザードでは、そこで含めない限り除外されます。どのフィールドが非表示なのかをアプリが時間内に判断できなかった場合は、**もう一度試す**を選ぶまで、すべてのフィールドを非表示として扱います。
- 新しいフィールドが、ドキュメントのリストの内側（`items[].qty` の隣の `items.note`）に置かれることはなく、`$` や角括弧も含まれません。
- ドキュメントは、アプリが受け取る形で計測されます。一度の受け渡しまたはダウンロードは、最大 1,000,000 文字、送信時のサイズで 1.04 MB までです。アプリからの確認に「いいえ」と答えた場合は、エラーではなく短いメモが残ります。
- IBAN、口座番号、カード番号に本物はありません。これらのテンプレートはダミーとして示されます（`XX00 TEST …`）。

## 権限

- **ドキュメントの読み取り:** フィールドを知るためのコレクションのサンプル。インポート自体は、アプリがウィザードを通じて行います。
