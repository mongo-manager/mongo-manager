# Срок действия (TTL)

TTL-индекс удаляет каждый документ коллекции через заданное время после даты в одном из его полей: сеансы через день, журналы через месяц. «Срок действия» показывает для каждого TTL-индекса коллекции, когда исчезают ее документы: сколько из них с истекшим, но еще не удаленным сроком, сколько уйдет в течение часа, дня, недели, позже и сколько индекс не удалит никогда.

Плагин только читает. Он ничего не изменяет в базе данных и ничего не удаляет.

## Где он появляется

- **Вкладка коллекции:** вкладка **Срок действия** рядом с «Документами», «Агрегациями» и другими вкладками каждой коллекции и каждого представления.

## Как пользоваться

Откройте коллекцию, затем вкладку **Срок действия**. Она читает индексы коллекции и считает сразу при открытии; **Пересчитать** считает заново, с момента нажатия.

Каждый TTL-индекс показан карточкой: его поле, через какое время после даты в поле документ удаляется (`expireAfterSeconds`; 0 означает в момент самой даты) и его частичный фильтр, если он есть. Его документы подсчитываются в шести группах:

- **Срок истек, еще не удалены:** время прошло. TTL-монитор сервера запускается примерно раз в минуту и удаляет их; на загруженном сервере возможна задержка.
- **В ближайший час**, **Через 1–24 часа**, **Через 1–7 дней**, **Позже чем через 7 дней:** каждая группа начинается там, где заканчивается предыдущая.
- **Никогда:** в поле нет даты (оно отсутствует либо содержит текст или число) или, для частичного индекса, документ не попадает под его фильтр.

**Показать** помещает в запрос «Документов» фильтр, выбирающий документы группы.

## Пример

В коллекции `sessions` с `createIndex({ lastSeen: 1 }, { expireAfterSeconds: 86400 })`:

```
lastSeen   Удаляет документ через 1 день после даты в поле lastSeen
Срок истек, еще не удалены      0 документов
В ближайший час                12 документов
Через 1–24 часа               340 документов
Через 1–7 дней                  0 документов
Позже чем через 7 дней          0 документов
Никогда                         3 документа
```

У трех документов, которые не будут удалены никогда, в `lastSeen` нет даты: **Показать** у группы **Никогда** найдет их.

## Разрешения

- **Чтение определения этой коллекции** (`collection:read`): чтобы перечислить ее индексы.
- **Чтение документов** (`documents:read`): чтобы подсчитать каждую группу конвейером только для чтения и поместить фильтр в запрос «Документов».

Чтение идет через приложение с правами вошедшего пользователя и маскированием полей: скрытое от пользователя TTL-поле подсчитать нельзя, и его группы сообщают об этом. Плагин не может читать другие коллекции.

## Настройки

Нет.

## Ограничения

- Каждая группа — это один конвейер, диапазон по TTL-полю, который может обслужить его индекс (**Никогда** и фильтр частичного индекса могут читать всю коллекцию); каждый выполняется не дольше 10 секунд. Группа, которую не удалось подсчитать, сообщает об этом и о причине.
- Документ, в поле которого несколько дат, удаляется по самой ранней и подсчитывается в ее группе.
- Читаются только TTL-индексы. Собственный `expireAfterSeconds` коллекции временных рядов или кластеризованной коллекции не показывается.
