# 到期 (TTL)

TTL 索引会在集合中每个文档某个字段的日期之后经过设定的时间将其删除——会话一天后，日志一个月后。“到期”会针对集合的每个 TTL 索引显示其文档何时被删除：有多少已到期但尚未删除，有多少会在 1 小时内、1 天内、1 周内或更晚被删除，以及有多少永远不会被删除。

该插件只读取。它不会更改数据库中的任何内容，也不会删除任何内容。

## 出现的位置

- **集合选项卡：** 在每个集合和视图中，“文档”“聚合”及其他选项卡旁边会出现一个**到期**选项卡。

## 使用方法

打开一个集合，然后打开**到期**选项卡。选项卡一打开就会读取集合的索引并统计；点击**重新统计**会从点击的那一刻起重新统计。

每个 TTL 索引是一张卡片：它的字段、文档在字段日期之后多久被删除（`expireAfterSeconds`；0 表示就在该日期时）、以及部分筛选条件（如果有）。其文档分为六组统计：

- **已到期，尚未删除：** 时间已过。服务器的 TTL 监视器大约每分钟运行一次并删除它们；服务器繁忙时可能会有延迟。
- **未来 1 小时内**、**1–24 小时内**、**1–7 天内**、**7 天之后：** 每一组从上一组结束的地方开始。
- **永不：** 字段不含日期（缺失，或为文本或数字），或者对于部分索引，文档不在其筛选范围内。

**显示**会将选择某一组文档的筛选条件放入“文档”查询。

## 示例

在带有 `createIndex({ lastSeen: 1 }, { expireAfterSeconds: 86400 })` 的 `sessions` 集合上：

```
lastSeen   文档在其 lastSeen 字段日期的 1 天后被删除
已到期，尚未删除      0 个文档
未来 1 小时内        12 个文档
1–24 小时内         340 个文档
1–7 天内              0 个文档
7 天之后              0 个文档
永不                  3 个文档
```

永远不会被删除的这三个文档在 `lastSeen` 中没有日期：在**永不**上点击**显示**即可找到它们。

## 权限

- **读取此集合的定义**（`collection:read`）：用于列出其索引。
- **读取文档**（`documents:read`）：用于通过只读管道统计每一组，并将筛选条件放入“文档”查询。

读取通过应用以已登录用户的权限和字段掩码进行：对用户隐藏的 TTL 字段无法统计，其分组会说明这一点。该插件无法读取其他集合。

## 设置

无。

## 限制

- 每一组是一个管道，即对 TTL 字段的一个范围查询，其索引可以支持（**永不**和部分索引的筛选条件可能会读取整个集合）；每个最多运行 10 秒。无法统计的分组会说明这一点及原因。
- 字段包含多个日期的文档按最早的日期删除，并计入该日期所在的分组。
- 仅读取 TTL 索引。时间序列集合或聚簇集合自身的 `expireAfterSeconds` 不会显示。
