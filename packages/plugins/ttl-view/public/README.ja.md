# 有効期限 (TTL)

TTL インデックスは、コレクションの各ドキュメントを、フィールドの 1 つにある日時から一定時間が経過した後に削除します。セッションは 1 日後、ログは 1 か月後などです。［有効期限］は、コレクションの TTL インデックスごとに、ドキュメントがいつ削除されるかを表示します。期限切れだがまだ削除されていない数、1 時間以内、1 日以内、1 週間以内、それ以降に削除される数、そして削除されない数です。

このプラグインは読み取りのみを行います。データベースの内容を変更したり、何かを削除したりすることはありません。

## 表示される場所

- **コレクションタブ:** すべてのコレクションとビューで、［ドキュメント］、［集計］などのタブの隣に **有効期限** タブが表示されます。

## 使い方

コレクションを開き、**有効期限** タブを開きます。タブを開くとすぐにコレクションのインデックスを読み込んで集計します。**再集計** をクリックすると、クリックした時点から集計し直します。

各 TTL インデックスはカードで表示されます。フィールド、フィールドの日時から何時間後にドキュメントが削除されるか（`expireAfterSeconds`。0 は日時そのもの）、部分フィルターがある場合はそのフィルターです。ドキュメントは 6 つのグループで集計されます。

- **期限切れ（未削除）:** 時間が過ぎています。サーバーの TTL モニターが約 1 分ごとに実行されて削除します。負荷の高いサーバーでは遅れることがあります。
- **今後 1 時間以内**、**1～24 時間以内**、**1～7 日以内**、**7 日より後:** 各グループは前のグループが終わるところから始まります。
- **削除されない:** フィールドに日時がない（存在しない、または文字列や数値）、または部分インデックスの場合はドキュメントがそのフィルターの対象外です。

**表示** は、そのグループのドキュメントを選択するフィルターを［ドキュメント］のクエリに設定します。

## 例

`createIndex({ lastSeen: 1 }, { expireAfterSeconds: 86400 })` を持つ `sessions` コレクションの場合:

```
lastSeen   ドキュメントは lastSeen フィールドの日時の1日後に削除されます
期限切れ（未削除）       0 件のドキュメント
今後 1 時間以内         12 件のドキュメント
1～24 時間以内         340 件のドキュメント
1～7 日以内              0 件のドキュメント
7 日より後               0 件のドキュメント
削除されない             3 件のドキュメント
```

削除されない 3 件は `lastSeen` に日時がありません。**削除されない** の **表示** で見つけられます。

## 権限

- **このコレクションの定義を読み取る**（`collection:read`）: インデックスを一覧表示するために使用します。
- **ドキュメントを読み取る**（`documents:read`）: 読み取り専用のパイプラインで各グループを集計し、［ドキュメント］のクエリにフィルターを設定するために使用します。

読み取りは、サインインしているユーザーの権限とフィールドのマスキングに従って、アプリ経由で行われます。ユーザーに対して非表示の TTL フィールドは集計できず、そのグループにはその旨が表示されます。このプラグインは他のコレクションを読み取れません。

## 設定

なし。

## 制限

- 各グループは、TTL フィールドに対する範囲指定で、そのインデックスが利用できる 1 つのパイプラインです（**削除されない** と部分インデックスのフィルターは、コレクション全体を読み取る場合があります）。各パイプラインの実行は最大 10 秒です。集計できなかったグループには、その旨と理由が表示されます。
- フィールドに複数の日時を持つドキュメントは、最も早い日時で削除され、そのグループで集計されます。
- 読み取るのは TTL インデックスのみです。時系列コレクションやクラスター化コレクション自体の `expireAfterSeconds` は表示されません。
