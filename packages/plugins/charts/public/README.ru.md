# Диаграммы

Диаграммы показывают значения коллекции: сколько документов содержит каждое значение поля, как количество или сумма меняется со временем, как распределено число или как связаны два числа. К каждой диаграмме прилагается сводная таблица, а каждая ее строка может показать свои документы на вкладке «Документы».

Плагин только читает. Он ничего не изменяет в базе данных.

## Где он появляется

- **Вкладка коллекции:** вкладка **Диаграммы** рядом с вкладками «Документы», «Агрегации» и другими у каждой коллекции и представления.

## Как пользоваться

Откройте коллекцию, затем вкладку **Диаграммы**.

1. Выберите тип диаграммы: **Столбчатая**, **По времени**, **Кольцевая**, **Гистограмма** или **Точечная**.
2. Выберите поле (для диаграммы по времени — поле даты, для гистограммы — числовое поле, для точечной — числовые поля для осей X и Y).
3. Для столбчатой, кольцевой диаграммы и диаграммы по времени выберите **Показатель**: количество либо сумму, среднее, минимум или максимум другого числового поля.
4. Для диаграммы по времени выберите **Период**: час, день, неделя, месяц или год.
5. Выберите **Документы для диаграммы**: **Фильтр документов** (запрос вкладки «Документы») или **Вся коллекция**.

Диаграмма строится, как только выбор завершен, и перестраивается при каждом изменении. Наведите курсор на столбец, сектор или точку, чтобы увидеть значение. Под диаграммой в таблице **Данные** перечислено все, что построено; кнопка **Показать** помещает в запрос вкладки «Документы» фильтр по документам этой строки.

## Пример

Коллекция `orders` с полем `status` и датой `createdAt`:

- Столбчатая, поле `status`, показатель «Количество»: по одному столбцу на каждый статус, самый большой первым.
- По времени, поле даты `createdAt`, период «Месяц», показатель «Сумма» по `total`: выручка по месяцам.
- Гистограмма по `total`: как суммы заказов распределены по 12 равным диапазонам.

Нажатие **Показать** в строке `shipped` столбчатой диаграммы помещает на вкладку «Документы» такой фильтр:

```json
{ "status": { "$eq": "shipped" } }
```

## Типы диаграмм

- **Столбчатая:** значения текстового, числового, логического поля или поля ObjectId, сгруппированные и подсчитанные (или просуммированные, усредненные…), самое большое первым. Отсутствующее значение образует отдельный столбец.
- **По времени:** документы по периодам поля даты с помощью `$dateTrunc` сервера, в UTC.
- **Кольцевая:** как столбчатая, но в виде долей целого.
- **Гистограмма:** числовое поле, разбитое на 12 интервалов одинаковой ширины между его наименьшим и наибольшим значениями.
- **Точечная:** два числовых поля одних и тех же документов в виде точек.

## Разрешения

- **Чтение документов** (`documents:read`): диаграммы — это конвейеры агрегации, выполняемые над открытой коллекцией, а список полей берется из выборки ее документов.

Чтение идет через приложение с правами и маскированием полей вошедшего пользователя. Плагин не может читать другие коллекции, индексы и вообще ничего за пределами коллекции, в которой он открыт.

## Параметры

Нет.

## Ограничения

- Список полей берется из случайной выборки в 200 документов. Поле, которого нет ни в одном из них, не предлагается.
- Вложенные поля предлагаются на глубину до двух уровней (например, `address.city`).
- Столбчатая диаграмма показывает 12 крупнейших групп, кольцевая — 7. Остальное объединяется в **Прочее**, а таблица показывает, что в него входит.
- Диаграмма по времени показывает последние 1000 периодов. Если их больше, более старые периоды не показываются, и диаграмма сообщает об этом; выберите более длинный период, чтобы увидеть их.
- Гистограмма использует 12 интервалов.
- Точечная диаграмма строит случайную выборку не более чем из 1000 документов, содержащих оба числа.
- Значение внутри массива не показывается на диаграмме как дата или число: массив — это не момент времени.
- Каждый конвейер выполняется не более 10 секунд, без использования диска и по одному за раз. Диаграмма по очень большой коллекции может не уложиться в это время; фильтр документов позволяет сузить выборку.
- Диаграммы строятся на сервере; в браузер попадают только сгруппированные результаты.
