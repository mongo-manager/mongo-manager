# 차트

차트는 컬렉션의 값을 그림으로 보여 줍니다. 필드의 각 값을 가진 도큐먼트가 몇 개인지, 개수나 합계가 시간에 따라 어떻게 변하는지, 숫자가 어떻게 분포하는지, 두 숫자가 서로 어떤 관계인지를 볼 수 있습니다. 모든 차트에는 요약 표가 함께 제공되며, 표의 각 행은 해당 도큐먼트를 도큐먼트 탭에서 표시할 수 있습니다.

이 플러그인은 읽기만 합니다. 데이터베이스는 아무것도 변경하지 않습니다.

## 표시 위치

- **컬렉션 탭:** 모든 컬렉션과 뷰에서 도큐먼트, 집계 등 다른 탭 옆에 **차트** 탭이 표시됩니다.

## 사용 방법

컬렉션을 연 다음 **차트** 탭을 엽니다.

1. 차트 유형을 선택합니다. **막대**, **시간별 추이**, **도넛**, **히스토그램**, **산점도** 중에서 고릅니다.
2. 필드를 선택합니다. 시간별 추이는 날짜 필드, 히스토그램은 숫자 필드, 산점도는 X축과 Y축에 쓸 숫자 필드를 선택합니다.
3. 막대, 도넛, 시간별 추이에서는 **집계**를 선택합니다. 개수, 또는 다른 숫자 필드의 합계, 평균, 최솟값, 최댓값 중에서 고릅니다.
4. 시간별 추이에서는 **기간**을 선택합니다. 시간, 일, 주, 월, 연 중에서 고릅니다.
5. **차트로 그릴 도큐먼트**를 선택합니다. **도큐먼트 필터**(도큐먼트 탭의 쿼리) 또는 **전체 컬렉션**입니다.

선택이 완료되는 즉시 차트가 그려지고, 변경할 때마다 다시 그려집니다. 막대, 조각, 포인트에 마우스를 올리면 값이 표시됩니다. 차트 아래의 **데이터** 표에는 그려진 내용이 나열되며, **표시**를 누르면 해당 행의 도큐먼트에 대한 필터가 도큐먼트 쿼리에 입력됩니다.

## 예시

`status` 필드와 `createdAt` 날짜가 있는 `orders` 컬렉션:

- 막대, 필드 `status`, 집계 개수: 상태별로 막대 하나씩, 큰 것부터 표시됩니다.
- 시간별 추이, 날짜 필드 `createdAt`, 기간 월, 집계 `total`의 합계: 월별 매출입니다.
- `total`의 히스토그램: 주문 합계가 동일한 폭의 12개 구간에 어떻게 분포하는지 보여 줍니다.

막대 차트의 `shipped` 행에서 **표시**를 누르면 도큐먼트 탭에 다음 필터가 입력됩니다.

```json
{ "status": { "$eq": "shipped" } }
```

## 차트 유형

- **막대:** 텍스트, 숫자, 참/거짓 또는 ObjectId 필드의 값을 그룹화하여 개수(또는 합계, 평균 등)를 큰 것부터 표시합니다. 값이 없는 경우는 별도의 막대로 표시됩니다.
- **시간별 추이:** 날짜 필드의 기간별 도큐먼트 수이며, 서버의 `$dateTrunc`를 UTC 기준으로 사용합니다.
- **도넛:** 막대와 같지만 전체에 대한 비율로 표시합니다.
- **히스토그램:** 숫자 필드를 최솟값과 최댓값 사이의 동일한 폭의 12개 구간으로 나눕니다.
- **산점도:** 같은 도큐먼트의 두 숫자 필드를 포인트로 표시합니다.

## 권한

- **도큐먼트 읽기** (`documents:read`): 차트는 열려 있는 컬렉션에서 실행되는 집계 파이프라인이며, 필드 목록은 해당 도큐먼트의 샘플에서 가져옵니다.

읽기는 로그인한 사용자의 권한과 필드 마스킹을 적용하여 앱을 통해 수행됩니다. 플러그인은 다른 컬렉션, 인덱스, 그리고 열려 있는 컬렉션 밖의 어떤 것도 읽을 수 없습니다.

## 설정

없음.

## 제한

- 필드 목록은 200개 도큐먼트의 무작위 샘플에서 가져옵니다. 그중 어느 것에도 없는 필드는 제공되지 않습니다.
- 중첩 필드는 두 단계 깊이까지 제공됩니다(예: `address.city`).
- 막대는 가장 큰 12개 그룹을, 도넛은 7개를 표시합니다. 나머지는 **기타**로 묶이며, 표에 기타에 무엇이 포함되는지 표시됩니다.
- 시간별 추이는 최근 1,000개 기간을 표시합니다. 그보다 많으면 이전 기간은 제외되고 차트에 그 사실이 표시됩니다. 더 긴 기간을 선택하면 볼 수 있습니다.
- 히스토그램은 12개 구간을 사용합니다.
- 산점도는 두 숫자를 모두 가진 도큐먼트 중 최대 1,000개의 무작위 샘플을 그립니다.
- 배열 안의 값은 날짜나 숫자로 차트에 표시되지 않습니다. 배열은 시점이 아니기 때문입니다.
- 각 파이프라인은 디스크를 사용하지 않고 한 번에 하나씩 최대 10초 동안 실행됩니다. 매우 큰 컬렉션의 차트는 시간이 초과될 수 있으며, 도큐먼트 필터로 범위를 좁힐 수 있습니다.
- 차트는 서버에서 실행되며, 그룹화된 결과만 브라우저에 전달됩니다.
