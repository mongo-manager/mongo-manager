# 图表

“图表”会绘制集合中的值:每个字段值被多少个文档持有,某个计数或总和如何随时间变化,某个数值如何分布,或两个数值之间有什么关系。每个图表都附带一张汇总表,表中的每一行都可以在“文档”中显示它自己的文档。

此插件只读取,不会更改数据库中的任何内容。

## 出现的位置

- **集合标签页:** 每个集合和视图中,在“文档”、“聚合”等标签页旁边有一个**图表**标签页。

## 使用方法

打开一个集合,然后打开**图表**标签页。

1. 选择图表类型:**柱状图**、**时间趋势**、**环形图**、**直方图**或**散点图**。
2. 选择字段(时间趋势选日期字段;直方图选数值字段;散点图选一个 X 和一个 Y 数值字段)。
3. 对于柱状图、环形图和时间趋势,选择**度量**:计数,或另一个数值字段的求和、平均值、最小值或最大值。
4. 对于时间趋势,选择**周期**:小时、天、周、月或年。
5. 选择**要绘制的文档**:**文档筛选**(“文档”标签页的查询)或**整个集合**。

选择完整后图表会立即绘制,之后每次更改都会重新绘制。将鼠标悬停在柱子、扇区或点上可查看它的值。图表下方的**数据**表列出了所绘制的内容;**显示**会把该行文档的筛选条件放入“文档”的查询中。

## 示例

一个 `orders` 集合,包含 `status` 字段和 `createdAt` 日期:

- 柱状图,字段 `status`,度量计数:每个状态一根柱子,最大的排在最前。
- 时间趋势,日期字段 `createdAt`,周期为月,度量为 `total` 的求和:每月的收入。
- `total` 的直方图:订单总额在 12 个等宽区间中的分布。

在柱状图中点击 `shipped` 行的**显示**,会在“文档”中放入这个筛选条件:

```json
{ "status": { "$eq": "shipped" } }
```

## 图表类型

- **柱状图:** 文本、数字、真/假或 ObjectId 字段的值,经分组后计数(或求和、求平均值等),最大的排在最前。缺失的值单独成为一根柱子。
- **时间趋势:** 按日期字段的每个周期统计文档,使用服务器的 `$dateTrunc`,以 UTC 计。
- **环形图:** 与柱状图类似,以占整体的份额显示。
- **直方图:** 一个数值字段,在其最小值与最大值之间分成 12 个等宽的区间。
- **散点图:** 同一批文档的两个数值字段,以点表示。

## 权限

- **读取文档**(`documents:read`):图表是在已打开的集合上运行的聚合管道,字段列表来自该集合文档的一个样本。

读取通过应用进行,使用已登录用户的权限和字段屏蔽。此插件无法读取其他集合、索引,也无法读取所打开集合之外的任何内容。

## 设置

无。

## 限制

- 字段列表来自 200 个文档的随机样本。样本中没有任何文档包含的字段不会被提供。
- 嵌套字段最多提供两层(例如 `address.city`)。
- 柱状图显示最大的 12 个分组;环形图显示 7 个。其余的合并为**其他**,表格会说明“其他”包含什么。
- 时间趋势显示最近的 1,000 个周期。超出时,更早的周期会被省略,图表也会注明;选择更长的周期即可看到它们。
- 直方图使用 12 个区间。
- 散点图最多随机抽取 1,000 个同时包含这两个数值的文档。
- 数组中的值不会被当作日期或数字来绘制:数组不是一个时间点。
- 每个管道最长运行 10 秒,不使用磁盘,一次只运行一个。对非常大的集合绘制图表可能会超时;可以用文档筛选来缩小范围。
- 图表在服务器上运行;只有分组后的结果会到达浏览器。
