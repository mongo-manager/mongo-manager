# グラフ

「グラフ」は、コレクションの値を描画します。フィールドの各値を持つドキュメントの数、件数や合計が時間とともにどう動くか、数値がどう分布しているか、2 つの数値がどう関係しているかを表示します。どのグラフにも集計表が付き、表の各行は、その行のドキュメントを「ドキュメント」で表示できます。

このプラグインは読み取るだけです。データベースは何も変更しません。

## 表示される場所

- **コレクションのタブ:** すべてのコレクションとビューで、「ドキュメント」や「集計」などのタブの隣に **グラフ** タブが表示されます。

## 使い方

コレクションを開き、**グラフ** タブを開きます。

1. グラフの種類を選びます: **棒**、**時系列**、**ドーナツ**、**ヒストグラム**、**散布図**。
2. フィールドを選びます(時系列は日付フィールド、ヒストグラムは数値フィールド、散布図は X と Y の数値フィールド)。
3. 棒、ドーナツ、時系列では **集計** を選びます: 件数、または別の数値フィールドの合計、平均、最小、最大。
4. 時系列では **期間** を選びます: 時間、日、週、月、年。
5. **対象ドキュメント** を選びます: **ドキュメントのフィルター**(「ドキュメント」タブのクエリ)または **コレクション全体**。

選択がそろうとすぐにグラフが描画され、変更するたびに再描画されます。棒、扇形、点にカーソルを合わせると値が表示されます。グラフの下の **データ** 表には描画された内容が一覧表示され、**表示** を押すと、その行のドキュメントのフィルターが「ドキュメント」のクエリに入ります。

## 例

`status` フィールドと `createdAt` 日付を持つ `orders` コレクションの場合:

- 棒、フィールド `status`、集計は件数: ステータスごとに 1 本の棒が、大きい順に並びます。
- 時系列、日付フィールド `createdAt`、期間は月、集計は `total` の合計: 月ごとの売上。
- `total` のヒストグラム: 注文の合計金額が、12 の等しい範囲にどう分布しているか。

棒グラフの `shipped` の行で **表示** を押すと、次のフィルターが「ドキュメント」に入ります。

```json
{ "status": { "$eq": "shipped" } }
```

## グラフの種類

- **棒:** テキスト、数値、真偽値、ObjectId のフィールドの値をグループ化して数えます(または合計、平均など)。大きい順に並びます。値がないものは、それだけで 1 本の棒になります。
- **時系列:** 日付フィールドの期間ごとのドキュメント数。サーバーの `$dateTrunc` を使い、UTC で集計します。
- **ドーナツ:** 棒と同様ですが、全体に対する割合で表示します。
- **ヒストグラム:** 数値フィールドを、最小値と最大値の間で等しい幅の 12 区間に分けます。
- **散布図:** 同じドキュメントの 2 つの数値フィールドを、点として表示します。

## 権限

- **ドキュメントの読み取り**(`documents:read`): グラフは、開いているコレクションで実行される集計パイプラインであり、フィールドの一覧はそのドキュメントのサンプルから作られます。

読み取りはアプリを通じて、サインインしているユーザーの権限とフィールドのマスキングに従って行われます。このプラグインは、他のコレクションやインデックス、開いているコレクションの外にあるものを読み取ることはできません。

## 設定

なし。

## 制限

- フィールドの一覧は、ランダムに選んだ 200 件のドキュメントのサンプルから作られます。どのドキュメントにもないフィールドは表示されません。
- ネストしたフィールドは 2 階層まで表示されます(例: `address.city`)。
- 棒は上位 12 グループ、ドーナツは 7 グループを表示します。残りは **その他** にまとめられ、その他に何が含まれるかは表に示されます。
- 時系列は最新の 1,000 期間を表示します。それを超える場合は古い期間が省略され、グラフにもその旨が表示されます。長い期間を選ぶと、すべて表示できます。
- ヒストグラムは 12 区間を使います。
- 散布図は、2 つの数値を両方持つドキュメントから、ランダムに最大 1,000 件を描画します。
- 配列の中の値は、日付や数値としてグラフにはされません。配列は時点ではないためです。
- 各パイプラインは最長 10 秒、ディスクを使わず、1 つずつ実行されます。非常に大きなコレクションでは、グラフがタイムアウトすることがあります。ドキュメントのフィルターで絞り込むことができます。
- グラフはサーバー上で実行され、グループ化された結果だけがブラウザーに届きます。
