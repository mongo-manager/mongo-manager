# 二进制数据预览

集合经常把文件作为二进制值存放在文档里：头像、扫描的收据、缩略图、小型 PDF。“文档”只会把这样的值显示为 `Binary(…)`，看不出它到底是什么。二进制数据预览会在你将指针悬停在它上面时说明它包含什么，并直接由其字节绘制出图片。NoSQLBooster 以“Binary Image Preview Tooltip”提供了同样的功能。

## 出现的位置

- **单元格值：** 在“文档”中将指针悬停在二进制值上，会说明它包含什么——`PNG 图片 · 320 × 200 · 24 KB`、`PDF 文档 · 1.2 MB`、`ZIP 压缩包`、`MP3 音频`、`HEIC 图片`、`QuickTime 视频`——其他情况则显示其子类型和长度。应用只会向插件发送该值的前 2 KB，绝不会发送整个值。
- **“图片”标签页：** 集合文档中存储的图片（PNG、JPEG、GIF、WebP、AVIF、BMP 和 SVG），在“文档”筛选范围内，每次 12 张。点击可放大查看一张；**打开文档**会在应用中打开其文档。
- **显示图片**（文档的操作）：该文档的图片。

## 读取方式

标签页首先最多读取 50 个文档，以找出哪些字段包含图片——只取应用一条 1 MB 消息能容纳的数量；如果第一个文档本身就超过上限，则逐个读取前 10 个——然后只读取这些字段和 `_id`，按 `_id` 顺序逐页读取，并涵盖所有类型的 `_id`。超过上限的一页只包含能容纳的文档，下一页从它们之后继续；只有当第一个文档本身就超过上限时才逐个读取，即使单独一个也过大的文档会被计数，标签页会说明有多少个需要在“文档”中打开。放大的图片会让键盘焦点一直留在其中，直到将其关闭（Escape 或**关闭**），之后焦点会回到它的缩略图上。

图片由该值自身的字节以 `data:` 地址绘制；插件的页面不得加载任何其他内容，作为图片显示的 SVG 不会运行任何脚本。UUID 绝不会被当作文件。

## 权限

- **读取文档：** 用于查找和显示图片，使用你自己的权限，你的隐藏字段仍保持隐藏。
