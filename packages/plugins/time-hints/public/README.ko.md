# 시간 힌트

시간 힌트는 날짜를 숨기고 있는 값 위에 읽기 쉬운 날짜를 보여 줍니다. ObjectId는 처음 4바이트에 생성된 초를 담고 있으며, 많은 컬렉션이 시간을 Unix 타임스탬프(1970년 이후의 초 또는 밀리초)로 저장합니다. 시간 힌트는 이러한 시점을 도큐먼트에서 앱의 언어와 사용자의 현지 시간으로 보여 주므로 직접 해독할 필요가 없습니다.

플러그인에는 자체 페이지가 없으며 데이터베이스에서 아무것도 읽지 않습니다. 앱이 이미 표시하고 있는 값만 살펴봅니다.

## 표시되는 위치

- **셀 값:** 도큐먼트에서 ObjectId에 포인터를 올리면 생성된 시점.
- **셀 값:** Unix 시간으로 읽히는 숫자에 포인터를 올리면 `≈`가 붙은 날짜.

둘 다 도큐먼트가 값을 보여 주는 모든 곳(테이블, 트리, 카드, 도큐먼트 검사기)에서 해당 셀이나 행에 포인터를 올리거나 키보드 포커스가 이동했을 때 나타나는 툴팁에 표시됩니다. 첫 줄에는 값 전체가, 그 아래에는 플러그인 이름 뒤에 시간이 표시됩니다. 값 옆에는 아무것도 쓰이지 않으며 도큐먼트 자체에도 아무것도 추가되지 않습니다. 스크린 리더는 값과 함께 시간을 읽어 줍니다.

## 사용 방법

열거나 설정할 것은 없습니다. 관리자가 플러그인을 승인하고 활성화하면 모든 사용자의 도큐먼트에 힌트가 표시됩니다.

## 예시

다음과 같은 도큐먼트가 있다고 합시다.

```json
{
  "_id": { "$oid": "652629f0c3e5b2a1d4f0a9b7" },
  "createdAt": 1696999920,
  "updatedAtMs": 1697003520000,
  "quantity": 3
}
```

이스탄불에 있는 사용자가 앱을 한국어로 사용하면 다음과 같은 툴팁이 표시됩니다.

```
_id           포인터를 올리면:  ObjectId("652629f0c3e5b2a1d4f0a9b7")
                               시간 힌트: 2023. 10. 11. 오전 7:52
createdAt     포인터를 올리면:  1696999920
                               시간 힌트: ≈ 2023. 10. 11. 오전 7:52
updatedAtMs   포인터를 올리면:  1697003520000
                               시간 힌트: ≈ 2023. 10. 11. 오전 8:52
quantity      툴팁 없음
```

`quantity`에는 힌트가 붙지 않습니다. 3은 Unix 시간의 범위에 들지 않기 때문입니다.

## 시간으로 읽는 값

- **ObjectId:** 항상. 처음 16진수 8자리가 초 단위의 생성 시간입니다. 이 시간은 ID가 생성된 시점이며, 보통 도큐먼트를 삽입한 프로그램의 드라이버가 생성하므로 삽입된 시점과 항상 같지는 않습니다.
- **숫자:** 1,000,000,000 이상 4,102,444,800 미만의 int, long 또는 double은 초로, 같은 범위의 1,000배는 밀리초로 읽습니다. 이는 2001년 9월 9일부터 2099년 말까지에 해당합니다.

숫자는 추측일 뿐입니다. 이 범위의 가격, 개수, 전화번호에도 날짜가 붙습니다. 숫자 힌트가 `≈`로 시작하는 이유입니다. 실제 BSON 날짜로 저장된 날짜는 앱이 직접 표시하므로 힌트가 필요하지 않습니다.

## 형식

- 날짜와 시간은 앱의 언어를 따릅니다. 중간 길이 날짜와 짧은 시간입니다(예: 영어는 `Oct 11, 2023, 7:52 AM`, 터키어는 `11 Eki 2023 07:52`).
- 시간대는 브라우저의 현지 시간대입니다.
- 앱의 언어를 바꾸면 힌트가 새 언어로 다시 표시됩니다.

## 권한

- **도큐먼트 읽기** (`documents:read`): 앱은 도큐먼트 읽기가 허용된 플러그인에만 셀의 값을 전달합니다. 시간 힌트는 페이지에 있는 값을 받을 뿐 데이터베이스를 직접 쿼리하지 않습니다.

없음.

## 제한 사항

- ObjectId와 일반 숫자만 읽습니다. 텍스트(`"2023-10-11T07:52:00Z"`)나 10진수(`$numberDecimal`)로 저장된 시간에는 힌트가 붙지 않습니다.
- 표시되는 가장 작은 단위는 초이며 밀리초는 표시되지 않습니다.
- 1,000,000,000초 미만(2001년 9월 이전)이거나 2100년 이후의 숫자는 시간으로 읽지 않습니다.
- 힌트는 앱이 표시하는 값을 따릅니다. 중첩된 객체 안의 값은 앱이 그 중첩된 값을 셀로 표시하는 곳에서 힌트가 붙습니다.
