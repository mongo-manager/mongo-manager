# 時刻のヒント

時刻のヒントは、日付を隠し持っている値の上に読みやすい日付を表示します。ObjectId は先頭の 4 バイトに作成された秒を持っており、多くのコレクションは時刻を Unix タイムスタンプ（1970 年からの秒数またはミリ秒数）として保存しています。時刻のヒントは、これらの時点をドキュメントにアプリの言語とお使いのローカル時間で表示するので、自分で変換する必要がありません。

このプラグインには専用のページがなく、データベースからは何も読み取りません。アプリがすでに表示している値だけを見ます。

## 表示される場所

- **セルの値:** ドキュメントで ObjectId にポインターを合わせると、その作成日時。
- **セルの値:** Unix 時間に見える数値にポインターを合わせると、その日付。`≈` が付きます。

どちらも、ドキュメントが値を表示するあらゆる場所（テーブル、ツリー、カード、ドキュメントインスペクター）で、セルまたは行にポインターを合わせたとき、あるいはキーボードのフォーカスがそこに移ったときに表示されるツールチップに現れます。1 行目に値の全体、その下にプラグイン名に続けて時刻が表示されます。値の横には何も書き込まれず、ドキュメント自体にも何も追加されません。スクリーンリーダーは時刻を値と一緒に読み上げます。

## 使い方

開いたり設定したりするものはありません。管理者がプラグインを承認して有効にすると、ヒントは全員のドキュメントに表示されます。

## 例

次のようなドキュメントは、

```json
{
  "_id": { "$oid": "652629f0c3e5b2a1d4f0a9b7" },
  "createdAt": 1696999920,
  "updatedAtMs": 1697003520000,
  "quantity": 3
}
```

イスタンブールにいて、アプリを日本語で使っているユーザーには、次のツールチップで表示されます。

```
_id           ポインターを合わせると:  ObjectId("652629f0c3e5b2a1d4f0a9b7")
                                       時刻のヒント: 2023/10/11 7:52
createdAt     ポインターを合わせると:  1696999920
                                       時刻のヒント: ≈ 2023/10/11 7:52
updatedAtMs   ポインターを合わせると:  1697003520000
                                       時刻のヒント: ≈ 2023/10/11 8:52
quantity      ツールチップなし
```

`quantity` にはヒントが付きません。3 は Unix 時間の範囲に入っていないためです。

## 時刻として読まれるもの

- **ObjectId:** 常に。先頭の 16 進数 8 桁が秒単位の作成時刻です。この時刻は ID が生成された時点のもので、通常はドキュメントを挿入したプログラムのドライバーが生成するため、挿入された瞬間とは限りません。
- **数値:** 1,000,000,000 以上 4,102,444,800 未満の int、long、double は秒として、同じ範囲の 1,000 倍はミリ秒として読まれます。これは 2001 年 9 月 9 日から 2099 年末までをカバーします。

数値はあくまで推測です。この範囲にある価格、個数、電話番号にも日付が付きます。数値のヒントが `≈` で始まるのはそのためです。本物の BSON 日付として保存されている日付はアプリ自身が表示するので、ヒントは不要です。

## 書式

- 日付と時刻はアプリの言語を使います。中程度の長さの日付と短い時刻です（例: 英語では `Oct 11, 2023, 7:52 AM`、トルコ語では `11 Eki 2023 07:52`）。
- タイムゾーンはブラウザーのローカルタイムゾーンです。
- アプリの言語が変わると、ヒントは新しい言語で表示し直されます。

## 権限

- **ドキュメントの読み取り**（`documents:read`）: アプリは、ドキュメントの読み取りを許可されたプラグインにだけ、セルの値を渡します。時刻のヒントはページ上の値を受け取るだけで、自分でデータベースにクエリを送ることはありません。

## 設定

なし。

## 制限

- 読み取られるのは ObjectId と通常の数値だけです。テキスト（`"2023-10-11T07:52:00Z"`）や小数（`$numberDecimal`）として保存された時刻にはヒントが付きません。
- 表示される最小の単位は秒で、ミリ秒は表示されません。
- 1,000,000,000 秒未満（2001 年 9 月より前）または 2100 年以降の数値は時刻として読まれません。
- ヒントはアプリが表示する値に従います。ネストされたオブジェクトの中の値には、アプリがそのネストされた値をセルとして表示する場所でヒントが付きます。
