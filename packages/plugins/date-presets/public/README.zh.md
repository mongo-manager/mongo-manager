# 日期筛选

日期筛选只需一次点击，就能把人们常用的日期范围（今天、最近 7 天、本月）放进“文档”查询，无需再手写 `{ createdAt: { $gte: ISODate("…"), $lt: ISODate("…") } }`。

该插件只读取，不会更改数据库中的任何内容：它会在“文档”查询中写入一个筛选条件，该查询的运行方式与你自己输入的任何查询相同。

## 出现的位置

- **集合标签页：** 在每个集合和视图中，“文档”、“聚合”等标签页旁边会多出一个**日期**标签页。

## 如何使用

打开一个集合，然后打开**日期**标签页。插件会读取 200 个随机文档来找出包含日期的字段，并选中出现最多的那个；**字段**会列出其他候选，也可以直接输入任何字段。

选择一个范围：

- **快捷范围：** 今天、昨天、最近 24 小时、最近 7 天、最近 30 天、本周、上周、本月、上月、今年。每一项都会显示它涵盖的日期。
- **最近：** 最近 n 小时（到现在为止）、截至今天结束的最近 n 天或 n 周（每周 7 天），或最近 n 个月，即完整的日历月，包括当前月。
- **两天之间：** 从某一天的开始到另一天的结束。

点击后，会在“文档”查询中为该字段设置选取此范围的筛选条件，查询随即运行。

**按以下时区划分日期**用于指定每天从浏览器时间的午夜开始，还是从 UTC 的午夜开始。每周从星期一开始（ISO 8601）。

## 关于 _id

当 `_id` 包含 ObjectId 时，它也会被列出：ObjectId 以其创建时的秒数开头，因此对 `_id` 设置范围可选取在该范围内创建的文档，即使集合中没有任何日期字段也可以。它还会用到 `_id` 索引。

## 示例

在 2026 年 10 月 28 日星期三，对 `createdAt` 选择**本周**，会在“文档”中放入：

```
{ createdAt: { $gte: ISODate("2026-10-26T00:00:00Z"), $lt: ISODate("2026-11-02T00:00:00Z") } }
```

（以 UTC 计；按浏览器时间时，则是同样的日期，从其本地午夜开始。）

## 权限

- **读取文档**（`documents:read`）：用于读取找出日期字段的样本，以及在“文档”查询中放入筛选条件。

读取通过应用进行，使用已登录用户的权限和字段掩码：被隐藏的值，插件看不到。插件无法读取其他集合。

## 设置

无。

## 限制

- 日期字段是在 200 个随机文档的样本中找出的；少见的字段可能不会列出，但可以手动输入。
- 文档较大时（例如 API 日志），样本只包含页面一次应答（1 MB）能容纳的文档。
- 范围对每个文档都相同：以文本或秒数形式存储的日期，对它来说不是日期。
- 范围按点击按钮那一刻计算。
