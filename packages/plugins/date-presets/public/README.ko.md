# 날짜 필터

날짜 필터는 사람들이 자주 쓰는 날짜 범위(오늘, 최근 7일, 이번 달)를 클릭 한 번으로 도큐먼트 쿼리에 설정합니다. 따라서 `{ createdAt: { $gte: ISODate("…"), $lt: ISODate("…") } }` 같은 쿼리를 직접 작성할 필요가 없습니다.

이 플러그인은 읽기만 합니다. 데이터베이스의 어떤 것도 변경하지 않습니다. 도큐먼트 쿼리에 필터를 작성하며, 그 쿼리는 직접 입력한 쿼리와 똑같이 실행됩니다.

## 표시되는 위치

- **컬렉션 탭:** 모든 컬렉션과 뷰에서 도큐먼트, 집계 및 다른 탭 옆에 **날짜** 탭이 표시됩니다.

## 사용 방법

컬렉션을 연 다음 **날짜** 탭을 엽니다. 플러그인은 무작위 도큐먼트 200개를 읽어 날짜가 들어 있는 필드를 찾고 가장 많이 쓰인 필드를 선택합니다. **필드**에서 다른 필드를 고를 수 있고, 어떤 필드든 직접 입력할 수도 있습니다.

범위를 선택합니다.

- **빠른 범위:** 오늘, 어제, 최근 24시간, 최근 7일, 최근 30일, 이번 주, 지난주, 이번 달, 지난달, 올해. 각 항목에 포함되는 날짜가 표시됩니다.
- **최근:** 최근 n시간(지금까지), 오늘 끝까지의 최근 n일 또는 n주(1주는 7일), 또는 최근 n개월(현재 달을 포함한 온전한 달력 월).
- **두 날짜 사이:** 한 날의 시작부터 다른 날의 끝까지.

클릭하면 해당 범위를 필드에서 선택하는 필터가 도큐먼트 쿼리에 설정되고, 쿼리가 실행됩니다.

**날짜 기준 시간대**는 하루가 브라우저 시간의 자정에 시작하는지, UTC의 자정에 시작하는지를 정합니다. 한 주는 월요일에 시작합니다(ISO 8601).

## _id에서

`_id`에 ObjectId가 들어 있으면 `_id`도 선택할 수 있습니다. ObjectId는 생성된 시점의 초로 시작하므로, `_id`의 범위는 날짜 필드가 없는 컬렉션에서도 그 범위에 생성된 도큐먼트를 선택합니다. 또한 `_id` 인덱스를 사용합니다.

## 예시

2026년 10월 28일 수요일에 `createdAt`에서 **이번 주**를 선택하면 도큐먼트에 다음이 설정됩니다.

```
{ createdAt: { $gte: ISODate("2026-10-26T00:00:00Z"), $lt: ISODate("2026-11-02T00:00:00Z") } }
```

(UTC 기준이며, 브라우저 시간 기준에서는 같은 날짜가 브라우저의 자정을 기준으로 계산됩니다.)

## 권한

- **도큐먼트 읽기** (`documents:read`): 날짜 필드를 찾는 샘플을 읽고, 도큐먼트 쿼리에 필터를 설정하기 위해 필요합니다.

읽기는 로그인한 사용자의 권한과 필드 마스킹이 적용된 채 앱을 통해 이루어집니다. 숨겨진 값은 플러그인이 볼 수 있는 날짜가 아닙니다. 플러그인은 다른 컬렉션을 읽을 수 없습니다.

## 설정

없음.

## 제한 사항

- 날짜 필드는 무작위 도큐먼트 200개의 샘플에서 찾습니다. 드물게 쓰이는 필드는 목록에 없을 수 있지만, 직접 입력할 수 있습니다.
- 범위는 모든 도큐먼트에 동일하게 적용됩니다. 텍스트로 저장되었거나 초 단위 숫자로 저장된 날짜는 날짜로 취급되지 않습니다.
- 범위는 버튼을 클릭한 시점을 기준으로 계산됩니다.
