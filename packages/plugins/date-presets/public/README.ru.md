# Фильтры по дате

«Фильтры по дате» одним щелчком задают в запросе «Документы» диапазоны дат, по которым часто фильтруют (сегодня, последние 7 дней, этот месяц), так что не нужно вручную писать `{ createdAt: { $gte: ISODate("…"), $lt: ISODate("…") } }`.

Плагин только читает. Он ничего не изменяет в базе данных: он записывает фильтр в запрос «Документы», который выполняется как любой запрос, введенный вами.

## Где он появляется

- **Вкладка коллекции:** вкладка **Даты** рядом с «Документами», «Агрегациями» и другими вкладками каждой коллекции и представления.

## Как пользоваться

Откройте коллекцию, затем вкладку **Даты**. Плагин читает 200 случайных документов, чтобы найти поля с датами, и выбирает самое распространенное; в списке **Поле** предлагаются остальные, а любое поле можно ввести вручную.

Выберите диапазон:

- **Быстрые диапазоны:** Сегодня, Вчера, Последние 24 часа, Последние 7 дней, Последние 30 дней, Эта неделя, Прошлая неделя, Этот месяц, Прошлый месяц, Этот год. Каждый показывает дни, которые он охватывает.
- **Последние:** последние n часов (до текущего момента), последние n дней или недель (по 7 дней) до конца сегодняшнего дня либо последние n месяцев — целые календарные месяцы, включая текущий.
- **Между двумя днями:** от начала одного дня до конца другого.

Щелчок записывает в запрос «Документы» фильтр, выбирающий диапазон по этому полю, и запрос выполняется.

**Дни по** определяет, начинаются ли дни в полночь по времени браузера или по UTC. Неделя начинается в понедельник (ISO 8601).

## Для _id

Если `_id` содержит ObjectId, он тоже предлагается: ObjectId начинается с секунды своего создания, поэтому диапазон по `_id` выбирает документы, созданные в этом диапазоне, даже в коллекции без поля с датой. Он также использует индекс по `_id`.

## Пример

В среду, 28 октября 2026 года, **Эта неделя** по полю `createdAt` записывает в «Документы»:

```
{ createdAt: { $gte: ISODate("2026-10-26T00:00:00Z"), $lt: ISODate("2026-11-02T00:00:00Z") } }
```

(по UTC; по времени браузера — те же дни, считая от его полуночи).

## Разрешения

- **Чтение документов** (`documents:read`): чтобы прочитать выборку, по которой находятся поля с датами, и записать фильтр в запрос «Документы».

Чтение выполняется через приложение с правами вошедшего пользователя и с маскированием полей: скрытое значение не является датой, которую плагин может увидеть. Плагин не может читать другие коллекции.

## Параметры

Нет.

## Ограничения

- Поля с датами ищутся в случайной выборке из 200 документов; редкое поле может не быть предложено, но его можно ввести вручную.
- При больших документах (например, журналах API) в выборку попадает лишь столько документов, сколько помещается в один ответ странице (1 MB).
- Диапазон одинаков для всех документов: дата, сохраненная как текст или как число секунд, для него датой не является.
- Диапазоны соответствуют моменту, когда нажата кнопка.
