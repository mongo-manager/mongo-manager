# 日付フィルター

日付フィルターは、今日・過去 7 日間・今月のようによく使われる日付範囲をワンクリックでドキュメントのクエリに設定します。`{ createdAt: { $gte: ISODate("…"), $lt: ISODate("…") } }` を手で書く必要はありません。

このプラグインは読み取りのみを行います。データベースの内容は何も変更しません。ドキュメントのクエリにフィルターを書き込み、そのクエリは自分で入力したクエリと同じように実行されます。

## 表示される場所

- **コレクションタブ:** すべてのコレクションとビューで、「ドキュメント」「集計」などのタブの横に**日付**タブが表示されます。

## 使い方

コレクションを開き、**日付**タブを開きます。プラグインは無作為に 200 件のドキュメントを読み取って日付を持つフィールドを見つけ、最も多いものを選びます。**フィールド**には他の候補が表示され、任意のフィールドを入力することもできます。

範囲を選びます。

- **クイック範囲:** 今日、昨日、過去 24 時間、過去 7 日間、過去 30 日間、今週、先週、今月、先月、今年。それぞれが対象とする日付が表示されます。
- **過去:** 過去 n 時間（現在まで）、今日の終わりまでの過去 n 日または n 週間（1 週間は 7 日）、または過去 n か月（現在の月を含む暦月単位）。
- **2 つの日付の間:** ある日の始まりから別の日の終わりまで。

クリックすると、そのフィールドで範囲を選択するフィルターがドキュメントのクエリに設定され、クエリが実行されます。

**日の区切り**では、日がブラウザーの時刻の午前 0 時に始まるか、UTC の午前 0 時に始まるかを選びます。週は月曜日から始まります（ISO 8601）。

## _id について

`_id` が ObjectId を持つ場合は、これも候補に表示されます。ObjectId は作成された秒から始まるため、`_id` に範囲を指定すると、その範囲内に作成されたドキュメントを選択できます。日付フィールドのないコレクションでも使えます。`_id` のインデックスも利用されます。

## 例

2026 年 10 月 28 日（水曜日）に `createdAt` で**今週**を選ぶと、ドキュメントには次が設定されます。

```
{ createdAt: { $gte: ISODate("2026-10-26T00:00:00Z"), $lt: ISODate("2026-11-02T00:00:00Z") } }
```

（UTC の場合。ブラウザーの時刻では、同じ日付がそのローカルの午前 0 時から始まります。）

## 権限

- **ドキュメントの読み取り**（`documents:read`）: 日付フィールドを見つけるためのサンプルを読み取り、ドキュメントのクエリにフィルターを設定するために使います。

読み取りはアプリを通じて、サインインしているユーザーの権限とフィールドマスクのもとで行われます。非表示の値は、プラグインから見える日付ではありません。プラグインは他のコレクションを読み取れません。

## 設定

なし。

## 制限

- 日付フィールドは無作為の 200 件のサンプルから見つけます。まれなフィールドは候補に出ないことがありますが、入力すれば使えます。
- 範囲はすべてのドキュメントで同じです。文字列や秒数として保存された日付は、プラグインにとって日付ではありません。
- 範囲は、ボタンをクリックした時点のものです。
