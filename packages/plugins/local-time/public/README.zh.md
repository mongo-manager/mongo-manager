# 本地时间

MongoDB 以 UTC 保存日期，“文档”页也按此显示：`2026-10-26T11:03:12.000Z`。本地时间插件把每个日期显示为日常读取时钟的样子——使用浏览器所在的时区，或自行设置的时区——并附带相对 UTC 的偏移，无需再心算加三个小时。这是 MongoDB Compass 反馈论坛上呼声最高的改进之一（“以本地时间而非 UTC 查看日期”）。

插件没有独立页面，也不会从数据库读取任何内容，只查看应用已在显示的日期。

## 显示位置

- **单元格的值：** 在“文档”中将鼠标指向某个日期时，显示该日期的本地时间：`2026年10月26日 14:03:12 (UTC+3)`。

凡是“文档”显示日期的地方（表格、树、卡片、文档检查器），都会在其单元格的提示框中显示；如在设置中选择，也可显示在值的旁边。文档本身不会增加任何内容，值仍是保存时的样子。

## 设置

由管理员在“插件”页面为所有人设置：

- **显示在日期旁边：** 关闭时，本地时间在提示框中；开启后，写在值的旁边。
- **时区：** IANA 名称，如 `Europe/Istanbul` 或 `America/New_York`。留空时，每个人看到的是各自浏览器的时区。浏览器不识别的名称按留空处理，且每个日期都会说明：`· 未知时区“Europe/Istambul”`。本身就是 UTC 的时区只标注一次：`(UTC)`。
- **附加距今多久：** 在日期后加上“3天前”或“2小时后”——四舍五入达到更大单位时改用该单位：显示“昨天”，而不是“24小时前”。

## 示例

例如这样的文档：

```json
{ "createdAt": { "$date": "2026-10-26T11:03:12Z" } }
```

对于身处伊斯坦布尔的人，显示为：`2026年10月26日 14:03:12 (UTC+3)`；如果设置了时区，则为 `2026年10月26日 14:03:12 (Europe/Istanbul, UTC+3)`。

1900 年之前或 2200 年之后的日期保持应用原有的显示方式。

## 权限

- **读取文档：** 单元格渲染器可看到其所回答的单元格的值；本插件只读取日期，并且只读取屏幕上的日期。
