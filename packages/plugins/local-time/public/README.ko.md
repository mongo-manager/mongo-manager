# 현지 시간

MongoDB는 날짜를 UTC로 저장하고, 도큐먼트 화면도 그대로 보여 줍니다: `2026-10-26T11:03:12.000Z`. 현지 시간 플러그인은 각 날짜를 시계를 읽는 방식대로(브라우저의 시간대 또는 직접 설정한 시간대로) UTC와의 오프셋과 함께 보여 주므로 머릿속으로 세 시간을 더할 필요가 없습니다. MongoDB Compass 피드백 포럼에서 가장 많이 요청된 개선 사항 중 하나입니다("날짜를 UTC가 아닌 현지 시간으로 보기").

이 플러그인에는 별도의 페이지가 없으며 데이터베이스에서 아무것도 읽지 않습니다. 앱이 이미 표시하고 있는 날짜만 살펴봅니다.

## 표시되는 위치

- **셀 값:** 도큐먼트에서 날짜 위에 마우스를 올리면 현지 시간으로 된 날짜가 나타납니다: `2026. 10. 26. 오후 2:03:12 (UTC+3)`.

도큐먼트가 날짜를 표시하는 모든 곳(테이블, 트리, 카드, 도큐먼트 검사기)에서 해당 셀의 툴팁에 나타나며, 설정에서 선택하면 값 옆에 표시됩니다. 도큐먼트 자체에는 아무것도 추가되지 않으며 값은 저장된 그대로입니다.

## 설정

관리자가 플러그인 페이지에서 모든 사용자를 대상으로 설정합니다.

- **날짜 옆에 표시:** 끄면 현지 시간이 툴팁에 표시되고, 켜면 값 옆에 함께 표시됩니다.
- **시간대:** `Europe/Istanbul`, `America/New_York` 같은 IANA 이름입니다. 비워 두면 각 사용자가 자신의 브라우저 시간대를 봅니다. 브라우저가 알지 못하는 이름은 빈 값으로 처리되며, 각 날짜에 그 사실이 표시됩니다: `· 알 수 없는 시간대 "Europe/Istambul"`. UTC 자체인 시간대는 한 번만 표기됩니다: `(UTC)`.
- **얼마나 전인지 추가:** 날짜 뒤에 "3일 전" 또는 "2시간 후"를 덧붙입니다. 반올림하여 상위 단위가 되면 그 단위로 표시합니다: "24시간 전"이 아니라 "어제".

## 예시

다음과 같은 도큐먼트는

```json
{ "createdAt": { "$date": "2026-10-26T11:03:12Z" } }
```

이스탄불에 있는 사용자에게 `2026. 10. 26. 오후 2:03:12 (UTC+3)`로 표시되며, 시간대를 설정했다면 `2026. 10. 26. 오후 2:03:12 (Europe/Istanbul, UTC+3)`로 표시됩니다.

1900년 이전 또는 2200년 이후의 날짜는 앱이 표시하는 그대로 둡니다.

## 권한

- **도큐먼트 읽기:** 셀 렌더러는 자신이 응답하는 셀의 값을 전달받습니다. 이 플러그인은 날짜만, 그것도 화면에 보이는 것만 읽습니다.
