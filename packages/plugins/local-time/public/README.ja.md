# ローカル時刻

MongoDB は日付を UTC で保存し、ドキュメントもそのまま `2026-10-26T11:03:12.000Z` のように表示します。ローカル時刻は、各日付を普段時計を読むとおりに、ブラウザーのタイムゾーン（または設定したタイムゾーン）で、UTC からのオフセットとともに表示します。頭の中で 3 時間を足す必要はもうありません。MongoDB Compass のフィードバックフォーラムで特に要望の多い変更のひとつです（「日付を UTC ではなくローカル時刻で表示」）。

このプラグインには専用のページがなく、データベースから何も読み取りません。アプリがすでに表示している日付だけを参照します。

## 表示される場所

- **セルの値:** ドキュメントで日付にポインターを合わせると、ローカル時刻の日付が表示されます: `2026/10/26 14:03:12 (UTC+3)`。

ドキュメントが日付を表示するすべての場所（テーブル、ツリー、カード、ドキュメントインスペクター）で、そのセルのツールチップに表示されます。設定で選べば、値の横にも表示できます。ドキュメント自体には何も追加されず、値は保存されたままです。

## 設定

管理者がプラグインページで、全員に対して設定します。

- **日付の横に表示:** オフの場合、ローカル時刻はツールチップに表示されます。オンの場合は値の横に表示されます。
- **タイムゾーン:** `Europe/Istanbul` や `America/New_York` のような IANA 名。空欄の場合は、各自のブラウザーのタイムゾーンが使われます。ブラウザーが認識しない名前は空欄として扱われ、各日付にその旨が表示されます: `· 不明なタイムゾーン "Europe/Istambul"`。UTC そのものであるタイムゾーンは 1 回だけ表示されます: `(UTC)`。
- **経過時間を追加:** 日付の後ろに「3 日前」や「2 時間後」を追加します。丸めた結果が上位の単位に達した場合は、その単位で表示されます。「24 時間前」ではなく「昨日」と表示されます。

## 例

次のようなドキュメントがあるとします。

```json
{ "createdAt": { "$date": "2026-10-26T11:03:12Z" } }
```

イスタンブールにいる人には `2026/10/26 14:03:12 (UTC+3)` と表示されます。タイムゾーンを設定した場合は `2026/10/26 14:03:12 (Europe/Istanbul, UTC+3)` です。

1900 年より前、または 2200 年より後の日付は、アプリの表示のままです。

## 権限

- **ドキュメントの読み取り:** セルレンダラーには、応答対象のセルの値が渡されます。このプラグインが読み取るのは日付のみで、画面に表示されているものだけです。
