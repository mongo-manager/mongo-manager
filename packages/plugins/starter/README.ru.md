# Привет, документы

«Привет, документы» показывает документы коллекции в простой таблице: `_id` и поля, которые есть у большинства документов. Это стартовый шаблон для плагинов Mongo Manager: он достаточно мал, чтобы прочитать его за несколько минут, и предназначен для того, чтобы вы заменили его своим плагином.

## Где он появляется

- **Вкладка коллекции:** вкладка **Привет** в каждой коллекции, после собственных вкладок приложения. Она показывает первые 50 документов, которые оставляет фильтр документов.
- **Страница:** **Привет, документы** на боковой панели. Если открыть ее при активной вкладке коллекции, она покажет первые 50 документов этой коллекции; если открыть откуда-то еще, она попросит сначала открыть коллекцию.

## Как пользоваться

- Откройте коллекцию и выберите вкладку **Привет**.
- Нажмите **Открыть** в строке, чтобы показать этот документ в разделе «Документы».
- Нажмите **Обновить**, чтобы прочитать документы заново, например после изменения фильтра документов.

Представления тоже работают: они помечены как доступные только для чтения, а плагин никогда ничего не записывает.

## Разрешения

- **Чтение документов** (`documents:read`): чтобы показать документы коллекции, в которой он открыт, от вашего имени, с вашими правами и маскированием приложения.

## Настройки

Нет.

## Ограничения

- Показывается не более 50 документов и не более четырех полей, кроме `_id`.
- Значения показываются одной строкой текста, обрезанной до 80 символов; вложенные документы и массивы показывают только размер.

## Свой плагин на основе этого

Замените этот README на README своего плагина: администраторы читают его на странице сведений о плагине, прежде чем одобрить его. Используйте только заголовки, абзацы, списки и код: ссылки, изображения, таблицы и HTML показываются как обычный текст.

Чтобы создать свой плагин:

1. Измените `id`, `name`, `version`, `author`, `repository` и вклады в `mongo-manager-plugin.json`.
2. Напишите свою страницу в `main.js` и `style.css`.
3. Пишите каждый текст на всех десяти языках приложения (английском, турецком, китайском, японском, испанском, португальском, корейском, немецком, французском и русском): каждый текст страницы и манифеста, каждую заметку в журнале изменений и этот README, с файлом `README.<lang>.md` рядом с `README.md` для каждого из остальных девяти.
4. Выполните `node scripts/pack.mjs`, чтобы получить `<id>-<version>.tgz`, или `node scripts/pack.mjs --folder <data-dir>/plugins`, чтобы попробовать плагин на своем сервере.
5. Опубликуйте архив как ресурс релиза GitHub.

Руководство по плагинам в документации Mongo Manager объясняет каждое поле, метод и правило.
