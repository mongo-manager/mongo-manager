# 안녕하세요, 도큐먼트

안녕하세요, 도큐먼트는 컬렉션의 도큐먼트를 간단한 표로 나열합니다. `_id`와 대부분의 도큐먼트에 있는 필드를 보여 줍니다. Mongo Manager 플러그인의 스타터 템플릿으로, 몇 분이면 읽을 수 있을 만큼 작고 직접 만든 플러그인으로 교체하도록 만들어졌습니다.

## 표시되는 위치

- **컬렉션 탭:** 모든 컬렉션에서 앱 자체 탭 뒤에 **안녕하세요** 탭이 표시됩니다. 도큐먼트 필터로 걸러진 처음 50개의 도큐먼트를 나열합니다.
- **페이지:** 사이드바의 **안녕하세요, 도큐먼트**. 컬렉션 탭이 활성화된 상태에서 열면 해당 컬렉션의 처음 50개 도큐먼트를 나열하고, 다른 곳에서 열면 먼저 컬렉션을 열라고 안내합니다.

## 사용 방법

- 컬렉션을 열고 **안녕하세요** 탭을 선택합니다.
- 행에서 **열기**를 클릭하면 해당 도큐먼트가 도큐먼트 화면에 표시됩니다.
- **새로고침**을 클릭하면 도큐먼트를 다시 읽습니다. 예를 들어 도큐먼트 필터를 바꾼 뒤에 사용합니다.

뷰도 사용할 수 있습니다. 뷰는 읽기 전용으로 표시되며, 플러그인은 아무것도 쓰지 않습니다.

## 권한

- **도큐먼트 읽기** (`documents:read`): 열린 컬렉션의 도큐먼트를 사용자의 권한과 앱의 마스킹을 적용하여 사용자로서 나열합니다.

## 설정

없음.

## 제한

- 최대 50개의 도큐먼트와, `_id` 외에 최대 네 개의 필드만 나열됩니다.
- 값은 한 줄의 텍스트로 표시되며 80자에서 잘립니다. 중첩된 도큐먼트와 배열은 크기만 표시됩니다.

## 이 템플릿으로 나만의 플러그인 만들기

이 README를 직접 만든 플러그인의 README로 바꾸세요. 관리자는 플러그인을 승인하기 전에 플러그인 세부 정보 페이지에서 이 문서를 읽습니다. 제목, 문단, 목록, 코드만 사용하세요. 링크, 이미지, 표, HTML은 일반 텍스트로 표시됩니다.

나만의 플러그인을 만들려면 다음과 같이 하세요.

1. `mongo-manager-plugin.json`에서 `id`, `name`, `version`, `author`, `repository`와 기여 항목을 바꿉니다.
2. `main.js`와 `style.css`에 페이지를 작성합니다.
3. 모든 텍스트를 앱의 10개 언어(영어, 튀르키예어, 중국어, 일본어, 스페인어, 포르투갈어, 한국어, 독일어, 프랑스어, 러시아어)로 모두 작성합니다. 페이지와 매니페스트의 모든 텍스트, 모든 변경 기록, 이 README가 대상이며, 나머지 9개 언어마다 `README.md` 옆에 `README.<lang>.md`를 둡니다.
4. `node scripts/pack.mjs`를 실행하여 `<id>-<version>.tgz`를 만들거나, `node scripts/pack.mjs --folder <data-dir>/plugins`를 실행하여 내 서버에서 시험합니다.
5. 아카이브를 GitHub 릴리스의 에셋으로 게시합니다.

Mongo Manager 문서의 플러그인 가이드에서 모든 필드, 메서드, 규칙을 설명합니다.
