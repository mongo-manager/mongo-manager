# こんにちは、ドキュメント

「こんにちは、ドキュメント」は、コレクションのドキュメントをシンプルな表で一覧表示します。`_id` と、ほとんどのドキュメントが持つフィールドを表示します。Mongo Manager プラグインのスターターテンプレートで、数分で読み終えられるほど小さく、ご自身のプラグインに置き換えて使うことを想定しています。

## 表示される場所

- **コレクションタブ：** すべてのコレクションに、アプリ標準のタブの後ろに **こんにちは** タブが表示されます。ドキュメントのフィルターで絞り込んだ先頭 50 件のドキュメントを一覧表示します。
- **ページ：** サイドバーの **こんにちは、ドキュメント**。コレクションのタブがアクティブな状態で開くと、そのコレクションの先頭 50 件のドキュメントを一覧表示します。それ以外の場所から開いた場合は、先にコレクションを開くよう案内します。

## 使い方

- コレクションを開き、**こんにちは** タブを選びます。
- 行の **開く** をクリックすると、そのドキュメントがドキュメント画面に表示されます。
- **再読み込み** をクリックすると、ドキュメントを読み直します。たとえばドキュメントのフィルターを変更した後などに使います。

ビューでも動作します。ビューは読み取り専用として表示され、プラグインは何も書き込みません。

## 権限

- **ドキュメントの読み取り**（`documents:read`）：開いたコレクションのドキュメントを、あなたの権限とアプリのマスキングに従い、あなたとして一覧表示するために使います。

## 設定

なし。

## 制限

- 一覧表示されるのは最大 50 件のドキュメントで、`_id` のほかに最大 4 つのフィールドです。
- 値は 1 行のテキストとして表示され、80 文字で切り詰められます。ネストされたドキュメントと配列はサイズのみ表示されます。

## このプラグインから自分のプラグインを作る

この README をご自身のプラグインのものに置き換えてください。管理者は、プラグインを承認する前に、プラグインの詳細ページでこれを読みます。見出し、段落、リスト、コードのみを使用してください。リンク、画像、表、HTML はプレーンテキストとして表示されます。

自分のプラグインを作るには：

1. `mongo-manager-plugin.json` の `id`、`name`、`version`、`author`、`repository` と、コントリビューションを変更します。
2. `main.js` と `style.css` にページを記述します。
3. すべてのテキストを、アプリの 10 言語すべて（英語、トルコ語、中国語、日本語、スペイン語、ポルトガル語、韓国語、ドイツ語、フランス語、ロシア語）で書きます。ページとマニフェストのすべてのテキスト、すべての変更履歴、この README が対象で、ほかの 9 言語それぞれについて `README.md` の横に `README.<lang>.md` を置きます。
4. `node scripts/pack.mjs` を実行して `<id>-<version>.tgz` を作成するか、`node scripts/pack.mjs --folder <data-dir>/plugins` を実行して自分のサーバーで試します。
5. アーカイブを GitHub リリースのアセットとして公開します。

Mongo Manager のドキュメントにあるプラグインガイドで、すべてのフィールド、メソッド、ルールを説明しています。
