# 你好，文档

“你好，文档”以简单的表格列出集合中的文档：`_id` 以及大多数文档都有的字段。它是 Mongo Manager 插件的入门模板，小到几分钟就能读完，目的是让你用自己的插件取代它。

## 出现的位置

- **集合标签页：** 每个集合上都有一个 **你好** 标签页，位于应用自带标签页之后。它列出文档筛选保留的前 50 个文档。
- **页面：** 侧边栏中的 **你好，文档**。在集合标签页处于活动状态时打开，会列出该集合的前 50 个文档；从其他位置打开，则会提示你先打开一个集合。

## 使用方法

- 打开一个集合，选择 **你好** 标签页。
- 点击某一行的 **打开**，即可在“文档”中显示该文档。
- 点击 **重新加载** 可再次读取文档，例如在更改文档筛选之后。

视图同样可用：它们会标记为只读，插件不会写入任何内容。

## 权限

- **读取文档**（`documents:read`）：以你的身份、按你的权限并应用应用的数据脱敏，列出其所打开集合中的文档。

## 设置

无。

## 限制

- 最多列出 50 个文档，除 `_id` 外最多四个字段。
- 值以单行文本显示，超过 80 个字符会被截断；嵌套文档和数组只显示其大小。

## 以此为基础制作你自己的插件

请用你自己插件的 README 替换本文件：管理员在批准插件之前，会在插件的详情页上阅读它。请只使用标题、段落、列表和代码：链接、图片、表格和 HTML 会显示为纯文本。

制作你自己的插件：

1. 在 `mongo-manager-plugin.json` 中修改 `id`、`name`、`version`、`author`、`repository` 以及各项贡献。
2. 在 `main.js` 和 `style.css` 中编写你的页面。
3. 用应用的全部十种语言（英语、土耳其语、中文、日语、西班牙语、葡萄牙语、韩语、德语、法语和俄语）编写每一段文本：页面和清单中的每一段文本、每一条更新说明，以及本 README；并在 `README.md` 旁为其他九种语言各添加一个 `README.<lang>.md`。
4. 运行 `node scripts/pack.mjs` 得到 `<id>-<version>.tgz`，或运行 `node scripts/pack.mjs --folder <data-dir>/plugins` 在你自己的服务器上试用。
5. 将该归档作为 GitHub 发布版本的资源文件发布。

Mongo Manager 文档中的“插件”指南说明了每个字段、方法和规则。
