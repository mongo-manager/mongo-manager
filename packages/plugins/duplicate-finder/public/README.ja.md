# 重複ドキュメント検索

重複ドキュメント検索は、コレクション内で一意であるべきフィールドの値を、複数のドキュメントが共有しているものを一覧表示します。たとえばメールアドレス、注文番号、姓と名の組み合わせなどです。各値には共有しているドキュメント数が付き、共有数の多い順に並びます。ドキュメント自体もワンクリックで開けます。

このプラグインは読み取りのみを行います。データベースの内容は何も変更しません。

## 表示される場所

- **コレクションのタブ:** すべてのコレクションとビューで、ドキュメント、集計などのタブの隣に表示される **重複** タブ。

## 使い方

1. コレクションを開き、**重複** タブに切り替えます。
2. **一意であるべきフィールド** の下にフィールド名を入力して Enter を押すか、**このコレクションのフィールド** の下に表示される候補のフィールドをクリックします。ネストしたフィールドはパスで入力します: `address.city`。カンマで区切って一度に入力した複数のフィールドは、まとめて追加されます。
3. 最大 5 つのフィールドを追加して、まとめて確認できます。その場合、すべてのフィールドが一致したときだけ重複とみなされます。
4. 下記のオプションを設定し、**重複を検索** を押します。

オプション:

- **大文字と小文字を区別しない:** `Ada@Example.com` と `ada@example.com` を同じ値として扱います。既定ではオフです。
- **フィールドがないドキュメントを除外:** 選択したフィールドがないか null のドキュメントはグループ化されません。既定ではオンです。フィールドを持たないドキュメントの数を確認したいときはオフにします。
- **検索範囲:** **コレクション全体**（既定）、または **ドキュメントのフィルター** に該当するドキュメントのみ。

結果には、見つかった重複値の数と、関係するドキュメントの数が表示されます。各行には値とその件数が表示されます。

- **ドキュメントを一覧表示** は行を開き、先頭の 20 件のドキュメントを表示します。**開く** はそのうちの 1 件をアプリで表示します。
- **表示**（または **すべてをドキュメントで表示**）は、その値のドキュメントを絞り込むフィルターをドキュメントのクエリに設定します。そこで全件をページ送りで確認できます。

## 例

`email` が一意であるべき `users` コレクションの場合です。`email` を選択し、**大文字と小文字を区別しない** をオンにして、**重複を検索** を押します。次のような行が表示されます。

```
ada@example.com     3 件のドキュメント
```

これは、3 人のユーザーが表記の違いはあるものの同じアドレスを共有していることを意味します。**表示** を押すと、その 3 件を絞り込むフィルターがドキュメントに設定され、どれを残すかをそこで判断できます。

二重に登録された人を探すには、`firstName` と `lastName` をまとめて選択します。2 つのフィールドがどちらも一致するドキュメントだけがグループ化されます。

## 仕組み

グループ化は、サーバー上で読み取り専用の集計パイプライン 1 本として実行されます。フィルター用の `$match`（フィールドがないものを除外する場合はそれも含む）、選択したフィールドでの `$group`、続いてドキュメントが 2 件以上あるグループを件数順に並べます。ブラウザーに返るのはグループだけで、コレクション全体が返ることはありません。

大文字と小文字を区別しない場合、テキスト値は小文字にして（`$toLower`）比較されます。それ以外の型はそのまま比較されます。

## 権限

- **ドキュメントの読み取り**（`documents:read`）: グループ化パイプラインの実行、フィールド候補のためのドキュメントの読み取り、グループのドキュメントの一覧表示に使用します。

読み取りはアプリを通じて、サインイン中のユーザーの権限とフィールドのマスクを適用して行われます。このプラグインは他のコレクションを読み取れません。

## 設定

なし。

## 制限

- 一度に最大 5 フィールド。
- 一覧表示される重複値は最大 200 件で、共有数の多い順です。それ以上ある場合、件数は「200+」と表示され、共有数の多い上位 200 件のみ表示している旨の注記が出ます。
- 各グループには先頭の 20 件のドキュメントが一覧表示されます。「表示」を使うと全件がドキュメントに設定されます。
- 候補のフィールドはコレクションの先頭 50 件のドキュメントから取得されます（候補は最大 12 件）。それ以外のフィールドも入力できます。
- 値は、大文字と小文字を区別しない場合を除き、保存されているとおりに厳密に比較されます。テキストとして保存された数値と、数値として保存された同じ数値は、別の値です。
- パイプラインは最大 10 秒間、ディスクを使わずに実行されます。非常に大きなコレクションでは、ドキュメントのフィルターで範囲を絞り込んでください。
