# 重复记录查找器

重复记录查找器会列出集合中本应唯一的字段里、被多个文档共有的值：例如电子邮件地址、订单号，或姓和名的组合。每个值都会标出共有它的文档数量，共有最多的排在前面，文档本身只需一次点击即可查看。

该插件只读取数据，不会更改数据库中的任何内容。

## 出现的位置

- **集合标签页：** 在每个集合和视图中，位于“文档”“聚合”及其他标签页旁边的 **重复项** 标签页。

## 使用方法

1. 打开一个集合，然后切换到 **重复项** 标签页。
2. 在 **应保持唯一的字段** 下输入字段名并按 Enter，或点击 **此集合中的字段** 下建议的某个字段。嵌套字段请输入其路径：`address.city`。一次输入的多个字段以逗号分隔，会一起添加。
3. 最多可添加五个字段一起检查：只有这些字段全部匹配时，文档才算重复。
4. 设置下面介绍的选项，然后点击 **查找重复项**。

选项：

- **忽略大小写：** `Ada@Example.com` 与 `ada@example.com` 视为同一个值。默认关闭。
- **排除缺少字段的文档：** 所选字段缺失或为 null 的文档不参与分组。默认开启；关闭后可查看有多少文档缺少该字段。
- **查找范围：** **整个集合**（默认），或仅限 **文档筛选** 中的文档。

结果会显示找到多少个重复值以及涉及多少个文档。每一行显示一个值及其数量：

- **列出文档** 会展开该行，显示其前 20 个文档；**打开** 会在应用中显示其中一个。
- **显示**（或 **在文档中查看全部**）会把用于筛选该值所对应文档的条件放入“文档”查询，在那里可以分页浏览全部文档。

## 示例

`users` 集合中的 `email` 应保持唯一。选择 `email`，开启 **忽略大小写**，然后点击 **查找重复项**。出现如下一行：

```
ada@example.com     3 个文档
```

表示有三位用户以不同的大小写写法共用了这个地址。**显示** 会把筛选这三个文档的条件放入“文档”，您可以在那里决定保留哪一个。

要找出被重复录入的人员，请同时选择 `firstName` 和 `lastName`：只有两个字段都匹配的文档才会被分为一组。

## 工作原理

分组在服务器上以一条只读聚合管道运行：先用 `$match` 处理筛选条件（若排除缺失字段，也在此处理），再对所选字段执行 `$group`，然后保留文档数多于一个的分组，并按数量排序。返回浏览器的只有这些分组，绝不会是整个集合。

忽略大小写时，文本值以小写形式（`$toLower`）比较；其他类型按原样比较。

## 权限

- **读取文档**（`documents:read`）：用于运行分组管道、读取少量文档以给出字段建议，以及列出某个分组的文档。

读取通过应用进行，使用已登录用户的权限和字段脱敏规则。该插件无法读取其他集合。

## 设置

无。

## 限制

- 一次最多 5 个字段。
- 最多列出 200 个重复值，共有最多的排在前面。超过时，数量显示为“200+”，并有提示说明仅列出共有最多的 200 个。
- 每个分组列出其前 20 个文档；“显示”会把全部文档放入“文档”。
- 建议的字段来自集合的前 50 个文档（最多 12 个建议）；其他任何字段都可以手动输入。
- 值按存储的原样精确比较，仅在忽略大小写时例外。以文本存储的数字与以数字存储的同一个数字是不同的值。
- 管道最多运行 10 秒，且不使用磁盘。对于非常大的集合，请用“文档”筛选缩小范围。
