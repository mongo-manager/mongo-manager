키보드 단축키

사용자 지정 키

아래 키는 앱에 기본으로 들어 있는 키입니다. 일반 단축키(명령 팔레트, 사이드바, 집중 모드, 고정, 단축키 목록, 쿼리, AI에게 묻기, 어시스턴트, 탭 이동, 분할 보기)는 계정 → 키보드 단축키에서 다른 키로 바꿀 수 있습니다. 변경을 선택한 다음 새 키를 누르세요. 다른 단축키가 쓰는 키, 브라우저나 편집 기능이 사용하는 키(복사, 붙여넣기, 탭 닫기, 새로 고침 등), 입력 중에 동작해 버리는 일반 문자나 기호는 이유와 함께 거부됩니다. 재설정은 한 단축키를 기본 키로 되돌리고(같은 키를 다시 눌러도 됩니다), 모두 초기화는 모든 단축키를 되돌립니다. 사용자의 키를 서버에서 읽어 오기 전에는 아무것도 변경할 수 없으며, 다시 시도를 누르면 다시 요청합니다. 최신 버전에서 더 이상 사용할 수 없는 키는 해당 단축키의 기본 키로 돌아가며, 설정에서 한 번 알려 줍니다. 사용자의 키는 서버에 저장되므로 다른 브라우저에서도 같은 키를 사용합니다. ? 목록, 명령 팔레트, 툴팁, 스크린 리더는 사용자의 키를 안내합니다. 편집기, 목록, 테이블, 다이어그램, 셸의 키는 그대로입니다.

워크스페이스 탭

탭 사이 이동 ← / → / Home / End
포커스된 탭 닫기 Delete
활성 탭을 왼쪽 또는 오른쪽으로 이동 Ctrl / ⌘ + Shift + ← / →
활성 탭을 이전 탭 옆에 열기, 분할 보기에서는 다른 창으로 이동 Ctrl / ⌘ + \
포커스된 탭의 메뉴 열기(옆에 열기, 창 닫기, 탭 닫기, 다른 탭 닫기) Shift + F10 / Menu
창 크기 조절(구분선에 포커스) ← / → / Home / End

분할 보기는 두 탭을 나란히 보여 줍니다. 탭 메뉴(화살표, 오른쪽 클릭 또는 Shift + F10)의 옆에 열기, 탭을 워크스페이스 오른쪽으로 끌어 놓기, 또는 Ctrl / ⌘ + \ 로 엽니다. 탭 막대는 하나이며, 화면에 보이는 두 탭에는 창 표시가 붙고, 탭 막대에서 선택한 탭은 사용 중인 창에서 열립니다. 사용 중인 창에는 강조 막대가 있고 활성 창이라고 표시됩니다. 다른 창을 사용하려면 클릭하거나 Tab 키로 이동하세요. 구분선을 끌거나 포커스를 두고 화살표 키를 사용해 너비를 나눕니다(20–80 %). 창 머리글의 창 닫기는 분할을 끝내고 두 탭을 모두 열어 둔 채 키보드 포커스를 해당 창에 남깁니다. 창의 탭을 닫아도 분할이 끝납니다. 홈은 분할을 끝내지 않고 숨깁니다. 분할의 탭을 선택하거나 홈에서 Ctrl / ⌘ + \ 를 누르면 다시 표시됩니다(유지된 분할이 없으면 홈에서 Ctrl / ⌘ + \ 가 마지막으로 사용한 두 탭을 나란히 놓습니다). Ctrl / ⌘ + \ 는 키보드 포커스를 사용 중인 창으로 옮기며, 창 사이를 이동해도 브라우저 기록에 항목이 추가되지 않습니다. 분할은 탭과 마찬가지로 새로 고침 후에도 복원됩니다. 너비가 768 px 미만이면 탭 하나만 표시되고(분할은 더 넓은 창에서 유지됩니다) 옆에 열기는 그냥 탭을 엽니다. 스크린 리더는 각 창을 탭 이름이 붙은 영역으로 인식합니다("orders, left pane").

다른 데이터베이스나 다른 페이지에서 작업하는 동안에는, 한 데이터베이스의 컬렉션 탭(두 개 이상이며, 데이터베이스 자체 탭이 열려 있으면 그 탭 포함)이 데이터베이스 이름과 탭 개수가 적힌 하나의 탭으로 묶입니다. 가리키거나 포커스하면 묶인 탭의 이름이 표시됩니다. 클릭하거나 Enter를 누르면 데이터베이스 자체가 열리고(열려 있지 않았다면 해당 탭을 열고) 묶인 탭이 다시 표시됩니다. 어디서든 그 컬렉션 중 하나를 열어도 다시 표시되며, 그 컬렉션이 활성 상태가 됩니다. 화살표 키는 이 탭에서 멈추고 열지 않습니다. Delete, 닫기 버튼, 마우스 가운데 클릭은 묶인 탭을 모두 닫으며, 실행 취소로 되돌릴 수 있습니다. Ctrl / ⌘ + Shift + 화살표는 활성 탭을 묶인 그룹 하나를 건너 이동시킵니다. 그룹은 끌어서 옮길 수 있습니다.
