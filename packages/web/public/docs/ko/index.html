개요

Mongo Manager는 브라우저에서 사용하는 안전한 MongoDB 관리 도구입니다. 텔레메트리, 업데이트 확인, CDN, 외부 글꼴 없이 완전히 오프라인으로 동작합니다. 브라우저는 Mongo Manager와만 통신하며, Mongo Manager는 사용자가 구성한 대상(MongoDB 배포와 SSH 호스트, 그리고 사용자가 켠 AI 제공업체, 백업 대상, GitHub 플러그인 설치)에만 접속합니다.

  • 시작하기 설치, 첫 실행, 첫 연결과 쿼리.
  • 보안 모드, 키, 2단계 로그인, 역할, 감사 로그.
  • 배포 시스템 서비스, Docker, 리버스 프록시, 오프라인 설치.
  • 가져오기 및 내보내기 CSV, JSON, NDJSON, Excel 파일, 필드 매핑, 모드, 시험 실행, 보고서.
  • 백업 및 복원 컬렉션, 데이터베이스 또는 서버를 암호화하거나 mongodump 아카이브로 백업하고, 계획·확인 절차·시험 실행과 함께 어디에든 복원합니다.
  • 서버 관리 MongoDB 사용자와 역할, 샤딩과 존, 이메일 및 웹훅 알림, 각 연결의 실시간 상태.
  • AI 도우미 쿼리, 파이프라인, 유효성 검사기를 자연어로 요청하고, 쿼리를 설명하거나 빠르게 만들고, 컬렉션을 설명합니다. 클라우드 모델과 로컬 모델을 모두 사용할 수 있습니다.
  • 플러그인 나만의 탭, 동작, 페이지를 만듭니다. 매니페스트, 브리지 API, 샌드박스와 보안 검사, GitHub 패키징 및 게시, 시작 템플릿, AI 코딩 도우미용 파일을 다룹니다.
