概要

Mongo Manager は、ブラウザーで使える安全な MongoDB 管理ツールです。完全にオフラインで動作し、テレメトリ、更新確認、CDN、外部フォントは一切使いません。ブラウザーが通信する相手は Mongo Manager だけで、Mongo Manager が接続するのは、お客様が設定したもの（MongoDB のデプロイメントと SSH ホスト、および有効にした AI プロバイダー、バックアップ先、GitHub からのプラグインインストール）だけです。

  • はじめに インストール、初回起動、最初の接続とクエリ。
  • セキュリティ モード、キー、二要素サインイン、ロール、監査ログ。
  • デプロイメント システムサービス、Docker、リバースプロキシ、オフラインインストール。
  • インポートとエクスポート CSV、JSON、NDJSON、Excel ファイル、フィールドのマッピング、モード、ドライラン、レポート。
  • バックアップとリストア コレクション、データベース、サーバーのバックアップ。暗号化または mongodump アーカイブで取得し、プラン、確認、ドライランを経てどこにでもリストアできます。
  • サーバー管理 MongoDB のユーザーとロール、シャーディングとゾーン、メールと Webhook によるアラート、各接続のリアルタイムの状態。
  • AI アシスタント クエリ、パイプライン、検証ルールを普通の言葉で依頼したり、クエリの説明や高速化、コレクションの説明を任せたりできます。クラウドモデルもローカルモデルも使えます。
  • プラグイン 独自のタブ、アクション、ページを作成できます。マニフェスト、ブリッジ API、サンドボックスとセキュリティスキャン、GitHub でのパッケージ化と公開、スターターテンプレート、AI コーディングアシスタント向けのファイルを扱います。
  • キーボードショートカット アプリ内のどこでも ? を押すと一覧が表示されます。
