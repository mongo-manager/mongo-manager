キーボードショートカット

独自のキー設定

以下のキーは、アプリの初期設定です。一般的なショートカット（コマンドパレット、サイドバー、フォーカスモード、ピン留め、ショートカット一覧、クエリ、AI に質問、アシスタント、タブの移動、分割表示）は、アカウント → キーボードショートカットで別のキーに変更できます。変更をクリックして、新しいキーを押してください。ほかのショートカットが使っているキー、ブラウザーや編集操作が使うキー（コピー、貼り付け、タブを閉じる、再読み込みなど）、入力中にも反応してしまう単独の文字や記号は、理由が表示されて拒否されます。リセットはショートカット 1 つを初期のキーに戻し（同じキーをもう一度押しても戻せます）、すべてリセットはすべてを戻します。キーの設定がサーバーから読み込まれるまでは何も変更できません。再試行でもう一度読み込みます。新しいバージョンで使えなくなったキーはそのショートカット本来のキーに戻り、設定画面で一度だけ知らされます。キーの設定はサーバー上にユーザーごとに保存されるため、ほかのブラウザーでも同じ設定が使えます。? の一覧、コマンドパレット、ツールチップ、スクリーンリーダーには、設定したキーが表示されます。エディター、リスト、テーブル、ダイアグラム、シェルのキーは変更できません。

一般

コマンドパレットを開く Ctrl / ⌘ + K
接続パネルを表示または非表示にする Ctrl / ⌘ + B
フォーカスモード: タブ周囲のパネルを非表示または表示 Ctrl / ⌘ + Shift + F
開いているタブの場所をホームにピン留め、またはピン留め解除 Ctrl / ⌘ + Shift + P
コマンドパレットの結果を移動 ↑ / ↓
開いているコレクションのクエリバーへ移動 /
これらのショートカットを表示 ?
クエリを開く Ctrl / ⌘ + Shift + L
コレクションについて AI アシスタントに質問する Ctrl / ⌘ + I
アシスタントを開く、または閉じる Ctrl / ⌘ + .
ダイアログ、メニュー、ポップオーバーを閉じる Escape

複数行エディターから実行または保存する Ctrl / ⌘ + Enter
複数行エディターでインデントする Tab
複数行エディターを離れる（Escape、次に Tab） Escape + Tab
候補を移動 ↑ / ↓
候補を確定する Tab / Enter
候補を閉じる Escape

アシスタント

メッセージを送信する Enter
メッセージ内で改行する Shift + Enter
ワークスペースに戻る Escape
アシスタントの幅を広げる、または狭める（区切りにフォーカス中） ← / →

ワークスペースのタブ

タブ間を移動する ← / → / Home / End
フォーカス中のタブを閉じる Delete
アクティブなタブを左または右に移動する Ctrl / ⌘ + Shift + ← / →
アクティブなタブを前のタブの横に開く。分割表示では、もう一方のペインへ移動 Ctrl / ⌘ + \
フォーカス中のタブのメニューを開く（横に開く、ペインを閉じる、タブを閉じる、他のタブを閉じる） Shift + F10 / Menu
ペインのサイズを変更する（仕切りにフォーカスがあるとき） ← / → / Home / End

分割表示では、2 つのタブを左右に並べて表示します。タブのメニュー（矢印、右クリック、または Shift + F10）の横に開くから開くか、タブをワークスペースの右側へドラッグするか、Ctrl / ⌘ + \ を押します。タブバーは 1 つだけで、画面に表示されている 2 つのタブにはペインの目印が付き、タブバーで選んだタブは使用中のペインで開きます。使用中のペインにはアクセントバーが付き、アクティブなペインと表示されます。もう一方を使うには、クリックするか Tab キーで移動してください。仕切りをドラッグするか、フォーカスして矢印キーを押すと、幅の配分を変えられます（20～80 %）。ペインのヘッダーにあるペインを閉じるは、分割を終了して両方のタブを開いたままにします。キーボードのフォーカスは残ったペインに移ります。ペインのタブを閉じても分割は終了します。ホームでは分割が終了せずに非表示になります。分割中のタブのどれかを選ぶか、ホームで Ctrl / ⌘ + \ を押すと、再び表示されます（分割が保持されていない場合、ホームで Ctrl / ⌘ + \ を押すと、直前に使った 2 つのタブが並んで表示されます）。Ctrl / ⌘ + \ は、キーボードのフォーカスを使用中のペインに移します。ペイン間の移動でブラウザーの履歴に項目が増えることはありません。分割はタブと同様に、再読み込み後も復元されます。幅が 768 px 未満のときは 1 つのタブだけが表示され（分割はより広いウィンドウのために保持されます）、横に開くは単にそのタブを開きます。スクリーンリーダーは、各ペインをタブ名が付いたリージョン（「orders、左ペイン」）として認識します。

別のデータベースや別のページなど、ほかの場所で作業している間は、データベースのコレクションタブ（2 つ以上。データベース自体のタブが開いていればそれも含む）が、データベース名と保持しているタブ数を付けた 1 つのタブにまとまります。ポイントするかフォーカスすると、まとまったタブの名前が表示されます。クリックするか Enter を押すと、データベース自体が開き（開いていなければタブが開きます）、まとまっていたタブが再び表示されます。どこからでもそのコレクションのどれかを開いた場合も、そのコレクションをアクティブにして再び表示されます。矢印キーはこのタブで止まり、開きません。Delete、閉じるボタン、中クリックのいずれかですべてを閉じられ、元に戻すで復元できます。Ctrl / ⌘ + Shift + 矢印は、アクティブなタブをまとまったグループの向こう側へ 1 つの塊として移動します。グループはドラッグもできます。

シェル

コードを実行（括弧、文字列、ステートメントが開いている間は入力を継続） Enter
改行を挿入する Shift + Enter
コードをそのまま実行する Ctrl + Enter
実行中のコマンドを停止、または行をクリア（出力を選択中はコピー） Ctrl + C
コマンド履歴を検索（もう一度押すと古い一致へ） Ctrl + R
画面と結果をクリアする Ctrl + L
行間を移動し、その後は前後のコマンドへ移動 ↑ / ↓
行頭と行末 Home / End (Ctrl + A / Ctrl + E)
行頭まで、または行末まで削除 Ctrl + U / Ctrl + K
単語単位で前後に移動 Alt + B / Alt + F (Ctrl + ← / Ctrl + →；Mac では Option)
カーソルの前、または後の単語を削除 Ctrl + W / Alt + D (Ctrl + Backspace / Ctrl + Delete)
コマンドを補完する Tab
ターミナルを離れる Shift + Tab

シェルページ

結果の幅を広げる、または狭める（ハンドル上で） ← / →
より大きな単位でサイズを変更する（ハンドル上で） Shift + 矢印キー
結果を最小幅または最大幅にする（ハンドル上で） Home / End
ターミナルと結果の間（狭い画面）、または結果ビュー間を移動する ← / →
