Raccourcis clavier

Vos propres touches

Les touches ci-dessous sont celles fournies avec l’application. Les raccourcis généraux — la palette de commandes, la barre latérale, le mode focus, l’épinglage, la liste des raccourcis, les requêtes, Interroger l’IA, l’assistant, le déplacement d’un onglet et la vue fractionnée — peuvent recevoir d’autres touches dans Compte → Raccourcis clavier : choisissez Modifier, puis appuyez sur les nouvelles touches. Sont refusées, avec la raison, les touches déjà utilisées par un autre raccourci, celles que le navigateur ou l’édition se réservent (copier, coller, fermer un onglet, recharger…) et une simple lettre ou un simple signe qui se déclencherait pendant la saisie. Réinitialiser rend à un raccourci ses touches d’origine (tout comme un nouvel appui sur ces touches), Tout réinitialiser le fait pour chacun d’eux ; rien ne peut être modifié tant que vos touches n’ont pas été lues depuis le serveur, et Réessayer relance la lecture. Les touches qu’une version plus récente ne peut plus utiliser reviennent à celles du raccourci, et les paramètres l’indiquent, une seule fois. Vos touches sont conservées pour vous sur le serveur, vos autres navigateurs les ont donc aussi ; la liste affichée par ?, la palette de commandes, les infobulles et les lecteurs d’écran citent vos touches. Les touches des éditeurs, des listes, des tableaux, du diagramme et du shell restent inchangées.

La vue fractionnée affiche deux onglets côte à côte. Ouvrez-la avec Ouvrir à côté dans le menu d’un onglet (sa flèche, un clic droit ou Shift + F10), en faisant glisser un onglet vers le côté droit de l’espace de travail, ou avec Ctrl / ⌘ + \. Il n’y a qu’une seule barre d’onglets : les deux onglets affichés portent un repère de volet, et un onglet choisi dans la barre s’ouvre dans le volet utilisé. Le volet utilisé porte la barre d’accent et indique Volet actif ; cliquez dans l’autre, ou placez-y le focus avec Tab, pour l’utiliser. Faites glisser le séparateur, ou donnez-lui le focus et utilisez les flèches, pour répartir la largeur (20–80 %). Fermer le volet, dans l’en-tête d’un volet, met fin à la vue fractionnée et garde les deux onglets ouverts, le focus du clavier restant dans le volet ; fermer l’onglet d’un volet y met fin aussi. L’accueil masque la vue fractionnée sans y mettre fin : choisir l’un de ses onglets, ou Ctrl / ⌘ + \ sur l’accueil, l’affiche de nouveau (si aucune vue fractionnée n’est conservée, Ctrl / ⌘ + \ sur l’accueil place côte à côte les deux derniers onglets utilisés). Ctrl / ⌘ + \ place le focus du clavier dans le volet utilisé, et passer d’un volet à l’autre n’ajoute aucune étape à l’historique du navigateur. La vue fractionnée revient après un rechargement, comme les onglets. En dessous de 768 px de large, un seul onglet est affiché — la vue fractionnée est conservée pour une fenêtre plus large — et Ouvrir à côté ouvre simplement l’onglet. Les lecteurs d’écran trouvent chaque volet sous forme de région nommée d’après son onglet (« orders, volet gauche »).

Lorsque vous travaillez ailleurs — dans une autre base de données, sur une autre page — les onglets de collection d’une base de données (au moins deux, avec l’onglet de la base elle-même lorsqu’il est ouvert) se regroupent en un seul onglet portant le nom de la base de données et le nombre d’onglets qu’il contient ; survolé ou ciblé, il les nomme. Cliquer dessus ou appuyer sur Enter ouvre la base de données elle-même (son onglet, ouvert s’il ne l’était pas) et les affiche de nouveau ; ouvrir l’une de ses collections n’importe où les affiche aussi, cette collection étant active. Les flèches s’arrêtent sur lui sans l’ouvrir ; Delete, son bouton de fermeture ou un clic du milieu les ferme tous, et Annuler les rétablit. Ctrl / ⌘ + Shift + flèches déplacent l’onglet actif au-delà d’un groupe réuni, comme un seul bloc ; un groupe peut être glissé.
