Overview

Mongo Manager is a secure MongoDB manager in your browser. It works fully offline, with no telemetry, update checks, CDN or external fonts: the browser only talks to Mongo Manager, and Mongo Manager reaches only what you configure — your MongoDB deployments and SSH hosts, and the AI providers, backup destinations and GitHub plugin installs you turn on.

  • Getting started install, first run, your first connection and query.
  • Security modes, keys, two-factor sign-in, roles and the audit log.
  • Deployment system service, Docker, reverse proxies and offline installs.
  • Import and export CSV, JSON, NDJSON and Excel files, field mapping, modes, dry runs and reports.
  • Backup and restore back up a collection, a database or the server, encrypted or as mongodump archives, and restore them anywhere with a plan, confirmations and dry runs.
  • Server administration MongoDB's users and roles, sharding and zones, alerts by e-mail and webhook, and each connection's live health.
  • AI assistant ask for a query, a pipeline or a validator in your words, explain or speed up a query, describe a collection — with a cloud or a local model.
  • Plugins build your own tabs, actions and pages — the manifest, the bridge API, the sandbox and its security scan, packaging and publishing on GitHub, with a starter template and files for AI coding assistants.
  • Keyboard shortcuts press ? anywhere in the app to see them.
