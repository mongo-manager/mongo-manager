键盘快捷键

自定义按键

下列按键是应用自带的默认按键。通用快捷键（命令面板、侧边栏、专注模式、固定、快捷键列表、查询、Ask AI、助手、移动标签页和分屏视图）可在“账户设置 → 键盘快捷键”中改用其他按键：选择“更改”，然后按下新的按键。已被其他快捷键占用的按键、浏览器或编辑操作保留的按键（复制、粘贴、关闭标签页、重新加载等），以及输入时会误触发的单个字母或符号，均会被拒绝，并说明原因。“恢复”可将单个快捷键恢复为自带按键（再次按下这些按键也有同样效果），“全部重置”则恢复所有快捷键；在从服务器读取到自定义按键之前，无法进行任何更改，“重试”会再次读取。新版本已无法使用的按键会恢复为该快捷键自带的按键，设置中会说明一次具体是哪些按键。自定义按键保存在服务器上，因此其他浏览器中也会生效；? 列表、命令面板、工具提示和屏幕阅读器都会显示自定义后的按键。编辑器、列表、表格、示意图和 Shell 的按键保持不变。

工作区标签页

在标签页之间移动 ← / → / Home / End
关闭当前聚焦的标签页 Delete
将当前标签页向左或向右移动 Ctrl / ⌘ + Shift + ← / →
在上一个标签页旁边打开当前标签页；在分屏视图中，移到另一个窗格 Ctrl / ⌘ + \
打开当前聚焦标签页的菜单（并排打开、关闭窗格、关闭标签页、关闭其他标签页） Shift + F10 / Menu
调整窗格大小（焦点在分隔条上时） ← / → / Home / End

分屏视图并排显示两个标签页。可通过标签页菜单（其箭头、右键单击或 Shift + F10）中的并排打开、将标签页拖到工作区右侧，或按 Ctrl / ⌘ + \ 来打开。标签栏只有一个：屏幕上的两个标签页带有窗格标记，在标签栏中选择的标签页会在当前使用的窗格中打开。当前使用的窗格带有强调色条并标示活动窗格；单击另一个窗格或用 Tab 键移入即可使用它。拖动分隔条，或让其获得焦点后使用方向键，可分配宽度（20–80 %）。窗格标题中的关闭窗格会结束分屏并保持两个标签页打开，键盘焦点留在该窗格中；关闭某个窗格的标签页也会结束分屏。主页会隐藏分屏而不结束它：选择其中一个标签页，或在主页上按 Ctrl / ⌘ + \，即可再次显示（若未保留分屏，则在主页上按 Ctrl / ⌘ + \ 会将最近使用的两个标签页并排显示）。Ctrl / ⌘ + \ 会把键盘焦点移入当前使用的窗格，在窗格之间切换不会在浏览器历史记录中增加条目。重新加载后分屏会恢复，标签页也是如此。窗口宽度低于 768 px 时只显示一个标签页（分屏会保留到窗口变宽时），此时“并排打开”只是打开该标签页。屏幕阅读器会将每个窗格识别为以其标签页命名的区域（“orders，左窗格”）。

在其他数据库或其他页面中工作时，同一数据库的集合标签页（两个或更多，数据库自身的标签页若已打开也算在内）会合并为一个标签页，以该数据库的名称和所含标签页数量命名；指向或聚焦它时会列出这些标签页。单击它或在其上按 Enter 会打开数据库本身（其标签页，若尚未打开则先打开）并重新显示这些标签页；在任何位置打开其中一个集合也会重新显示它们，并使该集合处于活动状态。方向键会停在它上面而不会打开它；Delete、它的关闭按钮或鼠标中键单击会将它们全部关闭，“撤销”可将它们恢复。Ctrl / ⌘ + Shift + 方向键会把活动标签页整体移过一个合并的标签组；标签组可以拖动。
