AI 助手

AI 助手可以把自然语言转换为查询、管道或验证器，解释查询，建议如何加快查询速度，并描述集合。它负责编写，由您审阅并运行。它绝不会自行运行任何内容。

打开集合，选择其各部分旁边的询问 AI，或按 Ctrl + I（Mac 上为 ⌘ + I）。命令面板中也提供“询问 AI 关于此集合……”。

功能

  • 编写查询（文档）：编写筛选，并在您提出要求时编写投影和排序。
  • 编写管道（聚合）：各阶段以卡片形式设置。
  • 解释：逐步说明当前查询或管道的作用。
  • 加快速度（执行计划）：根据其查询计划和索引，说明查询可能较慢的原因，并给出索引建议，建议会打开已填好内容的索引对话框——在您确认之前不会创建任何内容。
  • 编写验证器（验证）：以草稿形式设置 $jsonSchema；在您保存之前不会保存任何内容。
  • 描述集合（模式）：说明其包含的内容、值得注意的字段和异常之处。

回答会随着生成逐步显示。查询、管道或验证器会与编辑器当前内容并排显示；插入会将其放入编辑器（若编辑器中已有内容，会先询问）。会写入数据（$out、$merge）或运行 JavaScript 的管道会被标记；运行它时仍需像往常一样进行相同的确认。当服务器不允许服务器端 JavaScript 时，此类回答无法插入。

服务商

管理员在设置 → AI 助手（账户菜单）中添加服务商：Anthropic（Claude；默认为 claude-sonnet-5）、Google Gemini（来自 Google AI Studio 的密钥和 gemini-2.5-pro 之类的模型名称）、任何与 OpenAI 兼容的服务器，或 Ollama。其中一个为默认服务商；用户可以在其他服务商中选择。密钥在服务器上加密存储，不会再次显示，也绝不会发送到浏览器；更改服务商的地址时会再次要求输入其密钥，因为该密钥属于旧地址。测试会发送一行请求，并说明结果。

请求由服务器发往服务商，绝不会从浏览器发出。每张卡片都会说明该服务商是在本地网络或私有网络中应答（“本地”），还是来自外部（“云端”）。

离线使用本地模型

在您自己的网络中使用 Ollama（或任何与 OpenAI 兼容的服务器）时，助手无需访问互联网即可工作。本地和私有地址必须列在 MM_AI_PRIVATE_NETWORKS 中（例如 10.0.0.0/8）；在本地模式下，运行 Mongo Manager 的机器始终被允许，因此 http://localhost:11434 可直接使用。明文 http 仅允许用于所列网络。

聊天

助手（浮动在右下角的按钮，或 Ctrl / ⌘ + .）是覆盖在您工作内容之上的窗口中的对话：页面保持其宽度。可以从其左边缘和上边缘调整大小、展开，或关闭——它会保留您正在输入的内容；在手机上它会占满整个屏幕。在集合标签页上，每条消息都带有该集合的上下文，由服务器读取，方式与一次性操作相同：模式摘要，以及——按您通过消息框上方的标签选择——当前查询或管道、索引、验证器，并且在您对该条消息同意后，还有样本文档。在其他位置，消息不带任何数据，助手提供一般性的 MongoDB 帮助。当您转到另一个集合时，对话会显示其发生变化的位置。

  • 只有最新的一条消息携带数据。较早的消息作为此前的对话发送——最多最近 20 轮或 24 KB——并且仅包含已完成的回答。当较早消息所在的连接已不存在、您已无法读取它、其助手现已关闭、其个人数据规则此后已更改，或它来自仅允许本地服务商的连接而服务商从外部应答时，该消息会被略去，面板会对此予以说明。根据此类消息写成的回答会一并略去。
  • 回答中的每个代码块都有一个操作（索引建议每个索引一个），在该代码块所指明的集合中使用——未指明集合的代码块使用回答所指明的集合——或该消息所涉及的集合；若编辑器中已有内容，会先询问。指明了助手未获得的集合的代码块不会去往任何地方。运行会把查询放入查询栏，或把管道放入聚合部分，并运行；会写入数据的管道（$out、$merge）只会放入那里，由您自行运行。验证器会进入验证草稿；索引建议会打开“创建索引”对话框。单独的阶段（要添加到管道中的 $match）只显示为代码。若要求将结果作为文件提供（“下载为 Excel”），在连接允许导出的地方，该代码块会提供下载为 Excel、CSV 或 JSON：导出会带着查询或管道并设置好格式打开，由您启动。运行服务器端 JavaScript 的代码会先询问。没有您的点击，任何内容都不会运行。
  • 聊天属于您：没有任何路由允许其他人——包括管理员——读取它们，除非您从 AI 历史记录中分享其中的某一轮。它们在服务器上加密保存，自其最后一条消息起保留 MM_AI_CHAT_DAYS 天（默认为 30 天）；设为 0 时，它们只保存在服务器的内存中，保留 12 小时，不会向磁盘写入任何内容。您最多保留 50 个聊天，每个聊天最多 200 条消息；超出时最早的先被删除。面板中的历史记录可删除单个聊天或全部聊天；删除用户会同时删除其聊天。

智能体模式

在助手面板中开启智能体模式后，助手会替您处理您的连接：“在 Sales Mongo 连接中添加名为 users 的新集合，并添加一个演示用户”——它会找到 Sales Mongo，使用其默认数据库（并说明这一点——如果没有默认数据库，则会询问使用哪个数据库），提出创建集合，再提出创建演示用户，并告诉您它做了什么。该开关只属于您自己，并随您的账户保存——位于助手面板和“账户 → 偏好设置”中；关闭时，助手就是上文所述的助手。管理员在设置 → AI 助手 → 此服务器上的智能体模式中，为所有人设定智能体可以做什么：关闭（任何人都无法开启）、只读（它可以读取、统计、解释并打开您所要求的内容，但不会提出更改、备份或计划）或完全（默认）。该设置的更改会立即生效，对正在运行的一轮对话和已在卡片上等待的更改也是如此。

  • 它按名称了解您的连接：您可以使用助手的每个连接，连同您在其中的访问权限、它是否只读，以及智能体是否可以在其上提出更改——绝不包含其地址、用户名或密码。AI 策略为关闭的连接会被完全略去；设为仅限本地服务商的连接，只会告知被判定为在您所列网络中应答的服务商，此时整个请求也只能到达这些网络。它还会按名称获知您当前查看的标签页——集合、连接的某个部分（如性能或用户和角色），或某个页面（如计划备份或后台任务）——因此“这个”和“这里”指的就是它。同一聊天中的后续消息，会携带之前各步骤所做的事情，仅包含名称和数量（“已删除”“找到 2 个”），因此“在 Prod 上同样操作”或“删除它”无需重复说明。
  • 读取立即执行：列出连接、数据库、集合和备份目标；集合的统计信息、模式（名称、类型和占比）和索引；计数；解释查询（不运行任何内容）；查找文档以及运行只读聚合（最多 10 条结果；$out、$merge 和服务器端 JavaScript 会被拒绝）。它还可以替您打开连接、数据库或集合的某个部分，并检查连接是否有应答——像您一样打开它，使应用显示其已连接，或说明失败的类型（网络、找不到名称、其凭据、您必须进行的登录——会从该步骤提供；绝不包含地址）。被拒绝的登录只会尝试一次并被记住，因此一段时间内不会再次尝试（智能体不会导致任何账户被锁定），并且从不接受无人查看过的新 SSH 主机密钥。对于字段的不同值（“有哪些状态？”），它会被告知有多少个（数组的每个元素各算一个，与 MongoDB 的计算方式相同）；这些值本身（按出现频率从高到低）只有在您对该条消息同意（文档）后才会发送给服务商，且绝不会包含个人字段，也不会通过针对个人字段的筛选获得。 当要求提供文件时（“将配送中的订单导出为 CSV”），它会在卡片上提出导出，就像提出更改一样（由您确认；在智能体不得提出更改的地方，以及在只读策略下不会提出）——CSV、JSON、NDJSON、Excel 或 SQL（PostgreSQL、MySQL 或 SQLite），压缩或不压缩；可以是集合的全部内容、一次查找或只读管道。卡片会显示将要使用的查找或管道，对于查找还会显示文档数量；在您点击后，它就是您自己的导出（使用您的权限，您被隐藏的字段保持隐藏），任务完成后可从其步骤（下载）或从后台任务下载，且没有任何值会到达服务商。 查找或聚合步骤提供显示文档：以您的身份通过应用重新执行同样的读取（使用您的权限，您被隐藏的字段保持隐藏），只显示在该步骤中——绝不会发送给服务商，绝不会成为您最近的查询之一，并且在 AI 历史记录页面上不提供。当要求显示文档时（“Demo 上配送中的订单”），会打开该集合并在其中运行该查询，或在其构建器中打开管道：应用会像您一样运行它，并且没有任何值到达服务商。它会先询问，再替换您正在编写的查询；会写入数据的管道只会放入构建器，并且仅在智能体可以提出更改的地方才会这样做。回答中的查询会在其所指明的集合中运行（它使用过的集合），否则在其前面的代码块所指明的集合中，否则在其后第一个代码块所指明的集合中，否则在它最后使用的集合中；若都没有，则不会运行——绝不会在当前打开的任意标签页中运行。
  • 每项更改都等待您的确认。创建数据库或集合，插入、更新或删除文档，创建或删除索引，删除集合或数据库，设置集合的验证规则（卡片会显示被替换的规则，并说明现在有多少文档违反新规则；除非要求，否则保留其级别和操作，只会覆盖其所依据的规则，绝不用于时间序列，也不用于开启了客户端加密的地方——那里的规则是加密自身的规则），创建搜索索引（在服务器支持搜索的地方，绝不用于适用个人数据规则的地方：它会复制其值），重命名集合（需输入其名称；绝不能重命名为已被占用的名称，也不能用于个人数据规则指明了它的地方——这些规则会留在旧名称上；绝不用于视图、时间序列，也不用于开启了客户端加密的地方；会说明读取它的视图），像集合的“复制”一样复制集合（依据您自己的计划，其拒绝原因先用各自的原话说明；显示并统计筛选或管道，绝不按个人字段挑选；每种会更改目标文档的模式都需要输入其名称；在后台任务中跟踪），以及备份和备份计划，都会以卡片形式出现在对话中：包含操作位置、将要发送的确切内容，以及应用自身预览发现的情况（更新或删除匹配多少文档、删除会丢失多少、计划接下来的运行时间）。确认遵循应用的确认规则——需要稍等片刻才能按下，双击绝不会通过——并且删除，或更改每个文档，会像应用的对话框一样要求输入名称。会丢失数据的更改——删除、更新或删除文档、恢复，或覆盖现有内容的复制——会提供先备份：对其将要丢失的内容制作加密备份，其密码在卡片上要求输入两次，通过备份路由制作，且必须完成后才能确认更改（确认会等待它；之后该步骤会说明已备份并打开其任务）。 智能体会读取您的告警——触发的阈值、近期事件、报告的运行及其计数——并且对于管理员，还会读取告警规则和计划报告；它会创建、更改、暂缓提醒和删除连接的规则，并创建、更改、运行和删除报告，每项都通过告警路由在卡片上进行（渠道按其名称——绝不包含 Webhook 的地址——仅在设置了邮件服务器的地方才支持电子邮件；报告的计数绝不按个人字段，也不针对视图）。对大型集合（100,000 个文档或更多）的读取会先进行解释：没有索引能够支持的读取——它会读取整个集合，或可能会这样——会在其步骤中，在运行期间和之后予以说明，并告知智能体，使其可以提供索引建议（查看前几个文档的操作则不会）。一起要求的多项更改（最多八项）会先以计划的形式给出：按顺序列出，然后每项各有自己的卡片，逐一确认——计划会显示每项的执行情况；被拒绝或被驳回的更改会使其后的更改停止，在最后一项之前结束的一轮会对此予以说明。加密备份在卡片上要求输入两次密码，并带有备份对话框的强度条和生成器；密码只用于该备份。卡片还提供不带密码的选项，即压缩归档（用 mongorestore --archive --gzip 打开）——由您选择，绝不是智能体的选择，且仅在可以制作该备份的地方提供（不适用于只接受加密备份的目标，也不适用于个人数据不得未经加密就离开服务器的情况）；会以明文包含个人数据的备份会对此予以说明。备份制作完成后，其步骤会提供下载。备份的卡片会说明保存在服务器上的副本何时被移除以及发送到何处；一旦开始，其步骤会在后台任务中打开该任务，智能体会在那里跟踪它（“备份完成了吗？”）——发送到目标的备份也通过其发送任务跟踪——并列出您自己的任务和保存的备份，范围是它被告知的连接：状态、名称和每个副本的状态，在适用个人数据规则的地方大小会被隐藏，绝不包含错误本身的原话。备份计划（“设置每周备份”）会像保存时一样在其卡片之前先进行检查——计划数量不超过您可拥有的数量，您可使用的目标（未加密备份只能发往允许的地方），加密备份使用您的备份密钥，运行间隔至少一小时——并且在服务器关闭计划备份的地方，智能体不会提出任何计划。其卡片会说明运行时间，使用您浏览器的时区，除非您指定了另一个时区（会注明所指定的时区），以及保留什么；若完全没有目标，管理员会看到“备份目标”的入口。 也可以从聊天中恢复备份（“把昨晚的备份恢复到 orders_copy”）：通过恢复计划，在指明目标的卡片上进行——需输入其名称——卡片会说明将写入多少个集合、其中已有多少个，将覆盖多少文档，备份是何时制作的，以及哪些目标是固定集合（写入其中可能会移除其最旧的文档）；加密备份的密码在卡片上询问一次，与制作备份时一样，并且计划会在点击时用它重新生成：若目标在卡片之后发生了变化，则不会开始任何操作。它绝不会恢复到 MongoDB 自身的数据库中，整个服务器的备份，或计划要求确认的内容（TTL 索引、个人数据、脱敏备份），则需从“备份”中恢复。 您自己的计划可以从聊天中列出（“我有哪些计划？”）、立即运行、暂停、恢复、更改和删除，每项都按其名称在其卡片上进行：更改的卡片会说明其新的保留策略、时区或目标现在会移除多少备份，您确认的就是该数量；删除计划需要输入其名称，其备份仍会保留。管理员的暂停只能由管理员解除。 服务器的健康状况也可以从聊天中读取，就像“性能”标签页读取它一样（需具备其监控权限）：其状态、副本集（成员按编号，绝不包含其主机）、最繁忙的集合、慢查询、针对数据库的索引建议以及正在运行的操作——按数字、名称和类型，绝不包含命令或值。正在运行的操作通过一张要求输入其 opid 的卡片停止，适用于有权停止操作的用户——绝不用于 MongoDB 自身数据库上的操作，也不用于 Mongo Manager 自己的操作（任务、通过应用发出的请求）。 MongoDB 的用户和自定义角色也可以从聊天中列出，按名称和角色（需具备管理它们的权限）；创建用户并赋予角色，需在卡片上输入其密码——助手绝不会给出、看到或保存密码，也绝不会授予覆盖整个部署的角色——删除用户则通过要求输入其名称的卡片；绝不能删除连接所使用的登录账户。覆盖整个部署的角色绝不会从聊天中授予：admin 数据库中其他（仅限管理员的）内置角色、local 或 config 的任何角色，以及包含此类权限的自定义角色；也不能在 local 或 config 中创建用户。只有管理该连接的数据库并且可以看到其个人数据的人，才能列出或更改用户。 在您点击之前不会写入任何内容；拒绝会告知助手，并且不会有任何更改。一次只提出一项更改；10 分钟内未回答的更改，或您中止的消息，不会产生任何更改。当您确认时，会重新检查允许该更改的条件：如果智能体模式、连接的助手或智能体在此处的更改权限在此期间被关闭，则不会写入任何内容；更新或删除会被重新预览，若计数自卡片以来发生了变化，会予以说明，而不会执行。TTL 索引（在一定时间后移除文档的索引）同样属于破坏性更改：卡片会说明它在一分钟内将删除多少文档，并要求输入集合的名称。
  • 以您的身份，通过应用执行。每个步骤都使用您的会话调用应用自己的路由：您的权限、只读连接、个人数据脱敏和服务器端 JavaScript 规则，与在屏幕上完全一样地适用，并且每次写入都以您的名义记录在审计日志中——标明由助手执行，附带其所属的轮次和步骤：条目详情中的显示此轮对话会一并列出该轮的工具调用、您的回答以及应用为此所做的事情。管理员可以按连接关闭智能体的更改（连接表单中的允许智能体在此提出更改）；读取仍然可用。该开关对每个连接都是开启的，包括在此版本之前创建的连接：每项更改仍需等待您的点击。在消息进行期间，某个连接被关闭助手或设为仅限本地，会使下一步停止。
  • 每个步骤发送了什么。步骤按运行顺序列出，每个步骤都带有其执行位置、发现的内容、用于打开其所涉及对象的链接，以及它发送给服务商的内容：名称、计数、不含值的模式、索引键、不含值的计划，或更改的结果。文档的值只有在您对该条消息允许文档且服务商可以接收样本时才会发送；其中的个人字段对所有人隐藏，而规则无法跟踪其输出的查询完全不会发送任何值。命名了个人字段的筛选、排序、管道或索引会在运行之前被拒绝——即使是计数也会泄露关于其值的信息。MongoDB 自身的集合绝不会为助手读取：既不直接读取，也不通过管道的 $lookup、$graphLookup、$unionWith 或 $facet，也不通过视图。显示其他客户端的查询、目录或服务器地址的诊断阶段（$planCacheStats、$queryStats、$listCatalog、$currentOp、$indexStats、$collStats 等）绝不会为智能体运行，无论嵌套多深。
  • 限制。每条消息最多向服务商发出 10 次请求和 20 个操作，每人每分钟最多 30 个操作。一条消息的第一次向服务商的请求计入下文助手的限制；其后续请求计入它们自己的每分钟配额（默认为 30，MM_AI_AGENT_PER_MINUTE）和同一天的限制，并且每个请求在应答期间立即占用一个名额。一旦做出了更改，结束时的请求会等待其配额，而不是在未说明已完成的操作的情况下结束该消息。
  • Anthropic、Gemini、与 OpenAI 兼容的服务器和 Ollama 都可以使用工具。不能使用工具的模型（部分本地模型）会以只读助手的方式回答，面板会对此予以说明。

发送的内容

  • 来自最多 200 个采样文档的模式摘要：字段名称、类型及其出现频率。绝不包含值、范围、直方图或最常见的值。
  • 您的文字，以及当前查询或管道（由服务器读取并格式化）。
  • 对于“加快速度”：查询计划（阶段和索引，不含查询的值）以及索引。
  • 对于“编写验证器”：当前验证器。
  • 样本文档，仅在您为该请求开启它们且服务商可以接收它们时发送：1 至 5 个文档，每个截断为 4 KB。

工作表中的“已发送内容”会准确显示离开服务器的内容。所有内容的上限为 48 KB；被略去的内容会在那里注明。MongoDB 自身的集合（system.*）绝不会被发送，其他集合的任何内容也不会。

个人数据

连接的个人数据规则适用于发送给服务商的所有内容，对所有人都是如此——包括可以在屏幕上看到这些值的人——因为数据会离开服务器。个人字段在模式摘要中仅以名称出现；在样本和查询中，其值会被替换为 ***。您可以为一次请求隐藏更多字段（“隐藏这些字段”）。看起来像密码或令牌的键始终会被隐藏。

连接的 AI 策略

在连接的表单中，AI 助手可选任何服务商（默认）、仅限本地服务商或关闭。“仅限本地服务商”只允许请求发往所列网络内的地址——在建立连接时检查，而不是根据输入的名称。“关闭”会在该连接的界面上隐藏助手，并且智能体完全不会获知它的存在。允许智能体在此提出更改（默认开启）可以关闭，使智能体在该连接上只能读取。在智能体的工具下，管理员可以在那里单独关闭各个工具——读取和显示与更改分开，类似 MongoDB MCP 服务器的禁用工具：被关闭的工具会在其在该连接上读取或提出任何内容之前被拒绝（包括复制到该连接、从该连接恢复、按名称查找其计划、列出其任务或备份），已在卡片上等待的相关更改会在确认时被拒绝，在备份被关闭的地方不会提供“先备份”，并且智能体会被告知哪些已关闭。只列出作用于连接的工具；后续版本新增的工具默认开启。它们随连接的导出和导入一同传递（当前版本不认识的名称会被丢弃）。

限制

  • 每人每分钟 10 次请求、每天 200 次（MM_AI_PER_MINUTE、MM_AI_PER_DAY）。
  • 每人同时 2 个，服务器同时 8 个（MM_AI_MAX_CONCURRENT）。
  • 回答在 3 分钟或 512 KB 后停止；每个服务商都有各自的最长回答（以令牌计）。
  • 谁可以提问：管理员和编辑者（ai:use 权限），限于其有权读取的集合。

安全

  • 没有智能体模式时，助手没有任何工具：它无法读取任何其他内容，也无法运行任何内容。在聊天中，它只能看到此前的对话，别无其他。在智能体模式下，其工具只通过应用的路由，以您的身份行事，并且每项更改都等待您的点击。
  • 您集合中的数据可能试图指示模型。它写出的任何内容都只会成为编辑器中的文本，由与查询栏相同的安全解析器解析；在您运行之前不会运行任何内容。在智能体模式下，工具结果会以标记为数据的形式交给模型，绝不作为指令；即使数据说服模型提出更改，该更改在您确认之前也只是一张卡片。
  • 回答以带简单格式的纯文本显示：没有图片，也没有可用的链接，因此回答无法使您的浏览器加载任何内容。
  • 每个请求都保存在您的 AI 历史记录中（侧边栏中的 AI 历史记录），使用服务器的密钥封存，默认保留 90 天；管理员设置天数，以及所提问题和回答的文字是否保留。聊天是一个条目，其各轮按顺序排列——普通的、涉及集合的以及智能体的——全部显示在其页面上，并有一个再次打开该聊天的按钮。单独分享某一轮，绝不分享整个聊天：队友读取被分享的那一轮，并且仅限于他们有权读取其所依据内容的地方。智能体的一轮还会逐步显示智能体做了什么——每个工具、其工作位置和结束情况，包括其提出的更改——与其聊天中一样，绝不包含值。只有您能读取自己的请求，除非您与团队分享其中一个：此时，有权读取其所依据的每个连接（对于智能体的一轮，则是其步骤所指明的每个连接）的队友可以以只读方式读取它。聊天的保存方式见聊天。审计日志记录谁提问、哪个操作或聊天、服务商和集合、样本数量、令牌数量和结果——绝不包含文字、所发送的内容或回答。在智能体模式下，每个步骤也会被记录（工具、连接和命名空间、结束情况，以及您对更改的回答），绝不包含其参数或所读取的内容。
