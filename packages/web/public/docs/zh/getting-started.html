快速入门

安装

以下方式任选其一。每个发行版还会为所有文件提供 SHA-256 校验和，供离线（气隙）机器使用。

  • npm（Node.js 24 或更高版本）：npx @mongo-manager/app
  • 离线 npm：npm install --global ./mongo-manager-<version>.tgz
  • 独立二进制文件：下载适用于对应系统的文件并直接运行，无需 Node.js。
  • Docker：docker compose -f deploy/docker-compose.yml up -d

支持的 MongoDB 版本：6.0 及更高版本。连接较旧的服务器时会被拒绝，并给出相应提示。

首次运行

本地模式（默认）面向单台计算机上的单个用户：Mongo Manager 监听 127.0.0.1:4321 并打开浏览器。该模式没有登录步骤，而是通过一次性链接打开。在终端中启动时，链接会打印在地址的下一行；在其他位置（服务、容器、日志）启动时，则会打印一个可用于打开的文件的路径，该文件只有当前账户可以读取。此后，只要浏览器保留本站数据（最后一次使用后最多六个月；Safari 在一周未访问后会清除数据），浏览器就会保持已进入的状态，已安装的应用也是如此，但 Mac 上的 Safari 网页应用除外：它使用自己独立的数据，无法使用链接打开，因此在 Mac 上请在 Safari 标签页中使用 Mongo Manager。计算机上的其他程序或账户打开该地址，只会看到一个说明如何打开的页面。链接已用完或浏览器已遗忘时，运行 mongo-manager open 获取新链接；在终端中它同样会打印链接，供无法打开该文件的浏览器使用（Linux 上的 snap 或 Flatpak 浏览器）。在共用的计算机上，请使用团队模式。 

mongo-manager
mongo-manager open             # a new link for a running Mongo Manager (--no-open prints it)

团队模式增加了用户、角色和双重验证登录。首次启动时会在终端中打印一个一次性设置令牌（以服务或容器方式运行时，令牌位于数据文件夹的 setup-token 中）；打开页面并输入该令牌，即可创建第一个管理员。 

mongo-manager --auth

第一个连接

  1. 选择添加连接，在第一个字段中粘贴或输入连接字符串，例如 localhost:27017 或 mongodb+srv:// 地址（可省略 mongodb://）。表单会自动填写：字段下方的一行文字说明识别出的内容，名称会跟随主机名，直到手动输入名称为止。服务器、身份验证、TLS、SSH 等其余设置位于高级选项下；保存并连接会保存该连接并将其打开。
  2. 选择测试连接。它会显示 MongoDB 版本和拓扑结构。
  3. 保存。该连接会出现在左侧的树中。

登录方式

除用户名和密码（SCRAM）外，连接还可以使用 X.509 证书、LDAP（PLAIN）、AWS IAM 密钥、OIDC 或 Kerberos 登录。在高级选项 → 身份验证下选择方式。

  • MONGODB-OIDC（MongoDB Atlas、Enterprise）：每个人使用服务器指定的身份提供商登录，不会存储任何密码。首次打开该连接时，对话框会提供登录：提供商的页面在此标签页中打开，完成后返回。如果其重定向无法到达 Mongo Manager，请选择改用验证码，并输入提供商处显示的验证码。请在提供商处注册本服务器的 …/oidc/callback 地址，或在重定向地址中填写其他地址。允许的主机是登录信息可以发送到的主机（留空：Atlas 和本计算机）。连接页面会显示是否已登录，并可退出登录。工作负载标识（Azure、GCP、Kubernetes）则以运行 Mongo Manager 的机器身份登录：在团队模式下，仅在管理员允许时可用。
  • Kerberos (GSSAPI)：填写主体，并在服务器需要时填写服务名称、领域以及主机名规范化设置。它使用运行 Mongo Manager 的账户所持有的 Kerberos 票据登录：在自己的计算机上是本人的票据，在团队模式下是服务器的票据，且除非管理员允许，否则处于关闭状态。它需要 npm 包的可选依赖 kerberos 包（参见部署）。

客户端加密

在高级选项 → 加密下，连接可以使用客户端字段级加密（CSFLE）或可查询加密（Queryable Encryption）。它需要 npm 包的可选依赖 mongodb-client-encryption 包。

  • 密钥提供方：本地 96 字节主密钥（生成新密钥会创建一个；请保留一份副本，否则数据将无法解密）、AWS KMS、Azure Key Vault、Google Cloud KMS 或 KMIP。它们的凭据以密封方式保存，之后不再显示。密钥库是存放数据密钥的集合（默认为 encryption.__keyVault）。
  • 模式：读取和写入会解密读取的数据并加密写入的数据（MongoDB Enterprise 或 Atlas）；仅解密会以解密后的形式读取加密值，且不写入任何文档（MongoDB Community）。查询分析使用 crypt_shared 库（其路径；在团队模式下为服务器上的路径）或本计算机上的 mongocryptd。
  • 加密字段来自服务器的集合选项（可查询加密的 encryptedFields、CSFLE 的 $jsonSchema 验证器），除非连接自行提供映射。文档视图会用锁图标标记加密字段。
  • 连接的加密部分（面向其管理员）会列出数据密钥、创建新密钥并轮换密钥（使用主密钥重新包装），还可以创建可查询加密集合：每个字段需指定类型以及是否可按相等或范围查询，并为每个字段创建一个数据密钥。
  • 被隐藏个人数据的用户看到的是加密值的存储形式，并且无法在这类连接上写入文档。复制操作按存储形式移动加密值；可查询加密集合无法被复制。

主页和后续步骤

主页是一个小组件仪表板，可通过自定义仪表板添加、移除、调整大小和移动小组件；其布局会保存在服务器上。后续步骤小组件最多建议五件事，由应用根据最近的操作自行计算得出：正在触发的告警、过去一天内失败的任务、需要处理的实时同步和计划备份、为最近使用的数据库建议的索引（根据其慢查询，且需有权监视其服务器），以及最近打开过但当前未打开的位置。每一项都是可直接执行的链接：索引会打开常用的“创建索引”对话框并填好键，在那里确认之前不会构建任何内容。使用其 ✕ 忽略某一项（“撤销”可恢复）；忽略状态会随仪表板一起保存，同类的新事件会作为新步骤再次出现。小组件菜单中的重新显示已忽略的步骤会将它们全部恢复。

已设置 AI 服务商时，小组件菜单会提供用 AI 排序；该功能默认关闭，需手动开启。开启后，AI 仅根据事实对步骤排序并拟定标题：每个步骤的类型、名称（连接、数据库、集合、索引的字段名）和数量，绝不包含任何值、文档或错误文本。如果某个步骤所属连接的 AI 策略为“关闭”，或为“仅本地”而服务商并不确定是在本地网络内应答，则该步骤不会被发送，并保持原有位置。AI 无法添加步骤，也无法更改步骤的作用：在它给出的每个标题下方，由应用自己的文字说明该步骤的作用，且标题中不含数字（数量会过时；数量由应用的那一行给出）。只有在步骤发生变化（步骤类型或位置不同）或选择用 AI 重新排序时，才会重新排序；数量变化或时间流逝不会触发。每次排序都会记入 AI 历史记录（记为“后续步骤”，不含具体文字）和审计日志（仅记步骤数量，绝不记名称）。只有在有权创建索引的位置才会建议索引。

查询

打开集合并输入筛选条件，例如 { status: 'A', qty: { $lt: 30 } }，然后按 Enter。选项可添加投影、排序、跳过、限制、排序规则、hint 和时间限制。最近的查询列出在该集合上运行过的查询，星标会将查询保存为收藏，并可设置名称和标签。

打开集合时，最新的文档排在最前：排序 { _id: -1 } 显示在选项中和 _id 列上，可以在那里更改或清除，重置按钮会恢复它。视图和时间序列集合保持原有顺序。若要按存储顺序打开集合，请在偏好设置中关闭“打开集合时最新的文档排在最前”。

栏中的值可以是参数，写作 {{name}}： { status: {{status}}, qty: { $gte: {{min}} } }。每个参数在栏下方都有一个对应字段，查找会使用在那里填写的值运行查询：18 是数字， "18" 是字符串，ISODate("2026-01-01") 是日期，其他任何文本都按输入原样作为字符串。从栏中保存的收藏会保留其参数，并将已填写的值作为默认值；打开收藏时会填入这些值并运行，如果某个参数没有默认值，则等待输入。在引号、正则表达式或注释中，{{name}} 只是普通文本。无权查看某个连接的个人数据的用户，永远不会得到其他用户的默认值。

栏下方的标签建议了一些条件：最近在该集合上运行过的条件，以及根据其小样本推断出的条件（常见值，例如 status = "paid"，或许多文档都缺少的字段）；选择其中一个会将其添加到筛选条件并运行。采样在页面空闲或使用该栏时进行一次，绝不会在视图上进行（那会运行视图的管道）。在结果上方，当前使用的筛选条件中的每个条件各自是一个标签：移除它（点击其叉号，或在标签上按 Delete）会在没有该条件的情况下运行筛选，撤销可将其恢复。只有当栏中的文本就是当前使用的筛选条件时，栏中的文本才会随之更新；仍在编辑的筛选条件保持原样。栏下方的面板按部分显示当前使用的查询；其运行会再次运行该查询，其星标会将其保存为收藏。

在表格中，点击列名即可按该列排序：升序，然后降序，然后取消排序。 Shift + 点击会将该列加入排序。排序会写入选项，并与栏中的筛选条件一起运行，因此栏中始终显示实际运行的内容。拖动列的边缘（或聚焦后使用方向键）可更改列宽，双击边缘可让该列重新自动调整大小；列宽按集合分别保存，仅针对本人，且保存在此浏览器中。列菜单可对其排序、复制其名称或隐藏它。对您隐藏了值（个人数据）的列永远不会参与排序。

图表位于表格、卡片和 JSON 旁边，将查询结果绘制为柱状图、折线图、散点图或饼图：选择 X 轴上的字段、数值字段的计数、求和或平均值，以及将结果拆分为多个系列的字段。它最多读取前 1,000 个匹配的文档（仅读取绘制所需的字段），文档更多时会给出说明；同样数据的表格供屏幕阅读器使用。对您隐藏的字段不会提供，也绝不会绘入图表。数据库、集合和列的菜单中以及模式中字段旁边的复制名称，会复制纯名称。

表格的每一行开头都有编辑、删除（确认后执行）和 ⋮ 菜单；点击行的 _id 可打开文档阅读。卡片和 JSON 列表在每个文档上都显示编辑和删除。右键单击某一行会列出它的所有操作，右键单击单元格还会加上单元格自己的操作：复制其值、按此值筛选（用键盘时 Shift + F10 打开同一菜单）。文档会以页面的形式打开，取代结果。返回结果（或 Escape）回到结果原来的位置，并标记最后打开的文档。上一个文档和下一个文档（Alt + ↑ / ↓）依次浏览查询结果，到页末时进入下一页或上一页；因保存而不再符合查询的文档会保留其位置，页面会加以说明。

页面以树、JSON 或编辑器显示文档。在文档中搜索（页面获得焦点时按 Ctrl / ⌘ + F）可在键、值或两者中查找：它会统计匹配数，Enter 和 Shift + Enter 在匹配之间切换，包含匹配的分支会展开，其余部分变暗。转到下一个文档时搜索会保留。树上方的栏显示所选字段的位置（payments › 2 › amount）；复制路径会将其复制为 payments.2.amount。带投影的查询中的行只是文档的一部分：页面会加载、显示并编辑整个文档，并加以说明。

在您有写入权限的地方，可以直接在树中编辑：Enter 或双击可更改值，保留其类型或改为其他类型；F2 重命名字段，Delete 将其移除，字段的菜单可添加字段或项。树和文本是同一份草稿，共用一份撤销记录（Ctrl / ⌘ + Z, Ctrl / ⌘ + Shift + Z）。检查并保存会在写入任何内容之前准确显示哪些字段会变化；只保存这些字段，并以您打开的版本为准，绝不会覆盖服务器上更新的副本。_id 和对您隐藏的值永远不会被更改，搜索也永远找不到隐藏的值。在表格中，双击某个值（或在其上按 Enter）即可就地编辑，并保留其类型。双击行的其他位置会打开文档进行编辑。

批量更新文档和批量删除文档会在运行前先预览：显示有多少文档匹配，以及其中的几个。对于更新，每个样本会显示其中将发生的变化，由 MongoDB 通过不写入任何内容的读取操作计算得出；更新会失败的文档（对文本使用 $inc、经过数组的路径）会被标记。位置路径（$[]）、数组索引以及带条件的 $pull 不会在样本上预览，预览中会说明这一点。个人值在样本中无论更新前后都保持脱敏。

集合

新建集合可以为集合、固定集合或时间序列集合，或视图设置默认排序规则（语言、强度、数字排序以及 MongoDB 的其余选项）；MongoDB 在创建时即固定该设置。集合或固定集合也可以从一开始就保留变更流的前镜像和后镜像。之后，集合菜单中的编辑集合可以开启或关闭这些镜像（需在指明该集合的确认之后），显示其排序规则，并通向“验证”标签页，验证规则仍保留在那里。集合的标题会说明其排序规则以及是否保留镜像。

性能

连接的性能标签页以图表实时显示服务器状态：每秒操作数、连接数、网络和内存，在标签页打开期间每 2 秒采样一次。下方是运行最慢的操作，可按数据库或集合、类型、运行时间、等待锁以及空闲连接进行筛选，也可以暂停；还有耗时最多的集合。编辑者和管理员可以打开该页；操作的“…”菜单会显示其命令，对连接管理员还提供终止操作，执行前会先询问。MongoDB 本身必须允许该账户读取服务器状态：请授予其 clusterMonitor 角色，否则该标签页会说明缺少什么。

性能分析器部分显示每个数据库的性能分析器级别、slowms 和采样率；连接管理员可以通过数据库所在行的铅笔图标更改它们。级别 2（每个操作）会先询问，并在 30 分钟后自动恢复为之前的设置。慢查询列出来自性能分析器以及服务器自身日志的慢操作（即使性能分析器关闭也有效），按时间从新到旧排列，并附有执行计划、检查的键和文档数以及命令；读取的文档数远多于返回数的操作会被标记，在执行计划中打开会在其所属集合中打开它。

在连接的个人数据标签页上，连接管理员可以列出包含个人数据的字段（例如 crm.users.email 或 *.*.**.phone）；集合自己的个人数据标签页只列出并添加该集合的字段，新增字段只需提供字段名，并显示适用于它的连接级更宽泛的规则。被授予无法查看个人数据的用户，在性能分析器、慢查询和操作中看到的值为 ***，且无法使用 Shell。在本地模式（没有账户）下，这些规则同样会对您隐藏这些值，范围覆盖所有位置，包括文档、导出、AI 的上下文，并且在值被隐藏期间 Shell 保持关闭；连接标签页上的也对我隐藏可为该连接关闭此行为。

索引建议会读取数据库的慢查询，并按“相等—排序—范围”规则为每个发生扫描的查询提出索引建议，除非已有索引能满足该查询；它还会列出自服务器启动以来未被使用的索引，或是另一个索引前缀的索引。仅使用字段名。创建索引会打开常用对话框并填好键：在那里确认之前不会构建任何内容。

在连接标题中，打开“性能”时，可选择实时（最近 5 分钟）或已存储的 1 小时、24 小时或 7 天范围。连接管理员可在其旁边的指标历史菜单中开启记录指标历史（同一菜单在询问后可删除已存储的内容）：此后服务器每分钟对该连接采样一次，并保留 7 天（仅数字）。关闭期间，服务器绝不会自行连接该连接。在 mongos 上，该标签页显示分片概览：分片、均衡器、路由器以及每个分片集合的键和数据块分布，大小和超大数据块按需显示。其中的任何操作都不会更改集群。

在副本集上，同一标签页会列出每个成员：哪个是主节点，哪些已停机，每个从节点落后主节点多少秒（超过 10 秒为琥珀色，超过 60 秒为红色），多数派提交延迟和 oplog 窗口，以及最近几分钟延迟的图表。没有主节点的副本集以红色显示：在选出主节点之前，它无法接受写入。

聚合

集合的“聚合”标签页逐阶段构建管道。添加一个阶段，选择其操作符（在操作符字段中输入即可按名称或功能找到阶段，例如“join”会找到 $lookup，使用方向键和 Enter 选择；列表旁边显示该阶段的作用及其值的示例；每个阶段都从模板开始，并附有指向 MongoDB 手册的链接），然后编辑其值；输入时，每个阶段的输出都会在集合的样本（前 1000 个文档，或随机样本）上预览。阶段可以禁用，可通过拖放或 Alt+上箭头和 Alt+下箭头重新排序，也可以作为文本一次性全部编辑。

运行以流式方式返回完整结果（最多 10 000 个文档），并带有“停止”按钮；“计算总数”仅在请求时才统计数量。以 $out 或 $merge 结尾的管道绝不会被预览：它在确认（确认中会指明目标）后只运行一次，而替换集合时需要输入其名称。管道可以随集合保存（团队模式下可选择共享），可以导出为 Node.js、Python、Java、Go、C#、PHP、Ruby 或 Rust 程序（连接字符串从 MONGODB_URI 读取，绝不写入代码），也可以转换为视图。

视图的管道用同样的方式更改：视图上的编辑管道（在其概览或菜单中）会在其所读取集合的“聚合”标签页中打开它，标记为该视图的管道，并预览每个阶段。更新视图在确认（确认中会指明该视图）之后，将已启用的阶段写回视图。包含构建器无法读取的阶段的管道不会被打开（保存会丢失该阶段）；被隐藏个人数据的用户无法更改其定义被脱敏显示的视图。

查询页

查询页（侧边栏中的“查询”、命令面板，或 Ctrl / ⌘ + Shift + L；其地址为 /library）可按名称、标签、查询文本、类型或集合搜索连接的收藏、已保存的管道、Shell 代码片段和查询历史记录。它会打开您正在使用的连接，否则打开第一个连接，并在您返回时保留所搜索的内容。打开某一项会转到其集合：查找在“文档”中运行，管道会填入“聚合”卡片（如果该标签页已有内容，则先询问）。历史记录保留运行过的查找和聚合，每个集合最近 200 条、总共 2000 条，每条只保留一次并记录使用次数；条目可以逐个删除或清空。收藏和已保存的管道可以在查询页上重命名、重新设置标签、共享和删除，也可以固定：固定的查询仅属于本人（每个连接最多 50 个），在查询页和主页的“查询”小组件中排在最前。命令面板会列出所有在标签页中打开的连接的收藏、已保存的管道和 Shell 代码片段，每个连接按其名称分组，当前使用的连接排在最前。团队模式启动时，本地模式的历史记录会被删除（任何团队用户都无法查看或清除它们）；日志会说明删除了多少条。本地模式的收藏和已保存的管道会保留，供连接管理员使用。

高级 Shell

连接的 Shell 标签页运行真正的 mongosh，其终端用于输入代码：使用数据库、运行查找和聚合、编写脚本。代码完整时按 Enter 运行；当括号、字符串或语句尚未结束时（在 .、操作符、if (…) 之后），会在 ... 之后的下一行继续，Shift+Enter 则始终添加新行。Ctrl+Enter 按现状运行代码。可以将多行代码粘贴到终端：它逐行显示，只有按下 Enter 才会运行。脚本的运行方式与 mongosh 运行所输入内容的方式相同：use、show 和 it 各自单独运行，然后依次运行每条语句；出错时会在该处停止，并说明有多少条语句未运行。print() 和 printjson() 会写入终端； cls 会清除终端和结果，exit 会结束 Shell。

上箭头和下箭头先在所输入内容的各行之间移动，然后在历史记录中移动；Ctrl+R 搜索历史记录（再次按 Ctrl+R 查找更早的匹配项，按 Escape 退出）。Ctrl+C 会停止正在运行的命令，或清除当前行；选中输出时则为复制。Alt+B 和 Alt+F（或 Ctrl+左箭头和 Ctrl+右箭头）按词移动。每个用户的历史记录按连接保存并加密，可以清除。

Shell 对连接管理员开放，也对管理员授予权限的编辑者开放。它运行在不持有任何凭据的沙箱中，只能访问该连接自己的服务器；在只读连接上它会拒绝写入，非管理员无法执行集群或用户管理操作。

Shell 页面会说明它运行的位置（Shell 所在的连接和数据库，会跟随 use 变化）及其状态：正在连接、已连接、正在运行（并显示已运行的时间）或已关闭。其标题栏包含：命令运行时的“停止”；清除屏幕和结果（Ctrl+L，命令运行期间也可使用，或使用 cls；会有通知说明，通知中的“撤销”或空的“结果”卡片上的“恢复结果”可将其找回）；以及一个菜单，用于将所输入的内容（或最后运行的代码）保存为代码片段、清除历史记录（结果也一并清除）或重启 Shell（会话结束并开始新会话；变量和显示的结果将丢失）。终端采用应用的浅色或深色主题或自己的主题，并为代码着色。底部的栏列出了各个按键。只要其页面保持打开，Shell 就会一直保持打开，无论多久未使用。Shell 关闭时（您的登录已结束，或超过了服务器设定的空闲或生存期限制），页面会说明原因；按 Enter 会打开新的 Shell；连接中断时仍在运行的命令，在连接恢复后会在屏幕上完成。

输入时可按 Tab 获得补全：db. 之后是数据库的集合（也包括在 Shell 中创建的集合），链式调用返回内容的方法，$ 之后是操作符，以及从集合采样得到的字段名。Shift+Tab，或先按 Escape 再按 Tab，可离开终端。

终端旁边的“结果”卡片以表格、树或文本显示最近一次的结果；“更多”获取游标的下一批数据，标题中的结果历史记录用于选择更早的结果，每个结果以产生它的命令命名（仅保存在内存中）；“清除”清空该卡片；通知中的“撤销”或空卡片上的“恢复结果”可找回结果，直到 Shell 重启或其历史记录被清除。该卡片可以加宽；在窄屏幕上，终端和结果是两个标签页。可以同时打开多个 Shell 标签页，每个都有自己的会话。普通查找或聚合的游标会在其集合视图中打开：查找从其跳过位置开始，其限制作为页面大小，显示的文档可导出为 JSON 或 CSV。

代码可以保存为代码片段（私有，或与团队共享），参数写作 {{name}}。打开代码片段（从查询页或命令面板）时，会询问其参数，并将填好的代码放入终端；在按 Enter 之前不会运行任何内容。您自己的代码片段在查询页上编辑：名称、标签、代码及其参数（输入时，每个 {{name}} 后会随之出现一行），检查方式与新代码片段相同；共享的代码片段仍保持共享，审计日志会记录其代码已更改，但绝不记录代码本身。

终端支持屏幕阅读器：其屏幕阅读器模式默认开启，“账户”→“偏好设置”可将其关闭或重新开启，已打开的 Shell 也同样适用。

执行计划

在“文档”或“聚合”中点击“为什么慢？”会针对该查询或管道打开“执行计划”部分。它以树的形式显示 MongoDB 选择的计划（可用方向键在其中移动）、每个阶段读取和返回的内容、被否决的计划，以及用文字表述的警告：整个集合的扫描、在内存中完成的排序、读取量远多于返回量的筛选、对没有索引的字段的联接。当索引有帮助时，“执行计划”会给出建议（先是相等字段，然后是排序，最后是范围），“创建此索引”会在后台构建它。会写入数据的管道不会被分析执行计划，因为分析执行计划需要运行它。

验证

“验证”部分编辑每个插入或更新的文档必须遵循的规则，以及验证级别和操作。“从采样生成”根据集合的文档写出 $jsonSchema；“针对现有文档测试”在保存前统计有多少文档会不通过，并给出示例。保存前会先询问，并说明违反规则的文档在更新时是否会被拒绝；“恢复之前的规则”会在标签页保持打开期间，恢复上次保存所替换的内容。被规则拒绝的写入会说明未满足哪些规则（缺少字段、类型错误、低于最小值），导入或复制的报告也是如此；未通过的值绝不会被重复显示。

模式

集合的模式标签页分析一个随机样本（100、1,000 或 10,000 个文档）：每个字段的出现频率、类型，以及直方图或最常见的值。导出 可将分析结果转换为 Mongoose 模式、MongoDB JSON Schema 验证器或 TypeScript 接口，供复制或下载。当样本中每个文档都有某个字段时，该字段视为必填。

字段的条形（其范围和最常见的值）及其类型都是按钮：选择其中一个会将该条件添加到集合的“文档”筛选条件中（与已输入的条件并列，字段已有条件时则使用 $and），运行并显示文档。分析中被截断的值会显示但不提供选择。包含地点的字段（GeoJSON 点，或名称如 location 或 coords 下的坐标对）会在一张无需任何网络即可绘制的地图上显示（世界轮廓来自 Natural Earth，属于公有领域）：拖动或使用方向键移动；Ctrl 加滚轮、双指操作，或 + 和 − 缩放；这些地点也以表格列出；筛选此区域会添加当前视图区域的 $geoWithin。包含个人数据的字段绝不会被绘制。

数据模型

数据库的模型部分绘制其集合以及集合之间的引用。读取模型会对每个集合采样（100 到 1,000 个文档，最多 50 个集合）以获取其字段：顶层及其下一层，更深层仅在看起来像引用时才读取；并通过三种方式发现引用：以集合命名的字段（userId 或 user_id → users，tagIds → tags），采样到的 ObjectId 值在另一个集合中作为 _id 存在（每个字段最多十个值，总共最多六十次小规模计数），以及视图和您有权打开的已保存管道中的 $lookup 和 $graphLookup 阶段。实线表示通过名称或值发现，虚线表示仅通过 $lookup 发现，点线将视图连接到其源。连线在保存引用的字段一端以鸦脚（“多”）结束（多个文档可以持有相同的 id），在其所引用的集合一端以竖线（“一”）结束；对于引用数组，该端同样是鸦脚。字段会被标记为 PK（键，_id）、UQ（仅由它构成的唯一索引）或 IX（在某个索引中）；索引仅通过其键的名称读取。

拖动图示或使用方向键移动它，+ 和 − 缩放， 0 适应窗口。在图示获得焦点（点击它或用 Tab 进入）之前，滚轮滚动的是页面；获得焦点后，滚轮移动图示，Ctrl / ⌘ 加滚轮缩放（Shift 加滚轮则随时可移动）。点击某个集合，或用 Tab 移到它并按 Enter，可查看其链接并将其打开。列表视图以列表形式显示同一模型：每个集合可展开其字段和链接，点击链接会转到其指向的集合。导出可将图示保存为 PNG 或 SVG（采用当前主题的颜色和您的语言），将模型保存为 JSON，并将模型保存为 Mermaid 的 erDiagram（保存为 .mmd 或复制），用于可以绘制它的 README、wiki 或拉取请求，其中唯一字段按 Mermaid 的命名写作 UK。只显示名称、类型和数量；没有任何值会离开服务器。有权读取文档的用户可以读取模型；作为个人数据对您隐藏的字段只显示名称，绝不会读取其值。仅被授权访问部分集合的 MongoDB 用户只能看到这些集合。

读取模型会让服务器对每个集合采样一次：最多 50 个集合乘以样本大小，外加最多六十次小规模计数。服务器会限制一个模型总共读取的文档数（MM_MODEL_MAX_DOCS，默认 20,000）：集合很多时，每个样本会变小，该部分会说明这一点。在繁忙的生产数据库上，请在服务器空闲时读取，或使用较小的样本。

搜索索引

在 MongoDB Atlas 上，或在运行搜索进程（mongot）的 MongoDB 8.0 或更高版本上，“索引”标签页还会列出集合的 Atlas Search 索引和向量搜索索引：每个索引显示其类型、状态（待处理、构建中、就绪、失败及原因）和所覆盖的内容，构建期间每隔几秒重新检查一次。创建搜索索引接受 JSON 形式的定义，对于向量索引则提供引导式表单：包含嵌入的字段、其维度和相似度，以及用于筛选的字段。定义可以编辑，索引可以删除，删除前需在指明该索引的确认之后进行。在其他环境中，该标签页会说明搜索需要什么条件。

后台任务

构建索引和复制集合在后台运行，因此耗时较长的操作不会遇到超时。任务运行期间可以离开页面，也可以关闭标签页。顶部栏中的后台任务按钮会显示每个任务：MongoDB 报告进度时（索引构建）显示进度条和数字，未报告时（复制）显示仍在运行以及已用时间。您自己的任务结束时会收到通知，也可以在那里取消它们。

如果服务器在复制期间重启，复制会被放弃，其未完成的集合会被移除；目标绝不会处于只填了一半的状态。索引构建可能会在 MongoDB 内部继续进行；“索引”标签页会显示它。
