概览

Mongo Manager 是运行在浏览器中的安全 MongoDB 管理工具。它可完全离线工作，没有遥测、CDN 或外部字体，除非管理员开启每日检查，也不检查更新：浏览器只与 Mongo Manager 通信，而 Mongo Manager 只访问已配置的内容，即 MongoDB 部署和 SSH 主机，以及所启用的 AI 服务商、备份目标、GitHub 插件安装和更新检查。

  • 快速入门 安装、首次运行、第一个连接和第一次查询。
  • 安全 模式、密钥、双重验证登录、角色和审计日志。
  • 部署 系统服务、Docker、反向代理和离线安装。
  • 导入与导出 CSV、JSON、NDJSON 和 Excel 文件、字段映射、模式、试运行和报告。
  • 备份与恢复 备份集合、数据库或整个服务器，加密备份或 mongodump 归档均可，并可通过恢复计划、确认和试运行将其恢复到任意位置。
  • 服务器管理 MongoDB 的用户和角色、分片和区域、通过电子邮件和 Webhook 发送的告警，以及每个连接的实时健康状况。
  • AI 助手 用自然语言请求查询、管道或验证器，解释或加速查询，描述集合，可使用云端模型或本地模型。
  • 插件 构建自己的标签页、操作和页面，涵盖清单、桥接 API、沙箱及其安全扫描、在 GitHub 上打包和发布，并提供入门模板和面向 AI 编程助手的文件。
  • 键盘快捷键 在应用中的任意位置按 ? 即可查看。
